# Proposal: Triggered habits

**Status:** REJECTED. English *habit* / *triggered by*, when a cue produces the act, is CAUSE plus a because or *if* pole (`thewem thahum bl-…` / `thewem thohom bl-…`). Frequency stays a restrictor (`hual` / `hal`). Identity stays label scope. No overlay.

**Related:** [CAUSE](../../grammar/iff-fault.md#cause), [habit recipe](../../grammar/say-reasons.md#habit), [restrictors](../../grammar/restrictors.md), [label scope](../../grammar/label-scope.md).

## What was considered

A closed overlay on the cigarette root (`uzebu`) so *habit* named a **cue then an act**: `/h/` mood, cue in `/b/`, endings for how bound the link is (**-l** usually pulls, **-m** unstated, **-r** can still choose). Optional: *always* would still be `hual`.

The psychological job was context-cued automaticity, not a vice and not a kind of person.

## Why CAUSE already does the job

| English job | Agebon |
|-------------|---------|
| Cue as how the act is produced | **`thewem`** + **`thahum`** / **`thohom`** + cue in the pole's `/b/` |
| How often, no cue | **`hual` / `huam`** |
| When the claim counts | occasion + **`hal`** |
| Kind of person / this time | [label scope](../../grammar/label-scope.md) |
| Past pattern, no claim about now | FORMER + **`hual`** |
| Automatic, no external cue | **`thewem blanar`** |

CAUSE plus a pole already names the cue. The overlay would have been a second spelling of that stack. Its bind endings (**-l** pulls / **-r** can still choose) are not a CAUSE or because scale: because **-l** is *fault*, CAUSE **-r** is *one contributing push*, CAUSE **-l** as *compel* was left open on purpose. That gradient was not enough to add a mood.

English *habit* still needed a landing. That is a [recipe](../../grammar/say-reasons.md#habit), taught on [CAUSE](../../grammar/iff-fault.md#cause), not a new form.

## Not adopted

- Overlay on 🚬, kind `habit`, `/h/` (and a later `/w/` cell)
- Bind/interruptibility endings on that mood
- Recasting the cigarette mnemonic as cue-then-act for an overlay host
