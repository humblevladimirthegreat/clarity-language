# Proposal: atomic **`i`** for equality; **`ae`** → sequence

**Status:** REJECTED. The new ae unary and nullary forms weren't useful enough. The ai and oi stacks were also useless.  
**Phonology of `i`:** TBD — not yet in the [vowel inventory](../grammar/phonology.md) (`a` `e` `o` `u` only; singing constraint against fully closed vowels). Orthography **`i`** is a placeholder until a singable quality (or alternate letter) is chosen.

## Motivation

Equality / tie / equative currently lives on stacked **`ae`** (*corank* = **a**+**e**). That overloads a stack for a third primitive and blocks **a**+**e** as ordered additive. This proposal splits those jobs:

| Form | Proposed meaning |
|------|------------------|
| **`i`** (atomic) | **equality** — equal rank / tie; + SHARED scale → equative (*as … as*) |
| **`ae`** (**a**+**e**) | **sequence** — all hold, spoken order = *then* (steps / agenda / procedure); **not** set, **not** preference, **not** scalar rank |

Identity (*Clark is Superman*) stays [**SAME**](../grammar/predication.md#identity) — not **`i`**.

## Proposed join-series shape

**Families:**

| Family | Vowels | Role |
|--------|--------|------|
| **Set** | **a** / **o** / **ao** / **u** / **ua** / **uo** | unordered inventory / choice / negation / inverts |
| **Sequence** | **`ae`** | ordered additive (*A then B then C*) — **own family**, not set |
| **Rank** | **e** / **oe** / **ue** | preference / exclusive ladder / reverse rank |
| **Equality** | **`i`** / **`ai`** / **`oi`** / **`ui`** | tie / equative / co-equal / choice-among-equals / unequal |

**Naming (sketch):** **`i`** = *equal*; **`ai`** = *coequal*; **`oi`** = *choicequal*; **`ui`** = *counterequal*; **`ae`** = *sequence* (drop *corank*). Exact labels TBD at absorb time.

### Suggested **`i`** stacks

Same stacking habit as on **e**: lead with **a** / **o** / **u** onto the atomic.

| Stack | Build | Multi (2+) reading | + SHARED scale |
|-------|-------|--------------------|----------------|
| **`i`** | atomic | equal rank / tie among conjuncts | **equative** (*as ADJ as*; all equal on scale) |
| **`ai`** | **a**+**i** | **co-equal** — all hold **and** are equal (inventory + tie made overt; contrast bare **`i`**, which asserts sameness without the additive “all are in” bit) | equal **and** each/on-scale (*both equally ADJ* as one claim) |
| **`oi`** | **o**+**i** | **choice among equals** — pick **exactly one** (**-ol**-style) or **at most one** (**-om**-style) from an equivalent set (indifferent alternatives) | rare; prefer nest if needed |
| **`ui`** | **u**+**i** | **unequal** / **counter-equal** — listed are **not** equal (pairwise / as a slate); invert of **`i`** | **inequative** (*not as ADJ as* / unequal on scale) |

**Defaults:**

- No three-vowel stacks (no **uai** / **aoi** / **aei** / …).
- No **-r** on stacked **`ai` / `oi` / `ui` / `ae`** (same rule as other stacks).
- **-r** on atomic **`i`** optional: *some unspecified equal* / draw-frame member (parallel **`zer`**).
- No dedicated reverse-sequence stack (**uae** illegal); reverse steps = reverse conjunct order under **`ae`**.
- Revisers **`il` / `im` / `in`** optional later; restrictor **`hael`** → **`hil`** (tied occasions); **`hail`** / **`hoil`** / **`huil`** only if those stacks are absorbed into restrictors.

### Contrast (multi list)

| Vowel | Claim | Order means |
|-------|--------|-------------|
| **a** | all hold | insignificant |
| **`ae`** | all hold | **sequence** (*A then B then C*) |
| **e** | ranking / preference (exclusivity unmarked) | earlier ≻ later |
| **oe** | exclusive ranked | earlier ≻ later; pick / try one |
| **`i`** | **equal** / tie | **no** order |
| **`ai`** | all hold **and** equal | **no** order |
| **`oi`** | pick one among equals | **no** order (menu of equivalents) |
| **`ui`** | **unequal** | **no** order (or “not tied”) |
| **ue** | rank reversal | later ≻ earlier |

**Not sequence:** discourse *and then* / *therefore* between claims (other `/x/`); preference (**`e`**); scalar comparative (**`e`** + SHARED scale).

## Focus (unary) and bare (nullary)

### Equality — **`i`** / **`ai`** / **`oi`** / **`ui`**

Migrate today’s **`…ae…`** tie/draw readings onto **`i`**; stacks get parallel focus/bare.

**Focus (1 conjunct)**

| Form | Focus reading | Contrast |
|------|---------------|----------|
| **`…il`** | *X tied for* / *equal priority to X*; SHARED scale → **not** equative (needs 2+) | closed equal-rank singleton |
| **`…im`** | *X about tied for* / soft equal priority | open twin of **`…il`** |
| **`…in`** | *X tied for* (stock) / conventional draw label on X | named equal-rank singleton |
| **`…ir`** (optional) | *preferably some equal X* / unspecified peer of kind X | **-r** twin; omit if shipping minimal **`i`** |
| **`…ail`** | *X as equal peer* / *X among equals* (closed) | co-equal singleton — X in an equal inventory frame |
| **`…aim`** | *X as an equal, for one* | open co-equal singleton |
| **`…ain`** | *X among equals* (stock) | named co-equal singleton |
| **`…oil`** | *has to be X (among equals)* / *X as the equal pick* | closed choicequal — forced pick from equivalent menu |
| **`…oim`** | *say, X (any equal will do)* / *X or skip among equals* | open / empty-allowed twin (**o**-style) |
| **`…oin`** | *X as equal pick* (stock) | named choicequal singleton |
| **`…uil`** | *unequal to X* / *not tied with X* | closed counter-equal singleton |
| **`…uim`** | *unequal to X (among inequalities)* | open twin |
| **`…uin`** | *unequal to X* (stock) | named inequality singleton |

**Bare (0 conjuncts)**

| Form | Bare reading | Contrast |
|------|----------------|----------|
| **`…il`** | *it’s a draw* / *tie* / *equal ranking* | closed equal-rank outcome |
| **`…im`** | *probably a tie* / *looks even* | open / speaker-side tie |
| **`…in`** | *it’s a draw* (stock) | named tie label |
| **`…ir`** (optional) | *whatever’s equal* / unspecified tied member | positive twin of empty tie |
| **`…ail`** | *equals* / *an equal set* (nothing listed) | closed empty co-equal inventory — “there is an equal peer-set” frame with no names |
| **`…aim`** | *equals come to mind* / soft equal-set | open twin |
| **`…ain`** | *peers* / stock equal-set label | named |
| **`…oil`** | *no equal options* / *nothing equivalent to pick* | closed empty choicequal menu |
| **`…oim`** | *no equal pick from me* / skip OK | open / empty-allowed |
| **`…oin`** | *no equivalent* (stock) | named |
| **`…uil`** | *unequal* / *not a tie* | closed bare inequality |
| **`…uim`** | *unequal from me* / soft “not even” | open |
| **`…uin`** | *unequal* (stock) | named |

SHARED scale under bare/focus **`i`**-series stays **non-equative** (equative needs 2+ comparees), matching today’s **`ae`** rule — except multi **`ui`** + scale = inequative.

### Sequence — **`ae`**

**Not** set emptiness (*nothing*) and **not** rank emptiness (*no favorite*). Sequence frame = steps / procedure / agenda.

**Focus (1 conjunct)**

| Form | Focus reading | Contrast |
|------|---------------|----------|
| **`…ael`** | *sequence is just X* / *only step X* (closed) | single-step procedure, exhaustive |
| **`…aem`** | *X for starters* / *X as a first step* (others may follow) | open — X begins a longer sequence |
| **`…aen`** | *X first* (stock procedure) / conventional “start with X” | named sequence-start; **not** rank **`…en`** (*X first* as priority) and **not** **`…oem`** (*try X first* exclusive triage) |

**Bare (0 conjuncts)**

| Form | Bare reading | Contrast |
|------|----------------|----------|
| **`…ael`** | *no sequence* / *empty procedure* / *no steps* | closed — stand behind “there is no ordered list of steps” |
| **`…aem`** | *no sequence comes to mind* / *I don’t have steps* | open / speaker-side |
| **`…aen`** | *null procedure* / stock empty-agenda label | named; contrast bare **`…an`** (*null* as empty **set** value) |

**Multi reminder:** **`zael A B C`** → *A then B then C* (closed sequence). Open **`zaem`** = non-exhaustive step list. Named **`zaen`** = conventional procedure bundle (*stop–drop–roll* as sequence, not as unordered set **`zan`**).

**SHARED under `ae`:** like **`a`** — distributive / bundle description; **never** scale-as-equative (that’s **`i`**).

## Summary of changes to [coordination.md](../grammar/coordination.md)

- Add equality family **`i` / `ai` / `oi` / `ui`**; move **`ae`** out of rank/equality into its **own sequence family** (not set).
- Series table: *corank* → drop; add *equal* / *coequal* / *choicequal* / *counterequal* / *sequence*.
- Rank section = **`e` / `oe` / `ue` only**; new equality + sequence sections (or subsections) with multi / focus / bare tables as above.
- Equative / inequative pointers → **`i`** / **`ui`** + SHARED scale.
- **-r:** optional on atomic **`i`** only among the new forms; stacks stay **-r**-less.
- Examples and cross-links retarget tie/equative off **`ae`** onto **`i`**; **`ae`** demos become *then*-sequences.
- Downstream: [comparatives.md](../grammar/comparatives.md), [restrictors.md](../grammar/restrictors.md), [phonology.md](../grammar/phonology.md), [core.md](../grammar/core.md), [predication.md](../grammar/predication.md), [questions.md](../grammar/questions.md), [AGENTS.md](../../AGENTS.md).

## Open questions

1. **Phonetic value of `i`** — new quality vs remap; must stay singable.
2. **Ship all `i` stacks at once?** Minimal path = atomic **`i`** + sequence **`ae`** only; add **`ai` / `oi` / `ui`** in a follow-up.
3. **-r / revisers** on **`i`** — include at adopt time or defer.
4. **Restrictor parity** — only **`hil`**, or also **`hail` / `hoil` / `huil`**?
5. **Clause/VP sequence** — same **`ae`** morphology for *do A then B* / *A happened, then B*? (Expected yes.)
6. **`…ail` bare** gloss — “empty equal-set” is awkward; may prefer bare **`ai`** undefined until a clearer reading appears.
