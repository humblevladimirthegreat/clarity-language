### Classification packaging {#classification-packaging}

You already put a kind on `/ɡ/` after the name (*Azozon is a dog*). The extra choice here is how firmly the kind holds: hedge it, say it holds at every time, or deny it. The kind word stays on `/ɡ/`. Add a hedge on `/w/` before it (*sort of*), **`hual`** after the pair (*always*), or **`gul`** after it (*not*).

> `zazozon godozel gul.`
>
> z-Azozon | [g-dog | g-not]
>
> "Azozon is not a dog."

<!-- cheat-sheet: word-shape-clause -->
| Agebon | Use | English |
|--------|-----|---------|
| `/w/` hedge before the classifying `/ɡ/` | soft / hedged class | *Azozon is something of a dog* / *a dog, sort of* |
| `zazozon godozel hual` | characterizing / habitual | *Azozon is always a dog* |
| `zazozon godozel gul` | negation | *Azozon is not a dog* |

> `zazozon wayurom godozel.`
>
> z-Azozon | [w-degree | g-dog]
>
> "Azozon is something of a dog."

**Related form:** habitual *always* uses [**hual**](/restrictors).

**Related form:** *not a dog* uses [negation **u**](/joins#negation-u) (`gul`).

### Commands to be ADJ {#command-property}

A command can ask for a state as well as an act. Put the [command word](/speech-moves#speech-act-beginner) **`yol`** before a `/ɡ/` word with no verb: the listener is the unstated subject, and the pair reads *be ADJ!*, as a [verbless statement](/predication#classification-property) does.

> `yol guyulom.`
>
> y-command | g-caution
>
> "Be careful!"

The `/ɡ/` word takes the verb's place in the [usual order](/speech-moves#act-word-order), so it comes first. Name the listener after it to address one person (`yol guyulom zawan`), or use the verb root for the doing (`yol vuyulom`, *take care*). **`yul`** turns the same pair into *don’t be ADJ*.

### **SAME** endings

Beginner already used **`gorel`** (*is the same as*). Its other ending finishes the map.

| Agebon | Use | English |
|--------|-----|---------|
| **-l** | stand behind the match (closed) | *is* (the same as) |
| **-m** | leave the match open | *same for our purposes* / *basically* |

<!-- cheat-sheet: word-shape-clause -->
| Agebon | English |
|---------|---------|
| `zalazun gorel blazozon` | *Alazun is Azozon* (the same person) |
| `zalazun gorem blazozon` | *Alazun is basically Azozon* |
| `zalazun gorel blazozon gul` | *Alazun is not Azozon* (not the same person) |
| `zeyel gorel blazozon` | inside a noun phrase: *the person who is Azozon* |

**Compare with:** ordinary *coin* as a noun is `zorel`. Identity is **`gorel`** / **`gorem`** plus a following `/b/` label, kept next to each other.
