# Rank joins {#rank-joins-sitting}

A rank join puts the listed items in order: a tie, the order reversed, or a route from first to last.

### Rank joins {#rank-joins}
<a id="priority-ranking-e"></a>

When English would say two people are *as ADJ as* each other, use a tie: a rank join with two vowels, **o** then **e** (**`zoel`**, or open **`zoem`**). Write the names, then the tie, then the adjective right after it, so the adjective grades the whole list. In a tie, the order of the names does not matter.

> `zazozon zalazun zoel gamahum.`
>
> [z-Azozon | z-Alazun | z-equal-rank | g-challenge]
>
> "Azozon is as challenging as Alazun."

**Compare with:** *more / most* and *least* use **`o`** / **`uo`** plus the same shared adjective ([comparatives](/comparatives)).

### Invert (**`ua`** / **`uo`** / **`ue`**) {#invert-u-stacks}

Beginner already used *everything but* (**`ua`**). A leading **u** inverts **o** and **e** the same way: **uo** reverses a ranking, and **ue** offers everything outside the list.

| Ageben | Use | English | Cue |
|--------|-----|---------|-----|
| **ua** | invert add | *everything but* the listed | **u** ≈ undo + **a** ≈ add |
| **uo** | invert rank | *A after B after C* (last first) | **u** ≈ undo + **o** ≈ rank |
| **ue** | invert menu | *anything but* the listed (free choice outside) | **u** ≈ undo + **e** ≈ choice |

What *everything* or *anything* ranges over comes from context, or from a [SHARED](list-structure.md#shared-after-the-join) `/ɡ/` that names the kind. Only plain **`…em`** means *optional*; on **ue**, **-m** leaves the list open as usual. **-r** still attaches only to one-vowel **a** / **o** / **e** / **u**.

> `zedudal zogudal zual.`
>
> [z-tea | z-coffee | z-everything-but]
>
> "everything but tea and coffee."

> `zazozon zalazun zahelan zuol.`
>
> [z-Azozon | z-Alazun | z-Ahelan | z-rank/less]
>
> "Azozon, Alazun, Ahelan, from last to first."

**Compare with:** plain **`u`** is *not* / *none of* the listed, not an invert stack. *Every cat* uses SHARED kind after **`zual`**: `zual gogozel`.

### Route (**`ao`**) {#route-ao}

Rank **`o`** puts the first item at the **top** (*A matters more than B*). When English would instead say *A, then B* (an itinerary, a turn order, *from 3 to 5*), the first item is the **start**, not the winner. Write the items in that order and close with **`ao`**.

> `zazozon zalazun zahelan zaol.`
>
> [z-Azozon | z-Alazun | z-Ahelan | z-in-order]
>
> "Azozon, then Alazun, then Ahelan."

<!-- cheat-sheet: joins-hooks -->
| Arity | Closed **-l** | Open **-m** |
|-------|---------------|-------------|
| Multi (2+) | `A B zaol` *A, then B* | `A B zaom` *roughly A, then B* |
| Single-item | `X zaol` *start with X* / *from X on* | `X zaom` *maybe start with X* |
| Standalone | `zaol` *in no particular order* / *any order* | `zaom` *not sure where to start* |

A route does not say which item is better. With a SHARED quality it sorts the list from low to high. Two numbers in a route are two values in order (`zragel zrazal zaol` = *3, then 5*). (cue: **a** ≈ add + **o** ≈ rank: *and then*)

### Rank with one item or none {#rank-single-standalone}

Beginner already used single-item *just X* and standalone *nothing*. A rank join takes one item, or none, the same way: a rank of one, a tie of one, a route start, or a last place.

**Rank: single-item**

| Ageben | Use | English |
|--------|-----|---------|
| **…ol** (`zol` / …) | closed rank of one | *only X matters* / *X, period*; + SHARED scale → superlative ([comparatives](/comparatives)) |
| **…om** (`zom` / …) | open rank of one | *X first* / *mainly X*; + SHARED scale → open superlative |
| **…oel** (`zoel` / …) | closed tie of one | *X tied for* / equal priority to X |
| **…oem** (`zoem` / …) | open tie of one | *X about tied for* / soft equal priority |
| **…oen** (`zoen` / …) | stock tie of one | *X tied for* (stock / conventional draw label) |
| **…aom** (`zaom` / …) | open route start | *maybe start with X* |
| **…aol** (`zaol` / …) | closed route start | *start with X* / *from X on* |
| **…uol** (`zuol` / …) | closed last place | *X last*; + SHARED scale → least |
| **…uom** (`zuom` / …) | open last place | *mainly leave X for last* |
| **…on** (`zon` / …) | stock first | *X first* (stock) / *X, as usual* |
| **…or** (`zor` / …) | unspecified ranked member | *preferably some X* / *X as a priority* |

**Rank: standalone**

Standalone **o** says nothing is on top (no favorite; with a SHARED scale, *there is no biggest*). Standalone **uo** says nothing is at the bottom (no least, no veto). Neither says the items are tied (that is **`oe`**), and neither picks out *whichever is on top* (that is **`zor`**). Closed **-l** states it as a fact about the set; open **-m** says only that you know of none.

| Ageben | Use | English |
|--------|-----|---------|
| **…ol** (`zol` / …) | closed empty rank | *no favorite* / *nobody's first*; + SHARED scale → *there is no biggest* |
| **…om** (`zom` / …) | open empty rank | *no favorite, as far as I know*; + SHARED scale → *no biggest comes to mind* |
| **…oel** (`zoel` / …) | closed empty tie | *it's a draw* / *tie* |
| **…oem** (`zoem` / …) | open empty tie | *probably a tie* / *looks even* |
| **…oen** (`zoen` / …) | stock empty tie | *it's a draw* (stock) |
| **…aom** (`zaom` / …) | open empty route | *not sure where to start* |
| **…aol** (`zaol` / …) | closed empty route | *in no particular order* / *any order* |
| **…uol** (`zuol` / …) | closed empty last | *no least-favorite* / *nobody's last*; + SHARED scale → *there is no smallest* |
| **…uom** (`zuom` / …) | open empty last | *no objection* (not naming a veto) |
| **…on** (`zon` / …) | stock empty rank | *no favorite* (stock) |
| **…or** (`zor` / …) | unspecified empty rank | *whatever's most important* |
