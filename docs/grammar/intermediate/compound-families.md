# Which compound {#which-compound}

A word built from several pieces can be one of several kinds of compound, here called families. You tell the families apart by what sits on each side of the first `x`, or around a mid-word `th`. You can add more roots to an ordinary compound or a hyphenated name, and the last section gives the order in which to check a word.

### Left and right of `x` {#families-by-shape}

You have already used two roots glued with `x`, and dictionary words with no `x`. To tell which family a word belongs to, look at both sides of the first `x` after the role letter: that pair picks the family, and so how you read the word. A [role compound](/roles#role-compounds) or [role pointer](/pronouns#role-pointers) is not one of these families: it opens with `w`, a reach vowel, and a part consonant (`zwuzeduyol`, `zwuzer`), and only a noun inside its stem takes `x`.

<!-- cheat-sheet: word-shape-clause -->
| Ageben | Use | English | Cue |
|--------|-----|---------|-----|
| name `x` `a` / `o` / `e` / `u` + `-n` (conversation length) | conversation length | *Azozon, I have time* | vowel on the name |
| longer root `x` `a` / `e` / `o` / `u` | ability | *can’t sing right now* | extra vowel after the root |
| full roots on both sides, maybe more `x` + root | ordinary compound | `zuwedaxubudal`; `zaloxolowon` ([hyphenated names](proper-names.md#multipart-names)) | `x` ≈ plus |
| sake root `th` `a` / `e` / `o` / `u` | [sakes](/sakes) | `guwathal` | `th` ≈ *think* (your view of the sake) |
| other root `th` `a` / `e` / `o` / `u` (or a stack) | [label reach](/label-seams#label-reach) | *angry this time*; *a teacher* | `th` ≈ *think* (what kind of claim the label is) |
| direction root `th` facing person | [viewpoint lateral](viewpoint.md#viewpoint-laterals) | `gewuhothazozon` *Azozon’s left* | `th` ≈ *think* (whose point of view) |

A root is at least three letters, so one or two vowels left of `x` are never a root.

### Adding another piece {#ordinary-compound-order}

To narrow a compound further, or to build a hyphenated name from several labels, add another root with another `x`. Keep the English order in one word (*crush* then *love*; a shop named after three drinks). The last root is the kind, and each earlier root narrows it. The ending stays at the end of the whole word. In a name (a person or a shop), the roots are simply labels in order, and none of them is the kind.

> `gagamaxolamal.`
>
> g-crush-x-love
>
> "in love" (the crush kind)

> `zogudaxedudaxowulan.`
>
> z-Oguda-x-Eduda-x-Owulan
>
> "Coffee-Tea-Water" (one named shop)

[Hyphenated names](proper-names.md#multipart-names) use the same order (*Mary-Kate*: first piece first). A family name is not part of this stack; it is a separate `/ɡ/` word after the given name. [Body left / right](viewpoint.md#viewpoint-laterals) is not this stack: it joins the direction and whose facing counts with `th` (`gewuhothazozon`), because the second root is a point of view, not a kind.

A [role compound](/roles#role-compounds) can take such a stack as its stem (`zwuzodozexowurol` *someone who walks dogs*), but is never one piece of a stack.

**Compare with:** a short office handle is one root plus [`-n`](proper-names.md#proper-name--n), not this stack. A dictionary compound is one listed word, not a live list you extend.

### Which family is this?
<a id="decision-order"></a>

Use the table above. If the word has a mid-word `th`, it is a [sake](/sakes) word (a [sake root](/sakes#sake-inventory), then a vowel, with an optional [feeling tail](how-you-feel.md#feeling-word)), a [label reach](/label-seams#label-reach) word (any other root, then a vowel), or a [viewpoint lateral](viewpoint.md#viewpoint-laterals) (a root follows `th`). The root before `th` decides: after a sake root, letters that look like a root are always the emotion tail (`guwathamel`), never a lateral. Otherwise read both sides of the first `x` in this order:

- A name (one root or a [hyphenated name](proper-names.md#multipart-names)), `x`, a single vowel `a` / `o` / `e` / `u`, named `-n`, as a conversation-length bid → conversation length.
- A longer root, then `x`, then a single vowel `a` / `e` / `o` / `u` → ability.
- Full roots on both sides of the first `x` (and maybe more `x` + root) → an ordinary compound (sense or name).
