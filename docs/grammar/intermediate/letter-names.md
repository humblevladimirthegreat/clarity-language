# Letter names {#naming-letters}

This page gives the Ageben name of every letter, for spelling a word aloud. A drill then plays vowel stacks and letter names on their vowel pitches for you to sing back.

### Letter names {#letter-names}
<a id="letter-names-and-digits"></a>

When you spell a word aloud or name a letter, say the Ageben name for it. Pause between names so two names do not run into one syllable. A letter name is short and followed by a pause, so it does not sound like a [thinking sound](/phonology#thinking-sounds), which holds a vowel well past one beat. A code inside a number word spells its letters with these names too, and makes the pause required before a vowel (`zro'ebal`).

Each digit letter keeps its consonant and takes the [opposite vowel](phonology.md#opposite-vowels) of the digit (`a`↔`u`, `o`↔`e`), so naming a letter never sounds like counting. The second table below sets each name beside its digit.

The table is in alphabetical order. The ten letters that begin a digit syllable come first, in digit order (1 to 9, then 0), so `b` is the first letter and `m` the tenth. The other consonants follow, and the vowels come last.

| Ageben | Name | Cue |
|--------|------|-----|
| `b` | `bu` | *boo* |
| `d` | `de` | *den* |
| `g` | `go` | *go* (no glide) |
| `h` | `ha` | *ha* |
| `z` | `zu` | *zoo* |
| `v` | `ve` | *vet* |
| `r` | `ro` | *row* (no glide) |
| `l` | `la` | *la* |
| `n` | `nu` | *noon* (the *noo*) |
| `m` | `me` | *met* |
| `th` | `tho` | *though* (no glide) |
| `w` | `wa` | *wander* |
| `y` | `yu` | *you* |
| `x` | `xe` | *shed* |
| `u` | `u` | *you* (without the *y*) |
| `a` | `a` | *spa* |
| `o` | `o` | *Cambodia* (no glide) |
| `e` | `e` | *bet* |

<!-- retie: letter-names -->
```text
`ogoze` → `o` `go` `o` `zu` `e`
```

In a clause, a letter you talk about (such as `z`) is read aloud by its letter name (`zu`).

<a id="digit-letters"></a>
The ten digit letters are the consonants of the [digit syllables](/numbers#counts) you count with. This table sets each name beside its digit syllable, so you can see the [opposite vowel](/phonology#opposite-vowels) swap (`a`↔`u`, `o`↔`e`) described above. Counting climbs the vowel pitches, so reciting these ten names steps back down them. The other four names keep stepping down in the same order, so the whole alphabet recited by name keeps falling through the vowel pitches: … `nu` `me` `tho` `wa` `yu` `xe`.

<!-- cheat-sheet: sounds-spelling -->
| Ageben | Digit syllable | Name | Cue |
|--------|----------------|------|-----|
| `b` | `ba` (1) | `bu` | `a` ↔ `u` |
| `d` | `do` (2) | `de` | `o` ↔ `e` |
| `g` | `ge` (3) | `go` | `e` ↔ `o` |
| `h` | `hu` (4) | `ha` | `u` ↔ `a` |
| `z` | `za` (5) | `zu` | `a` ↔ `u` |
| `v` | `vo` (6) | `ve` | `o` ↔ `e` |
| `r` | `re` (7) | `ro` | `e` ↔ `o` |
| `l` | `lu` (8) | `la` | `u` ↔ `a` |
| `n` | `na` (9) | `nu` | `a` ↔ `u` |
| `m` | `mo` (0) | `me` | `o` ↔ `e` |

### Vowel pitch practice {#vowel-pitch-practice}

Sing along with the drill below to hear each vowel stack and each run of letter names as a melody. Choose a pattern, then say each note back on its pitch. The voice sings only the vowels, and you add the consonants.

| Control | What it does |
|---------|--------------|
| **Stacks** | Plays each vowel stack against your home note for you to say back |
| **Digits** | Counts the ten digits in digit order (`ba` `do` `ge` `hu` …), climbing the vowel pitches |
| **Alphabet** | Says every letter name in alphabet order (`bu` `de` `go` `ha` …), stepping back down |
| **Check me** | Matches each note itself, within about a semitone (one piano key) |
| **Strict** | Narrows **Check me** to about half a semitone |
