# Place-name roots {#place-name-roots-sitting}

### Place-name roots {#place-name-roots}

A country or territory name is spelled from the English sound. The root still starts and ends with a vowel. It may keep a consonant cluster (two consonants in a row) from the English name (`avranza` from *France*). A name with no cluster is at least seven letters and ends in `n` plus that last vowel (`azabana` from *Japan*), so it does not look like a three- or five-letter dictionary root.

The endings are the ones any country root takes: `azabanan` is *Japan*, `azabanam` is *Japanese* (belonging to its people), and `azabanal` is its flag ([countries](/proper-names#countries-traditions)).

A person or place that is not in the lexicon can take the same spelling. The [lexicon](lexicon.md#respell) writes it for a name you type. To keep the original letters, use a [span](/spans#loans).

<!-- cheat-sheet: sounds-spelling -->
| Ageben | Use | English |
|--------|-----|---------|
| `azabanan` | place-name root with no cluster (seven letters, ends `n` + vowel) | *Japan* |
| `avranzan` | place-name root that keeps a cluster | *France* |

#### Pick one {#intermediate-pick-one}

**1.** *Ahelan is Japanese.* `zahelan gazabanam.` or `zahelan gazabanan.`

::: details Show answer
`zahelan gazabanam.`

Belonging takes **-m**; **-n** is the country name.
:::
