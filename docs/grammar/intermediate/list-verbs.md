# List verbs {#list-verbs-sitting}

### List verbs {#list-verbs}

English has verbs for what a join does to a list: *includes*, *chooses*, *leaves out*. Ageben makes each of these moves a verb: first letter `v`, the join vowel for that move, and the ending `-n` (`van`, `ven`, …). Its object is one `/d/` phrase: one thing, or a group joined with a [phrase join](/joins). You can now name the act itself instead of only joining a list. On these verbs, `-n` does not mark a [name](proper-names.md#proper-name--n).

> `zazozon daledel van.`
>
> z-Azozon | d-apple | v-includes
>
> "Azozon adds an apple."

For an associative group (*Alazun and company*), put noun `-x` on the object as usual. `-x` on the verb itself is [collective](collectives.md#verbs-v).

**Compare with:** joining two acts uses a [verb join](verb-and-stance-joins.md#vp-clause-forms): `zazozon vowurol veruvol val` is *Azozon walks and runs*. `van` is itself an act, done to its object.

**Compare with:** *and then* between sentences uses clause [sequence](/clause-sequence#sequence) (`xan`, …), not `van`.

<!-- cheat-sheet: joins-hooks -->
| Clause sequence | List verb | Shared vowel move |
|-------------|---------------|-------------------|
| `xan` | `van` | add / include |
| `xen` | `ven` | one / choose |
| `xun` | `vun` | undo / refuse |

The `/x/` forms connect clauses and keep one speech act. Their `/v/` counterparts take an object and name an act on it. Prioritizing (`von`) has no clause sequence, and of the stacked vowels only `xaen` and `xuon` have one; the `/v/` forms follow the same series in the inventory below.

These are ordinary content verbs. To refer back to one of these acts you already named, use a whole-stem `-r` resume or say it again in full.

Stacked vowels combine the same four moves (`a` / `o` / `e` / `u`):

| Ageben | Use | English | Cue | Example |
|--------|-----|---------|-----|---------|
| **`van`** | hold the object in the set | *includes / adds* | `a` ≈ add (hold / inventory) | `zazozon daledel van` |
| **`ven`** | lock the object as the sole pick | *chooses (as the one choice)* | `e` ≈ choice (single pick) | `zazozon dedudal ven` |
| **`vaen`** | admit the object; more may follow | *picks (more picks may follow)* | `ae` ≈ add one, more may follow (open pick) | `zazozon dugedam vaen` |
| **`vun`** | reject the object | *denies / refuses* | `u` ≈ undo (take that member back) | `zazozon dulamul vun` |
| **`vuan`** | leave the object out of the set | *excludes* | `ua` ≈ undo + add (cut that member) | `zazozon duwedal vuan` |
| **`vuen`** | bar that one; the rest stay free | *bars (anything but)* | `ue` ≈ undo + choice (forbid that pick) | `zazozon dogudal vuen` |
| **`von`** | rank the object first | *prioritizes* | `o` ≈ rank (put this first) | `zazozon dabezul von` |
| **`vaon`** | put the object first in order | *starts with* | `ao` ≈ add + rank (begin here) | `zazozon durewem vaon` |
| **`voen`** | put the objects at the same rank | *equates / ties* | `oe` ≈ rank then choice (same height) | `zazozon dalazun dahelan dal voen` |
| **`vuon`** | rank the object lower | *deprioritizes* | `uo` ≈ undo + rank (drop this rank) | `zazozon dugedam vuon` |

English *refuse* vs *leave out*: `zazozon dumudel vun` (*Azozon refuses meat*) vs `zazozon dumudel vuan` (*Azozon excludes meat*). One locked choice vs an open pick: `zazozon duwedal ven` vs `zazozon duwedal vaen`. Rank vs route: `zazozon durewem von` (*prioritizes the workaround*: first by importance) vs `zazozon durewem vaon` (*starts with the workaround*: first in order).

### Practice {#intermediate-practice}

Short drills for Intermediate. Try each item before opening **Show answer**.

**Setting:** a roster desk

**New words:**

| English | Ageben | Cue |
|---------|--------|-----|
| *trophy* | `odoral` | 🏆: its abstract is *score* |

**Review:**

| English | Ageben |
|---------|--------|
| *Azozon* | `azozon` |
| *Alazun* | `alazun` |
| *Ahelan* | `ahelan` |
| *sandwich* | `edal` |
| *drink* | `vuwudal` |
| *table* | `edohel` |

#### English → Ageben {#intermediate-english-to-ageben}

**1.** *Azozon adds the trophy.*

::: details Show answer
`zazozon dodoral van.`

z-Azozon | d-trophy | v-includes
:::

**2.** *Alazun chooses the drink.*

::: details Show answer
`zalazun duwudal ven.`

z-Alazun | d-drink | v-choose
:::

**3.** *Ahelan excludes the sandwich.*

::: details Show answer
`zahelan dedal vuan.`

z-Ahelan | d-sandwich | v-excludes
:::

#### Ageben → English {#intermediate-ageben-to-english}

**1.** `zalazun dodoral ven.`

::: details Show answer
z-Alazun | d-trophy | v-choose

*Alazun chooses the trophy.* (as the one choice)
:::

**2.** `zazozon duwudal vun.`

::: details Show answer
z-Azozon | d-drink | v-denies

*Azozon refuses the drink.*
:::

**3.** `zahelan dedohel von.`

::: details Show answer
z-Ahelan | d-table | v-prioritizes

*Ahelan prioritizes the table.*
:::

#### Pick one {#intermediate-pick-one}

**1.** *Ahelan prioritizes the table.* `zahelan dedohel von.` or `zahelan dedohel van.`

::: details Show answer
`zahelan dedohel von.`

z-Ahelan | d-table | v-prioritizes

**`von`** ranks it first; **`van`** only adds it to the set.
:::

#### What changes {#intermediate-what-changes}

**1.** `zazozon dodoral vun.` / `zazozon dodoral vuan.`

::: details Show answer
z-Azozon | d-trophy | v-denies

z-Azozon | d-trophy | v-excludes

**`vun`** refuses it; **`vuan`** leaves it out of the set.
:::
