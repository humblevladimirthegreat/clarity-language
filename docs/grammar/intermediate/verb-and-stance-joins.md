# Joins on verbs and stances {#joins-on-verbs-and-stances}

The join vowels and endings from [joins](/joins) also join verbs (`/v/`), whole clauses (`/x/`), and stance words (`/th/`).

### Verb-phrase and clause forms {#vp-clause-forms}
<a id="vowels--endings"></a>
<a id="ending-senses-clause-joins"></a>

[Joins](/joins) already used `vam` and `xam`. The same vowels and **-l** / **-m** / **-r** endings work under `/v/`, `/x/`, and stance `/th/`. Clause **-n** forms are in [Sequence](/clause-sequence#sequence).

| | **-l** | **-m** | **-r** |
|---|--------|--------|--------|
| **a** | `val` / `xal` / `thal` | `vam` / `xam` / `tham` | `var` / `xar` / `thar` |
| **o** | `vol` / `xol` / `thol` | `vom` / `xom` / `thom` | `vor` / `xor` / `thor` |
| **u** | `vul` / `xul` / `thul` | `vum` / `xum` / `thum` | `vur` / `xur` / `thur` |
| **ao** | `vaol` / `xaol` / `thaol` | `vaom` / `xaom` / `thaom` | none |
| **ua** | `vual` / `xual` / `thual` | `vuam` / `xuam` / `thuam` | none |
| **uo** | `vuol` / `xuol` / `thuol` | `vuom` / `xuom` / `thuom` | none |
| **e** | `vel` / `xel` / `thel` | `vem` / `xem` / `them` | `ver` / `xer` / `ther` |
| **ae** | `vael` / `xael` / `thael` | `vaem` / `xaem` / `thaem` | none |
| **oe** | `voel` / `xoel` / `thoel` | `voem` / `xoem` / `thoem` | none |
| **ue** | `vuel` / `xuel` / `thuel` | `vuem` / `xuem` / `thuem` | none |

Stacked vowels take no **-r** under `/v/` or `/x/` (the *none* cells); only a stance join has stacked **-r**, as a fill-ask.

Each item in a verb-phrase join is a verb plus the words that go with it, and an item ends at its verb. One rule places every word: **a word before a verb belongs to that verb.** An `/h/`, `/d/`, or `/b/` word, or a hook with its `/b/`, between two joined verbs belongs to the verb after it. In `vowurol hadurom veruvol val`, *hastily* is on *run*, not *walk*. In the same way, an object or a `/b/` party between two verbs goes only with the second verb:

> `zazozon vowurol dahelan vayebel val.`
>
> z-Azozon | [v-walk | [d-Ahelan | v-see] | v-and]
>
> "Azozon walks and sees Ahelan."

> `zazozon vowurol bahelan vezuyol val.`
>
> z-Azozon | [v-walk | [b-Ahelan | v-tell] | v-and]
>
> "Azozon walks and talks to Ahelan."

The first item starts at the subject: the words between the subject and the first verb belong to the first verb. With no subject in the clause, the first item reaches back to the start of the clause.

> `zazozon dabedal vugudol vehohel val.`
>
> z-Azozon | [[d-popcorn | v-cooking] | v-sit | v-and]
>
> "Azozon cooked popcorn and sat."

> `zazozon hadurom vugudol veruvol val.`
>
> z-Azozon | [[h-haste | v-cooking] | v-run | v-and]
>
> "Azozon cooks hastily and runs."

Each verb takes its own recipient the same way, so one clause can name two:

> `zalazun bahelan vezuyol bazozon varal val.`
>
> z-Alazun | [[b-Ahelan | v-tell] | [b-Azozon | v-pay] | v-and]
>
> "Alazun talks to Ahelan and pays Azozon."

A hook with its `/b/` is an item word too:

> `zazozon vowurol al bahaham vezuvel val.`
>
> z-Azozon | [v-walk | [[in | b-locality] | v-sleep] | v-and]
>
> "Azozon walks, and sleeps in the village."

Words that every verb shares go in one of two places. **After the join**, a `/d/` object, a recipient `/b/`, or an `/h/` adverb is SHARED: every verb takes it. The join counts as *the verb*, so a recipient right after it is in its [usual place](/speech-moves#act-word-order).

> `zazozon vugudol vagedal val dabedal.`
>
> z-Azozon | [v-cooking | v-eat | v-and | d-popcorn]
>
> "Azozon cooks and eats popcorn."

> `zazozon vowurol veruvol val hahunom.`
>
> z-Azozon | [v-walk | v-run | v-and | h-intensity]
>
> "Azozon walks and runs, both intensely."

> `zalazun vezuyol varal val bazozon hahunom.`
>
> z-Alazun | [v-tell | v-pay | v-and | b-Azozon | h-intensity]
>
> "Alazun talks to Azozon and pays them, both intensely."

**Before the subject**, a word covers every verb. That is the place for scene-setting words (`h_15,30 zazozon vowurol veruvol val` *at 15:30 Azozon walks and runs*), and for a shared object when you want the verbs last. English works the same way: a fronted object is shared, and *cooked popcorn and ate* is not.

> `dabedal zazozon vugudol vagedal val.`
>
> d-popcorn | z-Azozon | [v-cooking | v-eat | v-and]
>
> "Popcorn, Azozon cooked and ate."

A verb that has its own object takes no shared object, and a verb that has its own recipient takes no shared recipient. After `dabedal vugudol vagedal val`, a shared object would give *cook* two objects, so it is not a sentence. Put the second object in its own verb's item instead (`dabedal vugudol daledel vagedal val`).

A [stance](/clause#stance-th) `/th/` word and an [intention adverb](/clause#intention-adverbs) are never item words, wherever they sit: like any stance word, each is about the whole claim. A `bl-` word right after an `/h/`, `/ɡ/`, or `/th/` word still completes that word.

With no subject, a statement with a shared object starts with its verbs (`vugudol vagedal val dabedal`), which is the default order for a command. Name the subject when the act could be misheard.

A rank join on verb phrases puts the acts in order of priority, so the earlier act is the one preferred: *would rather walk than run*.

> `zazozon vowurol veruvol vol.`
>
> z-Azozon | [v-walk | v-run | v-rank/more]
>
> "Azozon would rather walk than run."

Nothing is SHARED after a clause (`/x/`) join; each clause carries its own words.

Route **`ao`** keeps its [phrase meaning](rank-joins.md#route-ao) in both roles: the first item is where you start. Under `/v/` it is one subject doing steps in order; under `/x/` it fences a list of steps whose order is part of the message (a recipe, directions). Standalone **`xaol`** says the steps can go in any order.

> `zazozon vowurol veruvol vaol.`
>
> z-Azozon | [v-walk | v-run | v-in-order]
>
> "Azozon walks, then runs."

**Compare with:** clause **`xan`** ([sequence](/clause-sequence#sequence)) tells what happened next, one step at a time. **`xaol`** makes the order part of the claim (a recipe, directions): `A xaol B xaol C` says these steps go in this order. With rank **uo**, **`xuon`** steps backward: `A xuon B` says B happened before A.

A clause join with no clause before it is standalone, like `zal` *nothing*: `xal` means *nothing happened*, and open `xam` adds *as far as I know*.

> `xam.`
>
> x-and.open
>
> "Nothing happened, as far as I know."

All the clauses in an `/x/` join share one speech act. Any `/y/` word goes before the first clause only; the later clauses take the same act and leave `/y/` out.

> `zazozon vowurol xan zalazun veruvol.`
>
> [z-Azozon | v-walk | x-and-then | z-Alazun | v-run]
>
> "Azozon walks, and then Alazun runs."

> `zazozon vowurol xel zalazun veruvol xal zahelan vezuvel.`
>
> [[z-Azozon | v-walk | x-or-exactly-one | z-Alazun | v-run] | x-and | z-Ahelan | v-sleep]
>
> "Either Azozon walks or Alazun runs, and Ahelan sleeps." (only one of the first two)

### Stance joins {#stance-joins}

When English would deny or weigh **how you stand** toward a claim (*not because…*), put a `/th/` join word after the [stance](/clause#stance-th) words. The claim itself is untouched; the join works only on the stance words before it. (cue: same vowels as every other join.)

> `zazozon vowurol thahum blerulal thul.`
>
> z-Azozon | v-walk | [th-because | bl-rain] | th-not
>
> "Azozon walks, but not because of the rain."

The other join vowels work on stance words the same way they work on a phrase list ([recap](/joins#join-type-vowel-series)). A rank join says which ground matters most: the first stance word is the main one.

> `zazozon vowurol thahum blerulal thohem blalazun thol.`
>
> z-Azozon | v-walk | [th-because | bl-rain] | [th-if | bl-Alazun] | th-rank/more
>
> "Azozon walks mainly because of the rain, and also if Alazun is involved."

| Vowel | After stance words | Example reading |
|---|---|---|
| **o** | `thol` ranked, first is the main ground | *mainly because of the rain, also if Alazun* |
| **ao** | `thaol` in the order the grounds arose | *first because of the rain, then if Alazun* |
| **ua** | `thual` every ground but these | *on every ground but these two* |
| **uo** | `thuol` ranked, first is the weakest | *chiefly if Alazun, a little because of the rain* |
| **ae** | `thael` open list of grounds | *because of the rain, if Alazun, and maybe more* |
| **oe** | `thoel` equal weight | *the rain and the if-clause count the same* |
| **ue** | `thuel` any ground but these | *any ground but these two will do* |

Nothing is SHARED after an `/h/` or `/th/` join. To add a detail that covers the whole list, put a `/w/` word right before the join word.

**Compare with:** *Azozon does not walk* denies the event, so the join goes on the verb (`vowurol vul`), not on `/th/`.

#### Stance join before `blarl` {#stance-join-before-barl}

When the grounds are a whole clause (*not because Alazun runs*), the hinge takes **`blarl`** and the next sentence is the grounds ([hinges](/dependents#hinges)). That sentence comes last, so the join cannot go after it. Put the join word **between the hinge and `blarl`** instead. It closes the stance words before it as usual, and **`blarl`** still belongs to the hinge.

> `zazozon vowurol thahum thul blarl zalazun veruvol.`
>
> z-Azozon | v-walk | th-because | th-not | bl-that-clause | z-Alazun | v-run
>
> "Azozon walks, but not because Alazun runs."

Only one join fits there, and only when the last stance word before it is a hinge with no `/b/` yet. The same works for every join vowel and every hinge.

#### Standalone stance joins {#standalone-stance-joins}

When English would say how to take a claim without naming any grounds (*at face value*, *no judgment*, *all things considered*), put a `/th/` join with no stance words before it. It works like standalone `zal` *nothing*: the list of stance words is empty, and the join says what that empty stance means. The claim itself is untouched. (cue: same vowels as every other join.)

> `zazozon vowurol thul.`
>
> z-Azozon | v-walk | th-not
>
> "Azozon walks. No judgment."

In the table, *reason* means any grounds a stance word can give: a cause, a source, a likelihood, or a value.

| Vowel | **-l** | **-m** | **-r** |
|---|---|---|---|
| **a** | `thal` *at face value* | `tham` *I don't think there's more to it* | `thar` *for reasons I'm not stating* |
| **o** | `thol` *impartially* / *no decisive grounds* | `thom` *I don't lean either way* | `thor` *for one main reason, not named* |
| **u** | `thul` *no judgment* | `thum` *not weighing in* | `thur` *not for the reason you'd think* |
| **ao** | `thaol` *in no particular order* | `thaom` *not sure where to start* | question only |
| **ua** | `thual` *all things considered* | `thuam` *all known things considered* | question only |
| **uo** | `thuol` *no reason to object* | `thuom` *no objection that I know of* | question only |
| **e** | `thel` *no single reason to pick* | `them` *I'm not sure which reason it is* | `ther` *for some reason or other* |
| **ae** | `thael` *take it however you like* | `thaem` *any framing is fine, I think* | question only |
| **oe** | `thoel` *equally balanced* | `thoem` *equally balanced, I think* | question only |
| **ue** | `thuel` *anything goes* | `thuem` *anything goes, I think* | question only |

Outside a question, only the single-vowel **-r** cells are words. Under a question, a standalone **-r** stance join is a [fill-ask](/questions#fill-ask-r) for the grounds. Every vowel takes **-r** there.

> `yel thar zazozon vowurol.`
>
> y-question | th-why | z-Azozon | v-walk
>
> "On what grounds do you say Azozon walks?"

| Word | Question |
|---|---|
| `thar` | *Why do you say so?* / *On what grounds?* |
| `ther` | *For any reason?* |
| `thur` | *On what other grounds?* |
| `thaer` | *How do you want me to take this?* |
| `thuar` | *What's your overall take?* |
| `thuer` | *What reasons would you rule out?* |
| `thor` | *What's the main reason?* |
| `thaor` | *What would settle it?* |
| `thoer` | *What are you torn between?* |
| `thuor` | *What's your objection?* |

**Compare with:** `thul` *no judgment* withholds any stance; a *no chance* stance number is a stance that the claim is false. `thar` asks for the speaker's grounds, not what caused the event; for *Why does it happen?* use [`thahum blar`](/fill-ask-jobs#why).
