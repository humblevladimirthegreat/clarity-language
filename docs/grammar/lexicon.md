# Lexicon

Published roots, search by concrete English, abstract sense, packed **role English** (`v:see` on 👁️), Agebon form, overlay, or mnemonic. PoS letter and reference ending are added when you use a root in a sentence ([clause](./clause.md#role-letters), [word ending](./word-endings.md)). Morph uses packed role English for that role (`v-see` on `/v/`; still `z-eye` as a noun).

Closed special-vocabulary overlays (`sense_form` + PoS) are included in the same search ([Lexicon](./lexicon.md)).

## Respell an English name {#respell}

A published country already has an Agebon spelling (`azabanan` *Japan*). Any other English name of a person or place can be respelled the same way: the letters follow the English sound, and the root is long enough or clustered enough that it does not look like a dictionary word. Type a name to see the named citation. To keep the original spelling instead, write it in a [span](./spans.md#loans).

To wear a published root as your name in the examples, use **Use as my name** on a row below, or the picker on [word endings](./word-endings.md#named-n-beginner).
