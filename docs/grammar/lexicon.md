# Lexicon

Published emoji-seeded roots — search by concrete English, abstract sense, packed **role English** (`v:see` on 👁️), Agalan form, overlay, or mnemonic. PoS letter and reference ending are added when you use a root in a sentence ([clause](./clause.md#role-letters), [reference suffix](./reference-suffix.md)). Morph uses packed role English for that role (`v-see` on `/v/`; still `z-eye` as a noun).

Closed special-vocabulary overlays (`sense_form` + PoS) are included in the same search ([special vocabulary](./special-vocabulary.md#sense-form)).
