# Lexicon

Published emoji-seeded roots — search by literal English, metaphorical sense, packed **role English** (`v:see` on 👁️), Agalan form, overlay, or mnemonic. PoS letter and reference ending are added when you use a root in a sentence ([core](./core.md#role-letters), [reference suffix](./reference-suffix.md)). Role English is lookup packaging only; morph still uses the sense-root (`v-eye`, not `v-see`).

Closed special-vocabulary overlays (`sense_form` + PoS) are included in the same search ([special vocabulary](./special-vocabulary.md#sense-form)).
