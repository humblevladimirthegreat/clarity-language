# Stacked markers, from the end first {#stacked-markers-from-the-end-first}

### From the end: end-relative ordinal marker **`#-`** / **`uo`** {#from-the-end-end-relative-ordinal-marker-uo}
<a id="from-the-end"></a>
<a id="nth-from-the-end"></a>
<a id="negative-ordinal"></a>

To count **from the last place** (*penultimate*, *starting with the last one*), use marker **`uo`** (writing **`#-`**). Count back within the **same generation** (no exponent). Speech uses the marker vowels in u-first order: `#-` is spelled and pronounced **ruo** before its digit syllables and ending (e.g. `gruodol`). The number’s role-letter-plus-`r` cluster distinguishes it from join **`uo`**.

> `zanal gruodol.`
> z-book | g-2nd-from-end
>
> "There is a second-to-last book."

<!-- cheat-sheet: numbers -->
| Form | Reading |
|------|---------|
| **`g#-1`** | *1st from the end*: same referent as last place, framed as counting from the end (English *Starting with the last one*) |
| **`g#-2`** | *2nd from the end* / *penultimate* |
| **`g#-3`** | *3rd from the end* / *antepenultimate* |
| **`g~#-2`** | *about 2nd from the end* |
| **`g@#-2`** | named / titled *penultimate* (etc.) |
| **`g=#-2`** | resume that prior end-relative place |
| **`g#-`** | unspecified end-relative rank ([zero groups](/digitless-exponents#digitless)) |

`grodol` = numbered *2nd* (from the start); `gruodol` = *2nd from the end*. Last place as a landmark is a digitless exponent ([digitless and exponents](/digitless-exponents)).

On `/v/`, `/h/`, `/y/`, and `/x/`:

| Form | Reading |
|------|---------|
| **`h#-2`** | *for the 2nd-from-last time* / *the penultimate time* |
| **`v#-2`** | *place / come in 2nd from the end* |
| **`y#-2`** | *Penultimate!* / *Second from last!* |
| **`x#-1`** | *1st-from-end point:* / *Starting with the last one:* |
| **`x#-2`** | *2nd-from-end point:* / *penultimate item:* |

### Stacked markers {#stacked-markers}

When a number identity needs two marker vowels, write the symbols in their conventional order and pronounce the vowels with **`u` first**. The letter spelling and speech therefore use **rue** for a negative digit-string label (`#_`) and **rua** for a symmetric error bound (`+-`). A negative label identifies a value below zero, such as a basement floor; `+-N` gives an uncertainty of plus or minus N. These stacked forms work with the ordinary number endings.

Write the role letter, symbol stack, then digits: `gruebal` labels a floor numbered −1; `gruagel` gives an uncertainty of ±3.

<!-- cheat-sheet: numbers -->
| Symbol stack | Spelled and spoken marker | Use |
|--------------|---------------------------|-----|
| **`#_`** | **r-u-e** | A digit-string label whose value is negative (for example, a below-ground floor label). |
| **`+-`** | **r-u-a** | A symmetric error bound of ±N. |
| **`#-`** | **r-u-o** | Count from the end ([from the end](#from-the-end)). |
| **`_#`** | **r-o-e** | A calendar date, day then month then year ([time](/digit-strings#time)). |

These four are the whole set. The other two standard stacks, **r-a-o** and **r-a-e**, are not used. Labels carry no sign (a dialing code `+44` is written `_44`), and a count and a rank are separate markers on separate words.

### Ambient magnitude (casual)
<a id="ambient-magnitude"></a>

In careful writing, an omitted exponent means ones-place (`gragel` = 3). Prefer writing the exponent when the magnitude matters.

In casual measure-heavy talk, a stretch of conversation may set an **ambient** order of magnitude (often an engineering `e3` / `e6` / …). Numbers written without an exponent are then heard at that magnitude until you cancel it. A [topic change](/topic#topic-resets) starts a new stretch, so bare numbers go back to ones until an ambient decade is set again.

**Writing `e0`** says *ones* outright and cancels the ambient magnitude:

| In a stretch where ambient OoM = 3 | Reading |
|------------------------------------|---------|
| **`g+3`** (casual ambient) | *three at ambient* → often 3×10³ |
| **`g+3e3`** | *three at 10³* (exp explicit) |
| **`g+3e0`** | *three at OoM 0* → 3×10⁰ = **3** (break out of ambient) |
| **`g+e0`** | *ones-band amount* (bare OoM), not ambient thousands |

Write **`Ne0`** (any nonzero mantissa **N**) to insist on ones. Formal prose that never sets an ambient magnitude rarely needs **`e0`**: leave it out when ones are already clear.
