# Stacked markers, from the end first {#stacked-markers-from-the-end-first}

To name a place counted from the last one, as in *second-to-last*, a number takes the end-relative marker. That marker is one of four stacks of two marker symbols, which also cover labels below zero, error bounds of plus or minus N, and calendar dates.

### From the end: end-relative ordinal marker **`#-`** / **`uo`** {#from-the-end-end-relative-ordinal-marker-uo}
<a id="from-the-end"></a>
<a id="nth-from-the-end"></a>
<a id="negative-ordinal"></a>

English counts from the last place with words like *penultimate* and phrases like *starting with the last one*. Ageben gives the number the marker **`uo`**, written `#-`, and counts back within the same generation (among peers at one level, so the number takes no exponent). Speech uses the marker vowels in u-first order: `#-` is spelled and pronounced **ruo** before its digit syllables and ending (e.g. `gruodol`). Because the role letter is followed by `r`, a listener can tell this number from the join word `uo`.

> `zanal gruodol.`
> z-book | g-2nd-from-end
>
> "There is a second-to-last book."

<!-- cheat-sheet: numbers -->
| Form | Reading |
|------|---------|
| **`g#-1`** | *1st from the end*: same referent as last place, framed as counting from the end (English *Starting with the last one*) |
| **`g#-2`** | *2nd from the end* / *penultimate* |
| **`g#-3`** | *3rd from the end* / *antepenultimate* |
| **`g~#-2`** | *about 2nd from the end* |
| **`g@#-2`** | named / titled *penultimate* (etc.) |
| **`g=#-2`** | resume that prior end-relative place |
| **`g#-`** | unspecified end-relative rank ([zero groups](/digitless-exponents#digitless)) |

`grodol` = numbered *2nd* (from the start); `gruodol` = *2nd from the end*. Last place as a landmark is a digitless exponent ([digitless and exponents](/digitless-exponents)).

On `/v/`, `/h/`, `/y/`, and `/x/`:

| Form | Reading |
|------|---------|
| **`h#-2`** | *for the 2nd-from-last time* / *the penultimate time* |
| **`v#-2`** | *place / come in 2nd from the end* |
| **`y#-2`** | *Penultimate!* / *Second from last!* |
| **`x#-1`** | *1st-from-end point:* / *Starting with the last one:* |
| **`x#-2`** | *2nd-from-end point:* / *penultimate item:* |

### Stacked markers {#stacked-markers}

Some numbers need two marks at once: a label for a value below zero, such as a basement floor, or a value with an uncertainty of plus or minus N, written `+-N`. Ageben writes both marker symbols in their conventional order and pronounces the vowels with `u` first. The spelling and speech therefore use **rue** for a negative digit-string label (`#_`) and **rua** for a symmetric error bound (`+-`). These stacked forms take the ordinary number endings, so a floor label or an error bound works as one number word.

Write the role letter, symbol stack, then digits: `gruebal` labels a floor numbered −1; `gruagel` gives an uncertainty of ±3.

<!-- cheat-sheet: numbers -->
| Symbol stack | Spelled and spoken marker | Use |
|--------------|---------------------------|-----|
| **`#_`** | **r-u-e** | A digit-string label whose value is negative (for example, a below-ground floor label). |
| **`+-`** | **r-u-a** | A symmetric error bound of ±N. |
| **`#-`** | **r-u-o** | Count from the end ([from the end](#from-the-end)). |
| **`_#`** | **r-o-e** | A calendar date, day then month then year ([time](/digit-strings#time)). |

These four are the whole set. The other two standard stacks, **r-a-o** and **r-a-e**, are not used. Labels carry no sign (a dialing code `+44` is written `_44`), and a count and a rank are separate markers on separate words.

Short drills for Advanced. Try each item before opening **Show answer**.

**Setting:** a parking garage

#### English → Ageben {#advanced-english-to-ageben}

**1.** *A second-to-last car stands.*

::: details Show answer
`zugaval gruodol vuzuvel.`

[z-car | g-2nd-from-end] | v-stand
:::

**2.** *Ahelan sees parking −2.* (a label below zero)

::: details Show answer
`zahelan debahal gruedol vayebel.`

z-Ahelan | [d-parking | g-negative-label-2] | v-see
:::

**3.** *Alazun sees three cars, give or take one.*

::: details Show answer
`zalazun dugavalx gragel gruabal vayebel.`

z-Alazun | [d-car-x | g-three | g-plus-minus-1] | v-see
:::

#### Ageben → English {#advanced-ageben-to-english}

**1.** `zebahal gruodol.`

::: details Show answer
z-parking | g-2nd-from-end

*There is a second-to-last parking stall.*
:::

**2.** `x#-2 zazozon vehohel.`

::: details Show answer
🔊 `xruodol zazozon vehohel.`

x-2nd-from-end.short | z-Azozon | v-sit

*Penultimate item: Azozon sits.*
:::

**3.** `zugaval hruodol vehohel.`

::: details Show answer
z-car | h-2nd-from-end | v-sit

*The car sits here for the second-to-last time.*
:::

#### Pick one {#advanced-pick-one}

**1.** *There is a second car.* `zugaval grodol.` or `zugaval gruodol.`

::: details Show answer
`zugaval grodol.`

z-car | g-2nd

**`ro`** counts from the start; **`ruo`** would be second from the end.
:::

**2.** *Azozon sees parking −1.* (a floor label below zero) `zazozon debahal gruebal vayebel.` or `zazozon debahal gruobal vayebel.`

::: details Show answer
`zazozon debahal gruebal vayebel.`

z-Azozon | [d-parking | g-negative-label-1] | v-see

**`rue`** (`#_`) labels a value below zero; **`ruo`** (`#-`) would count from the end: the last stall.
:::
