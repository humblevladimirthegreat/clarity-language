# Join limits {#join-limits}

Use this page to check a join word before you write it. A join's role letter decides which endings it can take, and a short list of limits holds for every join, whatever its role. The reference table at the end lists rare readings that keep a meaning with any number of items, and how to mix two joins by nesting.

### Allowed joins by role letter {#allowed-joins-by-pos}
<a id="phrase-reserved-forms"></a>

A join has at most two vowels. Which endings it can take depends on its role letter:

| Role | Join endings | Notes |
|-------|----------------|-------|
| `/z/` `/d/` `/b/` | `-l` / `-m` / `-n` / `-r` (`-r` only on `a` / `o` / `e` / `u`), `-rx` | phrase lists; `-n` is a named package; `-rx` is an [unnamed group](/joins#unspecified-member-r-phrase) |
| `/w/` | none | not a phrase list: the only `/w/` before a join word is [`wubam`](/list-structure#respectively), with `-l` or `-m` |
| `/ɡ/` `/h/` | same series as restrictors allow | [restrictors](/more-occasions#defined-core-full); `-n` forms are [join-relations](/join-relations#join-relations) |
| `/v/` | `-l` / `-m` / `-r`, each with `-x` | `-x` is one [shared act](/collectives#verbs-v); parallel `-n` forms are [list verbs](/list-verbs#list-verbs) |
| `/th/` | `-l` / `-m` / `-r` (`-r` only on `a` / `o` / `e` / `u`) | [stance joins](/verb-and-stance-joins#stance-joins) on stance words (*not because…*) |
| `/x/` | `-l` / `-m` / `-n` / `-r` (`-r` only on `a` / `o` / `e` / `u`) | between clauses, not after them ([clause joins](/joins#clause-joins)); forms: [Joins on verbs and stances](/verb-and-stance-joins#vp-clause-forms) |

Word shape: [phonology](/phonotactics#phonotactics).

### Constraints

These limits apply to every join.

| Limit | Pattern |
|-------|---------|
| Each role once per chain | one subject, object, plain `/b/` recipient, `/ɡ/` stack, or `/w/` / `/h/` / `/th/` unit; hosted `/b/` stays on its `/ɡ/`, `/h/`, or `/th/` |
| Matching role letter | every item head and the join share the first letter |
| One right-close per flat list | nest as [fence nesting](/list-structure#fence-nesting) |
| Shared modifiers | only immediately after each join |
| Phrase `-r` | only `…ar` / `…er` / `…or` / `…ur`, plus `-x` for a group on `/z/` `/d/` `/b/` |
| Join `-x` | after `-r` on `/z/` `/d/` `/b/` (a group); after any ending on `/v/` (one shared act) |
| Verb+object packages | verb-phrase `/v/`; full sentences use `/x/` ([forms](/verb-and-stance-joins#vp-clause-forms)) |
| Revising one item | in-clause *including* / *rather* / *instead* / *except* are [hooks](/hooks) |
| Several manners on `/h/` `/w/` | juxtaposition (`hadurol halozul`) |

**Compare with:** prefix-less `al` / `am` / … are [hooks](/hooks). Under `/h/` `/w/`, the unit is a [restrictor](/restrictors), not sibling *and*. To keep a small list inside a bigger one of the same role, wrap it in a [scope island](/scope-islands#scope-islands).

*Because* / *if* use `/th/` plus `/b/` [`blarl`](/dependents#hinges). An `/h/` or `/th/` word between the items of a noun, adjective, or `/b/` list does not end the list. For how far an `/h/` reaches in a verb list, see [Verb-phrase and clause forms](/verb-and-stance-joins#vp-clause-forms). Each item of a clause join is a full clause.

### Practice {#advanced-practice}

Short drills for Advanced. Try each item before opening **Show answer**.

**Setting:** a post office

**New words:**

| English | Ageben | Cue |
|---------|--------|-----|
| *envelope* | `enonal` | ✉️ |
| *box* | `ubogal` | 📦 |

**Review:**

| English | Ageben |
|---------|--------|
| *Azozon* | `azozon` |
| *Alazun* | `alazun` |
| *Ahelan* | `ahelan` |
| *page* | `obonol` |
| *write* | `varuyol` |
| *see* | `vayebel` |
| *umbrella* | `omobul` |
| *clipboard* | `egowal` |
| *calendar* | `agorol` |

#### English → Ageben {#advanced-english-to-ageben}

**1.** *Alazun writes something other than a page.*

::: details Show answer
`zalazun dobonol dur varuyol.`

z-Alazun | [d-page | d-something-else] | v-write
:::

**2.** *Ahelan sees one of the box and the envelope.* (which one is not said)

::: details Show answer
`zahelan dubogal denonal dar vayebel.`

z-Ahelan | [d-box | d-envelope | d-something] | v-see
:::

**3.** *Azozon and Alazun see the umbrella and the box.*

::: details Show answer
`zazozon zalazun zal domobul dubogal dal vayebel.`

[z-Azozon | z-Alazun | z-and] | [d-umbrella | d-box | d-and] | v-see

Each list takes its own join, with the role letter of its items.
:::

#### Ageben → English {#advanced-ageben-to-english}

**1.** `zenonal zubogal zur.`

::: details Show answer
[z-envelope | z-box | z-something-else]

*something other than the envelope and the box*
:::

**2.** `zalazun zahelan zar domobul vayebel.`

::: details Show answer
[z-Alazun | z-Ahelan | z-something] | d-umbrella | v-see

*Alazun or Ahelan sees the umbrella* (one of them; which is not said)
:::

**3.** `zegowal zagorol zomobul zer.`

::: details Show answer
[z-clipboard | z-calendar | z-umbrella | z-anything]

*any of the clipboard, the calendar, or the umbrella is fine*
:::

#### Pick one {#advanced-pick-one}

**1.** *Azozon sees something other than the box.* `zazozon dubogal dur vayebel.` or `zazozon dubogal dul vayebel.`

::: details Show answer
`zazozon dubogal dur vayebel.`

z-Azozon | [d-box | d-something-else] | v-see

**-r** on **u** is *something other than*; **…ul** denies the box.
:::

#### Fix it {#advanced-fix-it}

**1.** *Alazun sees the envelope and the box.* <!-- lint: error -->`zalazun denonal zubogal dal vayebel.`

::: details Show answer
`zalazun denonal dubogal dal vayebel.`

z-Alazun | [d-envelope | d-box | d-and] | v-see

Every item shares the join's role letter: the box is an object, so `dubogal`, not `zubogal`.
:::

### Rare arities and edge readings

Most other phrase joins need two or more items. These edge readings keep a defined sense with any number of items, or mix two joins by nesting.

| Ageben | Use | English |
|--------|-----|---------|
| `…ul` / `…um` / `…un` | deny with any number of items | standalone *no*; one item *not X*; multi *none of* |
| `…ar` / `…er` / `…or` / `…ur` | unspecified member with any number of items | [unspecified `-r`](/joins#unspecified-member-r-phrase) |
| `…oen` / `…on` / `…an` standalone | fixed empty rank / named empty | *it's a draw*; *no favorite* (fixed); *null* / *void* |
| `…ual` / `…uel` standalone | empty invert | *everything*; *anything (goes)* |
| `zeyel` vs `zeyel zar` | content `-l` vs join `-r` | *a person* vs *some person, unknown who* |
| `A B C zer` vs `… zor` | menu vs rank unspecified | any of them is fine vs pick by ranking |
| `A B zar` / `zur` / `zual` | among / leftover / invert | some one among; some one other than; *everything but* |
| `A B zol` vs `A B zaol` | rank vs [route](/rank-joins#route-ao) | A matters more than B vs A, then B |

> `zedudal zogudal zowulal zer.`
>
> [z-tea | z-coffee | z-water | z-anything]
>
> "any of tea, coffee, or water is fine."

**For *except*, use:** hook `ul` / `um` ([hooks](/hooks)). Prefixed `zur` is unspecified *something else*. Nest when you need a rare mix (pick one of a closed list, but the pick is optional: `zedudal zogudal zel zem`).
