# Join islands {#join-islands-and-role-grid}

### Scope islands {#scope-islands-join}

A join takes every same-role item before it. When English groups a small list inside a bigger one of the same role (*Azozon and (just water)*), wrap the small list and its join in **`{ … }`**, called a scope island. The join inside the island takes members only from between those marks. One island per clause; material outside needs its own outer join. An island holds at most one phrase and may close partway through it ([scope islands](/span-mention#scope-islands)).

| Agebon | English |
|--------|---------|
| `zazozon { zowulal zal } zam` | *Azozon and (just water)* |
| `zazozon { zal } zam` | *Azozon and nothing* |
| `{ zowulal zal }` | *just water* (alone in the slot) |

> `zazozon { zowulal zal } zam.`
>
> [z-Azozon | SCOPE[z-water | z-and] | z-and.open]
>
> "Azozon and (just water)."

**Compare with:** an island limits only what a join or an `/h/` word covers.

### Named phrase **`-n`**
<a id="named-list"></a>
<a id="named--conventional-ending-phrase-level-all-join-vowels"></a>

When a list is a familiar set phrase (*Stop–Drop–Roll*), end its join with **-n** (under `/z/`, `/d/`, or `/b/`). The **-n** names the whole list as one title, the way it names a person ([titled phrases](/proper-names#titled-phrases)). Members keep their usual endings unless a member is itself a name.

> `zobodel zubudal zan.`
>
> NAME[z-bread | z-butter | z-and]
>
> "bread and butter" (the familiar bundle)

Standalone **…an** (no items) is *null* / *void*. Under `/ɡ/` `/h/`, **-n** forms join-derived relations; see [Join across roles](/join-across-roles#join-relations).

**Compare with:** clause **`xan`** is *and then*, not a named list.

### Allowed joins by role letter {#allowed-joins-by-pos}
<a id="phrase-reserved-forms"></a>

A join has at most two vowels. Which endings it can take depends on its role letter:

| Role | Join endings | Notes |
|-------|----------------|-------|
| `/z/` `/d/` `/b/` | **-l** / **-m** / **-n** / **-r** ( **-r** only on **a** / **o** / **e** / **u**), **-rx** | phrase lists; **-n** is a named package; **-rx** is an [unnamed group](/joins#unspecified-member-r-phrase) |
| `/w/` | none | not a phrase list: the only `/w/` before a join word is [`wubam`](/rank-joins#respectively), with **-l** or **-m** |
| `/ɡ/` `/h/` | same series as restrictors allow | [restrictors](/more-occasions#defined-core-full); **-n** forms are [join-relations](/join-across-roles#join-relations) |
| `/v/` | **-l** / **-m** / **-r**, each with **-x** | **-x** is one [shared act](/collectives#verbs-v); parallel **-n** forms are [join-act verbs](/join-across-roles#join-act-verbs) |
| `/th/` | **-l** / **-m** / **-r** ( **-r** only on **a** / **o** / **e** / **u**) | [stance joins](/join-across-roles#stance-joins) on stance words (*not because…*) |
| `/x/` | **-l** / **-m** / **-n** / **-r** ( **-r** only on **a** / **o** / **e** / **u**) | between clauses, not after them ([clause joins](/joins#clause-joins)); forms: [Join across roles](/join-across-roles) |

Word shape: [phonology](/phonotactics#phonotactics).

### Constraints

These limits apply to every join.

| Limit | Pattern |
|-------|---------|
| One slot per chain | one subject, object, plain `/b/` recipient, `/ɡ/` stack, or `/w/` / `/h/` / `/th/` unit; hosted `/b/` stays on its `/ɡ/`, `/h/`, or `/th/` |
| Matching role letter | every item head and the join share the first letter |
| One right-close per flat list | nest as [fence nesting](/rank-joins#fence-nesting) |
| Shared modifiers | only immediately after each join |
| Phrase **-r** | only **…ar** / **…or** / **…er** / **…ur**, plus **-x** for a group on `/z/` `/d/` `/b/` |
| Join **-x** | after **-r** on `/z/` `/d/` `/b/` (a group); after any ending on `/v/` (one shared act) |
| Verb+object packages | verb-phrase `/v/`; full sentences use `/x/` ([forms](/join-across-roles)) |
| Revising one item | in-clause *including* / *rather* / *instead* / *except* are [hooks](/hooks) |
| Several manners on `/h/` `/w/` | juxtaposition (`hadurol halozul`) |

**Compare with:** prefix-less **`al`** / **`am`** / … are [hooks](/hooks). Under `/h/` `/w/`, the unit is a [restrictor](/restrictors), not sibling *and*.

*Because* / *if* use `/th/` plus `/b/` [**`blarl`**](/dependents#poles). An `/h/` or `/th/` word between the items of a noun, adjective, or `/b/` list does not end the list. For how far an `/h/` reaches in a verb list, see [VP and clause forms](/vp-clause-forms#vp-clause-forms). Each item of a clause join is a full clause.

### Rare arities and edge readings

Most other phrase joins need two or more items. These edge readings keep a defined sense at every arity, or mix two joins by nesting.

| Agebon | Use | English |
|--------|-----|---------|
| **…ul** / **…um** / **…un** | deny at every arity | standalone *no*; one item *not X*; multi *none of* |
| **…ar** / **…or** / **…er** / **…ur** | unspecified member at every arity | [unspecified **-r**](/joins#unspecified-member-r-phrase) |
| **…oen** / **…en** / **…an** standalone | stock empty rank / named empty | *it's a draw*; *no favorite* (stock); *null* / *void* |
| **…ual** / **…uol** standalone | empty invert | *everything*; *anything (goes)* |
| `zeyel` vs `zeyel zar` | content **-l** vs join **-r** | *a person* vs *some person, unknown who* |
| `A B C zer` vs `… zor` | menu vs rank unspecified | any of them is fine vs pick by ranking |
| `A B zar` / `zur` / `zual` | among / leftover / invert | some one among; some one other than; *everything but* |
| `A B zol` vs `A B zaol` | rank vs [sequence](/rank-joins#sequence-ao) | A matters more than B vs A, then B |

> `zedudal zogudal zowulal zer.`
>
> [z-tea | z-coffee | z-water | z-anything]
>
> "any of tea, coffee, or water is fine."

**For *except*, use:** hook **`ul`** / **`um`** ([hooks](/hooks)). Prefixed **`zur`** is unspecified *something else*. Nest when you need a rare mix (pick one of a closed list, but the pick is optional: `zedudal zogudal zel zem`).
