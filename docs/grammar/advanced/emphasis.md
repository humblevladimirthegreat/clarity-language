# Emphasis and audible start {#emphasis-and-audible-start}

### English emphasis and clefts {#english-emphasis}

English often moves or stresses a word to single it out: *It's a cat that Uzozen sees*, *It was Uzozen who saw the cat*, or a stressed *Uzozen saw the cat*. Agebon word order carries no emphasis. A sentence's usual order is set by its [speech act](/speech-moves#act-word-order), and any other order means exactly the same (with joined verbs, a word's place says which verb it goes with, [verb-phrase forms](/join-across-roles#vp-clause-forms)). When you translate, ask what the English emphasis is doing.

If the English sets one person or thing against others (*Uzozen, not someone else*), put the [contrastive focus](/speech-acts#tone-marks) mark **`&`** on that word.

> `zuzozen &dagozol vawebol.`
>
> z-Uzozen | &d-cat | v-see
>
> "It's a cat that Uzozen sees." (not something else)

If the English only puts the new part first, with no others to set it against (answering *What does Uzozen see?* with *It's a cat that Uzozen sees*), write the plain sentence. What came before already shows which part is new.

> `zuzozen dagozol vawebol.`
>
> z-Uzozen | d-cat | v-see
>
> "Uzozen sees a cat."

Translating the other way, an Agebon sentence in an unusual order (a line fitted to a tune, say) becomes a plain English sentence.

<!-- cheat-sheet: word-shape-clause -->
| Agebon | Use | English |
|--------|-----|---------|
| `zuzozen dagozol vawebol.` | plain | *Uzozen sees a cat.* / *It's a cat that Uzozen sees.* (answering *what?*) |
| `&zuzozen dagozol vawebol.` | subject contrasted | *It was Uzozen who saw the cat.* |
| `zuzozen &dagozol vawebol.` | object contrasted | *It's a cat that Uzozen sees.* (not something else) |
| `zuzozen dagozol &vawebol.` | act contrasted | *Uzozen sees the cat.* (rather than doing something else to it) |

**Compare with:** what the whole conversation is about is the [topic](/topic#topic), set only by an `/x/` word.

### Starting a sentence audibly {#audible-start}

In writing, the period shows where one sentence ends and the next begins. In speech, a listener may miss that pause, especially in singing or with free word order. When that could happen, begin the next sentence with a word that can only start one: *yes* / *no*, the name of the person you address, or the statement word `yal`.

::: details Show answer

#### What changes {#advanced-what-changes}

**1.** `zuzozen daboval vawebol.` / `&zuzozen daboval vawebol.`

::: details Show answer
z-Uzozen | d-balloon | v-see

&z-Uzozen | d-balloon | v-see

The first is plain *Uzozen sees a balloon*; the second stresses Uzozen: *it was Uzozen, not someone else*.
:::

**2.** `zahelan dudoral vawebol.` / `zahelan dudoral &vawebol.`

::: details Show answer
z-Ahelan | d-drum | v-see

z-Ahelan | d-drum | &v-see

The second contrasts the act: Ahelan *sees* the drum, as opposed to doing something else to it.
:::
