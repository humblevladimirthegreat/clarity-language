# Sounds and spelling cheat sheet {#sounds-spelling-cheat-sheet}

A quick look at [phonology](../phonology.md) on one page. Nothing here is new: each row links to the section that teaches it. Stage: **B** Beginner, **I** Intermediate, **A** Advanced.

## Letters {#letters}

Each letter has one sound, and native text is lowercase. Two vowels in a row are two syllables. `th` is one letter written with two characters, and there is no `t`. `y` is always a consonant.

### Vowels {#vowels}

| Letter | Say | Like | Stage |
|--------|-----|------|-------|
| [`e`](../phonology.md#vowels) | /e̞/ | *bet* | B |
| [`u`](../phonology.md#vowels) | /u/ | *boot* (no glide) | B |
| [`o`](../phonology.md#vowels) | /o̞/ | *Cambodia* (no glide) | B |
| [`a`](../phonology.md#vowels) | /ä/ | *spa* | B |

### Consonants and their names {#consonants}

The name is what you say when you [spell a word aloud](../phonology.md#letter-names). The unvoiced sound is fine for style; prefer the voiced one so you can hold a note.

| Letter | Say | Like | Unvoiced | Name | Stage |
|--------|-----|------|----------|------|-------|
| [`b`](../phonology.md#consonants) | /b/ | *be* | /p/ | `be` | B |
| `m` | /m/ | *me* | | `me` | B |
| `w` | /w/ | *we* | | `we` | B |
| `v` | /v/ | *vie* | /f/ | `vu` | B |
| `d` | /d/ | *do* | /t/ | `da` | B |
| `n` | /n/ | *no* | | `nu` | B |
| `z` | /z/ | *zoo* | /s/ | `ze` | B |
| `l` | /l/ | *lie* | | `lo` | B |
| `r` | /ɹ/ | *red* | | `ro` | B |
| `y` | /j/ | *yes* | | `ya` | B |
| `g` | /ɡ/ | *go* | /k/ | `ga` | B |
| `h` | /ɦ/ | *ahead* | /h/ | `hu` | B |
| `th` | /ð/ | *this* | /θ/ | `tha` | B |
| `x` | /ʒ/ | *vision* (not English *x*) | /ʃ/ | `xe` | B |

The vowels name themselves (`e`, `u`, `o`, `a`). Pause between names: `agadu` is `a` `ga` `a` `da` `a`. A letter you talk about in a clause is a [mention](../spans.md#mention), read by its name.

## Word shape {#word-shape}

### Edges and syllables {#edges}

| Rule | Example | Stage |
|------|---------|-------|
| [A content word ends in **-l**, **-m**, **-n**, or **-r**](../phonology.md#word-edges), the audible end | `azawan` = *a-za-wan* | B |
| [Inside a word, a consonant starts a syllable](../phonology.md#word-edges) and never closes one | `odogal` = *o-do-gal* | B |
| [Roots are vowel-first](../phonology.md#phonotactics): **V(CV)+** | `zubuhel` = `z` + `ubuhe` + **-l** | I |

### Parts of a word, in order {#parts-in-order}

| Part | What it is | Stage |
|------|------------|-------|
| [Role letter](../phonology.md#phonotactics) | first letter: the word's job in the clause | I |
| Optional `l` after `/ɡ/` | [adjective before the noun](../clause.md#left-bound-adjectives) | I |
| Root(s) | vowel-first; a [dictionary compound](../phonology.md#phonotactics) is one long root (`ebedalahaza` *bedroom*); a root after a root is joined by mid-word `x` ([x-compounds](../x-compounds.md)) | I |
| Mid-word `th` | the stance seam: [scope](../predication.md#label-scope), [sakes](../sakes.md), [viewpoint](../roles.md#viewpoint-laterals) | I |
| **-l** / **-m** / **-n** / **-r** | the [word ending](../word-endings.md) | B |
| **-ln** | [one of a name](../word-endings.md#name-instance--ln) | I |
| **-x** | [plural / associates](../plurality.md), after the ending | B |
| **-rl** / **-rm** | [stand-in or pinned resume](../dependents.md#dependent-clauses) | I |
| **-rth** | [pointing back](../dependents.md#stand-in-back): the only word-final `th` | I |

Word-initial `x` is the [continue](../dependents.md#continue-x) prefix, not a compound seam.

## Singing {#singing}

| Feature | What it means | Stage |
|---------|---------------|-------|
| [Pure vowels, one per letter](../phonology.md#singability-constraints) | stacked vowels are separate syllables; no glides | A |
| [No stress in spelling](../phonology.md#singability-constraints) | rhythm may stress a beat | A |
| [Voiced preferred](../phonology.md#singability-constraints) | unvoiced is style only | A |
| [On a high note](../phonology.md#singability-constraints) | **u** may open toward [ʊ]; it is still **u** | A |
| [Legal clusters](../phonology.md#singability-constraints) | `gl-`; role letter + `r` (number) or + `w` (tag); `-lx` `-mx` `-nx` `-rx`; `-ln`; `-rl` `-rm` `-rth` | A |
