# Restrictors and spans cheat sheet {#restrictors-spans-cheat-sheet}

A quick look at [restrictors](../restrictors.md) and [spans](../spans.md) on one page. Nothing here is new: each row links to the section that teaches it. Stage: **B** Beginner, **I** Intermediate, **A** Advanced.

## When a claim counts {#restrictors}

List the **occasions** (times or cases) in the adverb slot `/h/`, then end with a restrictor. The occasion words and the restrictor are one unit. Put the same restrictor on `/w/` right before an adjective to limit only that adjective; `/h/` limits the whole clause.

### The core words {#core}

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [Only when](../restrictors.md#only-when-never-hal) | `zazawan vowogal herehel hal.` | *Azawan walks only when raining.* | B |
| [Never](../restrictors.md#only-when-never-hal): no occasion, closed | `zalahen vowogal hal.` | *Alahen never walks.* | B |
| [Always](../restrictors.md#always-hual) | `zahaben vezehel hual.` | *Ahaben always sings.* | B |
| [Usually](../restrictors.md#always-hual): open | `zahaben vezehel huam.` | *Ahaben usually sings.* | B |
| [Always except](../restrictors.md#always-hual) | `zazawan vowogal herehel hual.` | *Azawan always walks except when raining.* | B |
| [Sometimes](../restrictors.md#sometimes-anytime-some-other-time) | `zalahen varahal har.` | *Alahen runs sometimes.* | B |
| [Anytime](../restrictors.md#sometimes-anytime-some-other-time) | `zahaben vowogal hor.` | *Ahaben walks anytime.* | B |
| [Some other time](../restrictors.md#sometimes-anytime-some-other-time) | `zahaben vowogal hur.` | *Ahaben walks at some other time.* | B |
| [When and at other times too](../restrictors.md#listed-occasions-open): open | `zazawan vezebal herehel hanadal ham.` | *Azawan sleeps when raining and at night, among other times.* | B |
| [Only the adjective](../restrictors.md#on-the-following-adjective-w) | `zazawan wal gezebul.` | *Azawan is never sleepy.* | B |
| [Only the adjective, listed](../restrictors.md#on-the-following-adjective-w) | `zazawan werehel wal gezebul.` | *Azawan is sleepy only when raining.* | B |
| [A habit, on an adjective](../restrictors.md#on-the-following-adjective-w) | `zalahen wual gezebul.` | *Alahen is always sleepy.* | B |

Two manner adverbs in a row, with no restrictor, both describe the walk: `zazawan vowogal hadehum halahom.` *quickly and quietly* ([only when / never](../restrictors.md#only-when-never-hal)).

### Which restrictor {#which}

The vowel picks the reading and the ending says how open the list is: **-l** closed, **-m** open, **-r** an unspecified member. The same map works on `/w/` (`wal`, `wam`, `wual`, and so on).

<!-- cheat-sheet: restrictors-spans -->
| Agazan | Use | English (with occasions) | English (bare) | Stage |
|--------|-----|--------------------------|----------------|-------|
| [**`hal` / `ham`**](../restrictors.md#more-occasions) | listed times | *only when…* / *when…, among others* | *never* / *never, as far as I know* | B |
| [**`hol` / `hom`**](../restrictors.md#more-occasions) | one exclusive menu | *either when A or when B (not both)* | | I |
| [**`haol` / `haom`**](../restrictors.md#more-occasions) | any of the listed times | *when A and/or when B* | | I |
| [**`hul` / `hum`**](../restrictors.md#more-occasions) | invert the list | *not when…* | | I |
| [**`hual` / `huam`**](../restrictors.md#more-occasions) | every time minus the list | *always except when…* | *always* / *usually* | B |
| [**`huol` / `huom`**](../restrictors.md#more-occasions) | any leftover time minus the list | *anytime except when…* | | I |

### Ranked {#ranked}

<!-- cheat-sheet: restrictors-spans -->
| Agazan | Use | English | Stage |
|--------|-----|---------|-------|
| [**`hel` / `hem`**](../restrictors.md#more-occasions) | priority | *preferably when A ≻ when B* | I |
| [**`hael` / `haem`**](../restrictors.md#more-occasions) | in order | *first when A, then when B* | I |
| [**`hoel` / `hoem`**](../restrictors.md#more-occasions) | equal frequency | *equally when A and when B* | I |
| [**`huel` / `huem`**](../restrictors.md#more-occasions) | last-first | *as a last resort when A* | I |

With several occasions before `huel`, the last listed is the first choice.

### Some member, unlisted {#unspecified}

**-r** points at some time without saying which, so nothing needs to come before it.

<!-- cheat-sheet: restrictors-spans -->
| Agazan | Use | English (with occasions) | English (bare) | Stage |
|--------|-----|--------------------------|----------------|-------|
| [**`har`**](../restrictors.md#more-occasions) | some member of the listed times | *sometimes among these* | *sometimes* | B |
| [**`hor`**](../restrictors.md#more-occasions) | some member of a one-choice menu | *anytime among these* | *anytime* | B |
| [**`hur`**](../restrictors.md#more-occasions) | a leftover occasion | *some time other than these* | *some other time* | B |
| [**`her`**](../restrictors.md#more-occasions) | the first-ranked occasion | *at whichever ranks first* | *at the preferred time* | I |

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [Either, not both](../restrictors.md#more-occasions) | `zazawan vowogal herehel hanadal hol.` | *Azawan walks either when raining or at night.* | I |
| [And/or](../restrictors.md#more-occasions) | `zalahen vezebal herehel hozezol haol.` | *Alahen sleeps when raining and/or when snowing.* | I |
| [Preferably](../restrictors.md#more-occasions) | `zazawan vowogal hamabam hahobam hel.` | *preferably in an emergency rather than for convenience* | I |
| [Last resort](../restrictors.md#more-occasions) | `zazawan vowogal herehel huel.` | *Azawan walks only as a last resort when raining.* | I |
| [When's best?](../restrictors.md#more-occasions) | `yol her zahan vowogal.` | *When's best for us to walk?* | I |
| [On an adjective, one of two](../restrictors.md#more-occasions) | `zazawan werehel wanadal wol gezebul.` | *sleepy either when raining or at night* | I |
| [A whole clause as the occasion](../restrictors.md#occasions-vs-a-dependent-when): `barl` | `zahaben vezehel thoyem barl zazawan vowogal.` | *Ahaben sings if Azawan walks.* | I |

Use a restrictor when each occasion is a word; use `barl` when the occasion is a full clause. To ask *when?*, see [questions](../questions.md#when).

## Setting a chunk apart {#spans}

A **span** is a role letter and a pair of brackets. The letter is the role of the whole chunk in the sentence. A span is written only: speech has no word for its edges.

### Which bracket {#brackets}

| Bracket | Inside is | Use | Example | Stage |
|---------|-----------|-----|---------|-------|
| [`[…]`](../spans.md#writing) | Agazan | cite: what someone said, a title | `zazawan d[azawan] vezebel.` | B |
| [<code>&lt;…&gt;</code>](../spans.md#loans) | not Agazan | opaque: a foreign word, code, a name | <code>zazawan d&lt;kimchi&gt; vahahal.</code> | B |
| [`th(…)`](../spans.md#asides) | Agazan | aside: a side comment; `g(…)` on a noun, `w(…)` on the next word, `h(…)` on the action | `zazawan vowogal th(hagawal).` | B |
| [`{ … }`](../spans.md#scope-islands) | Agazan | scope island: a binder inside reaches only that chunk | `zazawan { hegewem zodogal geredal } vahahal.` | I |

When the lexicon has a matching root, write the ordinary word, not a span. An aside holds the same speech act as the outer sentence and never goes under `/y/`, `/z/`, `/d/`, `/b/`, or `/v/`.

### Marks before the bracket {#marks}

<!-- cheat-sheet: restrictors-spans -->
| Mark | Use | English | Example | Stage |
|------|-----|---------|---------|-------|
| [*(none)*](../spans.md#exact-paraphrase-proper) | exact | verbatim wording | `d[azawan]` | B |
| [**`~`**](../spans.md#exact-paraphrase-proper) | paraphrase | the gist | `d~[zazawan vezehel]` | B |
| [**`@`**](../spans.md#exact-paraphrase-proper) | proper | a work known by that title | `d@[onodan alahen]` | B |
| [**`~@`**](../spans.md#exact-paraphrase-proper) | proper, loosely remembered | *something like that title* | `d~@[onodan alahen]` | B |
| [**`^@`**](../spans.md#one-of-a-title) | one thing under the name | *an iPhone*, *a copy of* | `d^@[onodan alahen]` | I |
| [**`~^@`**](../spans.md#one-of-a-title) | one copy, title roughly | *a copy of something like* | `d~^@[onodan alahen]` | I |

A one-word name is an ordinary **-n** word (`donodan`), not a span.

### Which slot {#slot}

<!-- cheat-sheet: restrictors-spans -->
| Agazan | Use | English | Stage |
|--------|-----|---------|-------|
| [`/d/`](../spans.md#pos) | object | *said / wrote / saw “…”* | B |
| [`/z/`](../spans.md#pos) | subject | a foreign name as the subject | B |
| [`/b/`](../spans.md#pos) | extra party | a foreign name as the recipient | B |
| [`/v/`](../spans.md#pos) | verb | echo the act as wording; a loan verb | B |
| [`/ɡ/`](../spans.md#pos) | adjective | a loan adjective; an aside on the noun | B |
| [`/w/`](../spans.md#pos) | extra detail | a loan degree word; an aside on the next word | B |
| [`/h/`](../spans.md#pos) | adverb | a loan adverb; an aside on the action | B |
| [`/th/`](../spans.md#pos) | stance | an aside on the sentence | B |

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [Quote a sentence](../spans.md#exact-paraphrase-proper) | `zalahen d~[zazawan vezehel] varadal.` | *Alahen wrote something like “Azawan sings.”* | B |
| [A title of several words](../spans.md#exact-paraphrase-proper) | `zahaben d@[onodan alahen] vezehel.` | *Ahaben sang Onodan Alahen.* | B |
| [A cite as the verb](../spans.md#pos) | `yul zalahen v[vazadal].` | *Don't say “stop,” Alahen.* | B |
| [A loan verb](../spans.md#pos) | <code>zalahen v&lt;google&gt; dazawan.</code> | *Alahen googled Azawan.* | B |
| [A loan adjective](../spans.md#pos) | <code>zodogal g&lt;rouge&gt; vowogal.</code> | *A rouge dog walks.* | B |
| [A quoted question](../spans.md#quote-acts) | `zazawan d[yol zalahen vowogal] vezebel.` | *Azawan said, “Does Alahen walk?”* | I |
| [Point back at a quote](../spans.md#span-noun) | `zalahen d[azawan] vezebel. zahaben duxar vahahal.` | *Alahen said “Azawan.” Ahaben saw that.* | I |
| [Topic from a title](../spans.md#topic-quotes) | `x@[onodan alahen] dozan vezehel.` | *Now, about Onodan Alahen: it is sung.* | I |
| [An aside as a clause](../spans.md#asides) | `zazawan vowogal th(zalahen vezebal).` | *Azawan walks (Alahen sleeps).* | B |
| [An aside on a noun](../spans.md#asides) | `zazawan g(zazawar vowogal) vezehel.` | *Azawan, who walks, sings.* | B |
| [An aside on one word](../spans.md#asides) | `zodogal w(zazawan vezebel) gubuhel vowogal.` | *A (so Azawan says) blue dog walks.* | B |
| [An aside before the noun](../spans.md#gl-spans) | `gl(gubuhel) zodogal gamazam vowogal.` | *The small dog (it is blue) walks.* | I |
| [A loan adjective before the noun](../spans.md#gl-spans) | <code>gl&lt;rouge&gt; zodogal vowogal.</code> | *A rouge dog walks.* | I |
| [A loan degree word](../spans.md#pos) | <code>zodogal w&lt;molto&gt; gubuhel vowogal.</code> | *A molto blue dog walks.* | B |
| [Aside inside a cite](../spans.md#nesting) | `zazawan d[ th(hagawal) azawan ] vezebel.` | *Azawan said “Azawan” (quietly).* | A |

## Scope islands {#islands}

Braces `{ … }` group one chunk so a binder inside reaches only it. The edges are a pause in speech. A [tone mark](../speech-moves.md#tone-marks) right before the brace colors the whole island.

| Rule | Detail | Stage |
|------|--------|-------|
| [Binder required](../spans.md#scope-islands) | a scope-taking `/h/` or `/th/`, or a join, inside; a hook is never a binder | I |
| [At most one phrase](../spans.md#scope-islands) | a noun phrase, verb phrase, or `/ɡ/` stack, with its own detail | I |
| [One island per clause](../spans.md#scope-islands) | islands do not nest | I |
| [Hosts keep their `/b/`](../spans.md#scope-islands) | host and hosted `/b/` are both inside or both outside | I |
| [No role letter](../spans.md#scope-islands) | on the edges | I |
| [Empty `{ }`](../spans.md#scope-islands) | has no reading | I |

| Placement | Reading | Stage |
|-----------|---------|-------|
| [`/h/` or `/th/` inside](../spans.md#scope-islands) | frames that chunk | I |
| [`/h/` or `/th/` outside](../spans.md#scope-islands) | ordinary floating word: frames the verb or clause | I |
| [Join inside](../spans.md#scope-islands) | joins only the interior conjuncts | I |
| [Join outside](../spans.md#scope-islands) | ordinary lookback; the edges do not filter it | I |

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [A possibility, on one chunk](../spans.md#scope-islands) | `zazawan { hegewem zodogal geredal } vahahal.` | *Azawan saw, as a possibility, the red dog.* | I |
| [A join, on one pair](../spans.md#scope-islands) | `zazawan { zalahen zal } zam vahahal.` | *Azawan and (just Alahen) saw …* | I |
| [A recipient first, then the binder](../spans.md#scope-islands) | `zazawan { balahen hegewem } vezebel.` | *Azawan told Alahen, possibly* | I |

## Don't mix up {#dont-mix-up}

| This | vs | That |
|------|----|------|
| `hal` *only when* ([a closed list](../restrictors.md#only-when-never-hal)) | | `ham` *among other times* ([an open list](../restrictors.md#listed-occasions-open)) |
| `hual` *always* ([every time](../restrictors.md#always-hual)) | | `har` *sometimes* ([some time](../restrictors.md#sometimes-anytime-some-other-time)) |
| `hor` *anytime* ([any one will do](../restrictors.md#sometimes-anytime-some-other-time)) | | `hual` *always* ([at all times](../restrictors.md#always-hual)) |
| `hur` *some other time* ([a leftover occasion](../restrictors.md#more-occasions)) | | `huol` *anytime except when…* ([leftover times in general](../restrictors.md#more-occasions)) |
| `herehel hal` *only when raining* ([a restrictor list](../restrictors.md#occasions-vs-a-dependent-when)) | | `thoyem barl` *if a whole sentence* ([a dependent](../restrictors.md#occasions-vs-a-dependent-when)) |
| `d[azawan]` *what was said* ([a cite](../spans.md#writing)) | | `donodan` *the one-word name* ([an ordinary -n word](../spans.md#exact-paraphrase-proper)) |
| `d@[onodan alahen]` *the work* ([a proper span](../spans.md#exact-paraphrase-proper)) | | `glelen` *the name as spelling* ([a mention](../spans.md#mention)) |
| `th(…)` *an aside* ([a comment](../spans.md#asides)) | | `{ … }` *a scope island* ([a chunk for a binder](../spans.md#scope-islands)) |
