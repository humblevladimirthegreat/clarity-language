# Ageben → English cheat sheet {#to-english-cheat-sheet}

Met a short word you can't place? Find its family by shape, then look it up in the tables below, sorted by spelling. Every table except the first is built from the dictionary, so it always matches the grammar, and each row links to the section that teaches it. Stage: **B** Beginner, **I** Intermediate, **A** Advanced.

Ordinary roots and [dictionary compounds](/compounds#dictionary-compounds) are not here: look them up in the [lexicon](/lexicon). To build a sentence from an English job (*because*, *by Friday*, *walked*), use [Saying it in Ageben](/english).

## Find the family by shape {#by-shape}

| Shape | Family | Example | Stage |
|-------|--------|---------|-------|
| vowel(s) + ending, no role letter | [hook](/hooks) | `al`, `el` | B |
| root + ending, no role letter, mid-clause | [same-role word](/same-role-words#same-role-words) | `abam` | I |
| role letter + vowel(s) + ending, no root | [join](/joins) | `zal`, `vul` | B |
| `y` + vowel + ending, no root | [speech act](/firm-soft#speech-act) | `yal` | B |
| role letter + vowel + **-rn** | [stand-in word](/stand-in-roles#stand-in-roles) | `darn` *a statement* | I |
| role letter + `w` + vowel + part + vowel + ending | [role pointer](/pronouns#role-pointers) | `zwuzer` *the latest doer* | B |
| role letter + `w` + vowel + ending | [tag](/tag-pronouns#tag-pronouns) | `zwar` *A* | I |
| a name's root + **-r** | [resume](/pronouns#resume-r) | `zazozor` *Azozon again* | B |

Every join and hook, with its English: [Joins and hooks cheat sheet](joins-hooks.md).
