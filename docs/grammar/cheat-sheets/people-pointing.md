# People and pointing cheat sheet {#people-pointing-cheat-sheet}

A quick look at [pronouns](../pronouns.md) and [plurality](../plurality.md) on one page. Nothing here is new: each row links to the section that teaches it. Stage: **B** Beginner, **I** Intermediate, **A** Advanced.

## Pointing back {#pointing-back}

### Which pointer to use {#which-pointer}

| You want | Use | Example | English | Stage |
|----------|-----|---------|---------|-------|
| [The same one again, by name](../pronouns.md#resume-r) | role letter + whole stem + **-r** | `zuzazor` | *Uzazon* (again) | B |
| [The same kind again](../pronouns.md#resume-r) | the same, on a kind | `zodozor` | *the dog* | B |
| [By the part they played](../pronouns.md#role-pointers) | role letter + role vowel + `x` + pointer vowel + **-r** | `zaxar` | *the latest doer* | B |
| [A new one of that kind](../pronouns.md#a-new-one) | the same pointer with **-l** | `duxal` | *another one* (as object) | B |
| [Their part, not them](../pronouns.md#share) | the same pointer with **-m** | `zaxam` | *what the doer did* | B |
| [Pin one sense](../pronouns.md#resume-sense) | **-rl** concrete, **-rm** abstract | `dodozorl` | *the dog* (not the loyalty) | I |
| [A label you chose](../pronouns.md#tag-pronouns) | role letter + `w` + tag vowel | `zwar` | *A* | I |
| [The talk's topic](../pronouns.md#topic-pronoun) | `oza` + **-n** | `zozan` | *the topic* | I |

A resume uses the **whole stem**: `debeholuruhar` is *the bedroom*, `debehor` is *the bed*. It points at the **most recent** word with that stem.

### Role pointers {#role-pointers}

Role letter for the slot now (see [role pointers](../pronouns.md#role-pointers)), a **role vowel** for the part, `x`, a **pointer vowel** for which event, then the ending.

| Role vowel | Part in the earlier event | Where it sat | Example | Stage |
|------------|---------------------------|--------------|---------|-------|
| **a** | the doer | `/z/` | `zaxar` | B |
| **u** | the one it happens to | `/d/` | `duxar` | B |
| **o** | the extra party | `/b/` | `zoxar` | B |

| Pointer vowel | Picks | Example | English | Stage |
|---------------|-------|---------|---------|-------|
| **a** | [the latest sentence with someone in that part](../pronouns.md#role-pointers) | `zaxar` | *they* | B |
| **e** | [this sentence's own event](../pronouns.md#themself) | `daxer` | *themself* | B |
| **o** | [the nearest one other than the last](../pronouns.md#the-other-one) | `zaxor` | *the other one* | B |
| **u** | [the latest sentence that left the part unsaid](../pronouns.md#whoever-it-was) | `zaxur` | *whoever did it* | B |

Endings on a pointer: **-r** the same one, **-l** [a new one](../pronouns.md#a-new-one) (not with **u**), **-m** [their part](../pronouns.md#share) (not with **e**). A pointer never names its own slot. A topic change [ends its reach](../pronouns.md#topic-resets).

### Other ways to point {#other-pointing}

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [Same action again](../pronouns.md#cross-role-recast): change only the role letter | `zolozun vuzazor.` | *Olozun does the same with Uzazon.* | I |
| [Each other](../pronouns.md#reciprocal) | `zuzazon zolozun zal vanobol hedam.` | *Uzazon and Olozun see each other.* | I |
| [A new one with a new property](../pronouns.md#cross-role-recast) | `zolozun dar godozor gabulol vanobol.` | *Olozun sees a black one.* | I |

### Tags {#tags}

A [tag](../pronouns.md#tag-pronouns) is a label you choose: role letter, `w`, a tag vowel (A **a**, E **e**, O **o**, U **u**), an ending. It stays on its referent. Tags fill `/z/`, `/d/`, `/b/` only.

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| Assign: tag **-l** after a phrase | `zodozol zwal` | *a dog, call it A* | I |
| A new referent with no name | `zwal` | *someone A* | I |
| Recall | `zwar` / `dwar` / `bwar` | *A* | I |
| Recall a tag assigned to a name | `zwan` / `dwan` / `bwan` | *A* (a named one) | I |
| A's part in the latest event | `zwam` / `dwam` / `bwam` | *what A did* | I |
| A and associates | `zwarx` / `zwanx` | *A and associates* | I |
| Two tags (six stacks: `zwaer` `zwaor` `zwoer` `zwuar` `zwuor` `zwuer`) | `zwaer` | *A and E* | I |
| Two tags, their parts | `zwaem` | *what A and E did* | I |
| Two tags and associates | `zwaerx` | *A, E, and associates* | I |

## The topic {#topic}

Only an `/x/` word at the start of a sentence sets the [topic](../pronouns.md#topic). Being first, being the subject, and *as for* do not.

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| Introduce a person | `xuzazon` | *now, about Uzazon* | I |
| Introduce a kind | `xodozol` | *now, about a dog* | I |
| [Return to an earlier topic](../pronouns.md#topic-return) | `xuzazor` | *back to Uzazon* | I |
| [Return to the kind from before](../pronouns.md#topic-return) | `xodozor` | *back to the dog* | I |
| [Clear the topic](../pronouns.md#topic) | `xevewem` / `xavadom` | *next* / *by the way* | I |
| [The topic itself, in any slot](../pronouns.md#topic-pronoun) | `zozan` / `dozan` / `bozan` | *the topic* | I |

The topic pronoun is never a topic word or a resume (`xozan`, `xozar`, `zozar` are not sentences). A dropped subject is never the topic: write `zozan`.

| [What a topic change resets](../pronouns.md#topic-resets) | Resets? | Stage |
|----------------------------|---------|-------|
| [Role pointer anchors](../pronouns.md#topic-resets) | yes | I |
| Bare-number magnitude | yes | I |
| Whole-stem **-r** | no | I |
| Tags | no | I |

## People in the conversation {#people}

### Special pronouns {#special-pronouns}

Role letter + the root + **-n** ([special pronouns](../pronouns.md#special-pronouns)). Prefer a proper name when you have one.

| Word | Means | In a slot | English | Same root as | Stage |
|------|-------|-----------|---------|--------------|-------|
| [`amun`](../pronouns.md#special-pronouns) | the speaker | `zamun` | *I* | `amul` *microphone* | B |
| `ehon` | the one listening | `zehon` / `dehon` | *you* | `ehol` *headphones* | B |
| `ahan` | speaker and addressees together | `zahan` | *we* (you and I) | `ahal` *handshake* | B |
| `unan` | a nonspecific individual | `zunan` | *someone* | `unal` *neutral* | B |
| [`oben`](../pronouns.md#generic-pronoun) | any person, as a rule | `zoben` | *one*, generic *you* | `obel` *person* | B |

**Notes:** As an object, *we* is `dahan`. `ehon` is always the person actually listening. `oben` takes no **-x**.

### Groups with **-x** {#groups}

| Form | Means | Example | English | Stage |
|------|-------|---------|---------|-------|
| [name **-nx**](../plurality.md#associative) | anchor and associates | `zuzazonx` | *Uzazon and associates* | B |
| [**-lx** / **-mx**](../plurality.md#associative) | an indefinite group | `zegazolx` | *some cats* | B |
| [**-lnx**](../word-endings.md#name-instance--ln) | some of a name | `duzazolnx` | *some Azawans* | I |
| [**-rx**](../plurality.md#associative) | someone mentioned, and associates | `zuzazorx` | *they* | B |
| [speaker **-x**](../plurality.md#person-role-x) | the speaker and their people, you not included | `amunx` (`zamunx`, `damunx`) | *I and my people* | B |
| [listener **-x**](../plurality.md#person-role-x) | the address set, speaker not included | `ehonx` (`zehonx`, `dehonx`) | *you all* | B |
| [interlocutors **-x**](../plurality.md#person-role-x) | everyone here, and their people | `ahanx` | *we all* | B |

Who counts as an associate is [open unless you say](../plurality.md#associate-resolution): a join or `ul` names it; otherwise a group already named, then the obvious group in the scene. Nonspecific `unan` takes no **-x**; *some people* is `zobelx`.

### One act, one unit {#collective}

**-x** on a verb or adjective says the group acts, or the property holds, as one.

| Job | Example | English | Stage |
|-----|---------|---------|-------|
| [Group, act left open](../plurality.md#verbs-v) | `zuzazonx vezeyol` | *Uzazon and associates sing* | I |
| [One shared act](../plurality.md#verbs-v) | `zuzazonx vezeyolx` | *they sing as one performance* | I |
| [Joint doing, others unnamed](../plurality.md#verbs-v) | `zuzazon vezeyolx` | *Uzazon sings jointly* | I |
| [The group as one unit](../plurality.md#verbs-v) | `zovayal voworelx` | *the family walks as one unit* | I |
| [Property of each member](../plurality.md#adjectives-g) | `zavagal zulol zal garalom` | *the file-box and the toolbox are each heavy* | I |
| [Property of the whole](../plurality.md#adjectives-g) | `zavagal zulol zal garalomx` | *heavy together* | I |
| [Group-level size](../plurality.md#adjectives-g) | `zovayal gagalam` | *the family is vast* | I |
| [Members, plain](../plurality.md#adjectives-g) | `zavagalx garalom` | *the file-boxes are heavy* | I |
| [Members, collectively](../plurality.md#adjectives-g) | `zavagalx garalomx` | *the file-boxes are heavy collectively* | I |
| [Call a group](../plurality.md#vocatives-y) | `yehonx` | *hey, you all* | I |

## Don't mix up {#dont-mix-up}

| This | vs | That |
|------|----|------|
| `zuzazor` *Uzazon, again* ([the stem, resumed](../pronouns.md#resume-r)) | | `zaxar` *the latest doer* ([by the part they played](../pronouns.md#role-pointers)) |
| `duxar` *the same one* ([-r](../pronouns.md#a-new-one)) | | `duxal` *another one* ([-l](../pronouns.md#a-new-one)) |
| `zaxar` *the person* ([-r](../pronouns.md#share)) | | `zaxam` *what they did* ([-m](../pronouns.md#share)) |
| `zahan` *you and I* ([`aha`](../pronouns.md#special-pronouns)) | | `zamunx` *I and my people*, not you ([speaker -x](../plurality.md#person-role-x)) |
| `zehon` *you* ([one listener](../pronouns.md#special-pronouns)) | | `zehonx` *you all* ([the address set](../plurality.md#person-role-x)) |
| `zunan` *someone* ([tied to no event](../pronouns.md#special-pronouns)) | | `zaxur` *whoever did that* ([tied to one known event](../pronouns.md#whoever-it-was)) |
| `zoben` *one*, people at large ([generic](../pronouns.md#generic-pronoun)) | | `zehon` *you*, the listener ([just them](../pronouns.md#special-pronouns)) |
| `xuzazon` *now, about Uzazon* ([sets the topic](../pronouns.md#topic)) | | `zozan` *the topic* ([refers to it](../pronouns.md#topic-pronoun)) |
