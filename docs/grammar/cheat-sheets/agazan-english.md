# Agazan → English cheat sheet {#agazan-english-cheat-sheet}

Met a short word you can't place? Find its family by shape, then look it up in the tables below, sorted by spelling. Every table except the first is built from the dictionary, so it always matches the grammar, and each row links to the section that teaches it. Stage: **B** Beginner, **I** Intermediate, **A** Advanced.

Words made from an ordinary root and an ending (`zodogal` *a dog*) are not here: look up the root in the dictionary.

## Find the family by shape {#by-shape}

| Shape | Family | Example | Stage |
|-------|--------|---------|-------|
| vowel(s) + ending, no role letter | [hook](../hooks.md) | `al`, `ol` | B |
| role letter + vowel(s) + ending, no root | [join](../joins.md) | `zal`, `vul` | B |
| `y` + vowel + ending, no root | [speech act](../speech-moves.md#speech-act) | `yal` | I |
| role letter + vowel + **-rn** | [stand-in word](../dependents.md#stand-in-roles) | `darn` *a statement* | I |
| role letter + vowel + `x` + vowel + **-r** | [role pointer](../pronouns.md#role-pointers) | `zaxar` *the latest doer* | I |
| role letter + `w` + vowel + ending | [tag](../pronouns.md#tag-pronouns) | `zwar` *A* | I |
| a name's root + **-r** | [resume](../pronouns.md#resume-r) | `zazawar` *Azawan again* | B |

Every join and hook, with its English: [Joins and hooks cheat sheet](joins-hooks.md).
