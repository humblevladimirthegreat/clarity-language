# Terminology

English names these grammar pages use. Each entry is a short gloss plus a link to the teaching section. The teaching page is the source of truth for how the form works.

This is not a dictionary of roots. For word senses, use the [Lexicon](lexicon.md).

## Closed labels

SMALLCAPS tags and series names as the lessons print them.

### Join-vowel names

English names for set / rank join vowels ([coordination](coordination.md)):

| Name | Vowel | Gloss |
|------|-------|--------|
| additive | **a** | *and* (inventory) |
| choice | **o** | exclusive *or* |
| cochoice | **ao** | inclusive *and/or* |
| negation | **u** | *not* / *none of* / standalone *no* |
| counteradditive | **ua** | *everything but* |
| counterchoice | **uo** | *anything but* |
| rank | **e** | earlier outranks later |
| corank | **ae** | equal rank / tie |
| choicerank | **oe** | exclusive ranked menu |
| counterrank | **ue** | rank reversal |

### Span TYPE / EDGE letters

From [spans](spans.md#shape): **TYPE** **a** cite / **e** aside / **o** mention / **u** opaque; **EDGE** **a** multi / **e** clause-scoped / **o** atomic / **u** empty (exact empty `…axul` / resume `…axur`).

### Number marker identities

From [numbers](numbers.md#marker-vowel-referential-identity): **scalar** (`+` / `-`), **ordinal** / rank from the start (`#`), **end-relative ordinal** (`#-`), **digit-string** / label (`_`).

## A–Z

### Ability / incapability

Hosted *can* / *can’t* (`xa` / `xe` / `xo` / `xu`) and hostless **ABIL**.

[Ability](ability.md)

### Act word

The written `/j/` word: **`jal` / `jol` / `jel` / `jul`** and soft **-m**.

[Core](core.md#speech-act)

**Compare with:** [speech act](#speech-act) is the setting (statement / question / command / prohibition). Polar [stance](#polar-stance) particles are not act words.

### Address set

Listener special plus **-sh**: the current addressees (no speaker).

[Plurality](plurality.md#person-role-sh)

### Adjective extra (`/w/`)

Detail on the previous adjective, not the whole clause.

[Core](core.md)

**Compare with:** a [restrictor](#restrictor) says when the host applies. Default `/w/` on needs is [values](#values).

### Adverb

Ordinary manner `/h/`.

[Core](core.md#adverbs-h)

**Compare with:** [mood tags](#mood-tags) are closed psychological `/h/` only.

### Ambient magnitude

Casual claim that an omitted exponent inherits a discourse order of magnitude; **`Ne0`** asserts OoM 0.

[Numbers](numbers.md#ambient-magnitude)

### Antecedent

The word a **-r** form points back to.

[Pronouns](pronouns.md)

### Arity (list / single-item / standalone)

How many items sit before a join: **list** (2+), **single-item** (1), **standalone** (0).

[Coordination](coordination.md#single-item-phrase)

### As-for

Complex `/h/` + `/b/` (**`ahaza`**) *as for X*.

[Core](core.md#as-for)

**Compare with:** values [topic](#met-unmet-motive-prescription-topic-values) is a need with no `x`.

### Aside

Span TYPE **e** (`h(…)`).

[Spans](spans.md#asides)

### Associative

**-sh** = named **anchor plus associates**.

[Plurality](plurality.md#associative)

### Atomic (span EDGE)

Span open that does not nest-push (EDGE **o**).

[Spans](spans.md#edge)

### Bare OoM

Digitless exponent naming a magnitude band (`g+e0`, `g+e3`).

[Numbers](numbers.md#bare-oom-bands)

### Binder

Inside a scope island: scope-taking `/h/` and/or a join.

[Spans](spans.md#scope-islands)

### Body (utterance)

Clause content after the left-edge `/j/` cluster.

[Core](core.md#left-edge-order-and-sentence-boundaries)

### Bound / endorse / invite

Prescription-force endings on value **`xo`**.

[Values](values.md#value-force)

### Changeability

Endings on unmet **`xu`**, **DECISION**, and ability *can’t*.

[Values](values.md#value-changeability), [plan / decision](plan-decision.md#decision)

### Citation / prefix-less citation

Root + ending with no role letter, outside a sentence.

[Core](core.md#citation-forms)

### Classification

Kind / role as predicative `/ɡ/` (no *to-be* verb).

[Predication](predication.md#classification)

**Compare with:** [identity](#identity) uses **SAME**. [Equative](#equative) is *as ADJ as*, not kind-ascription.

### Clause pole / NP pole

Condition vs outcome as NPs vs full sentences after **`adoro`**. **Clause pole** is the causation reading.

[Causation](causation.md)

### Clusivity

Who counts as *we* / *you* when names are unavailable.

[Pronouns](pronouns.md#clusivity)

### Collective

**-sh** on `/v/` (one shared act) vs on `/ɡ/` (property of the group as a unit).

[Plurality](plurality.md#verbs-v), [plurality](plurality.md#adjectives-g)

### Command / request / prohibition

Speech act **`jel` / `jem` / `jul` / `jum`**.

[Core](core.md#speech-act)

### Comparative / superlative / equative

Rank join + SHARED **scale**; single-item = superlative; **`ae`** = equative.

[Comparatives](comparatives.md)

### Complex adjective / complex adverb

`/ɡ/` or `/h/` plus immediately following `/b/`.

[Core](core.md#extra-nouns)

### Confirming a negative

Polar patterns that confirm a denied body.

[Questions](questions.md#confirming-a-negative)

### Contact / contact channel

Met-value **`xa`** endings (physical / mental / spiritual).

[Values](values.md#value-contact)

### Continue (`/x/`)

Same-speech-act forward motion.

[Core](core.md#continue-x)

**Compare with:** a [sentence linker](#sentence-linker) is the *therefore / however* subclass of continue.

### Conventional (number **-n**)

Number ending **-n**.

[Numbers](numbers.md#number-endings)

**Compare with:** content **-n** is [named](#literal-metaphorical-named-resume). Phrase join **-n** is a [named list](#named-list). Clause join **-n** is a [sequence](#sequence).

### Cross-role recast

Resume with a different PoS letter than the antecedent.

[Pronouns](pronouns.md)

### Dependent clause / **`adoro`**

Full sentence after **`adoro`** (last in the host slot).

[Core](core.md#dependent-clauses)

### Digitless

Number word with marker and ending but no digit groups.

[Numbers](numbers.md#digitless)

### Digitless exponent

Advanced free-number specials (`+e`, `-e-`, `+0e`, …). **Imaginary** is free `-e-`.

[Numbers](numbers.md#digitless-exponents), [imaginary](numbers.md#imaginary)

**Compare with:** [quasi](#quasi) is derivation `ROOTx-e-`. **NOTIONAL** is the as-if [mood](#mood-tags), not a number.

[Comparatives](comparatives.md#equatives)

### Evidentiality

[Commentary](commentary.md#evidentiality)
