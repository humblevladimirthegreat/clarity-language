# Terminology

English names these grammar pages use. Each entry is a short gloss plus a link to the teaching section. The teaching page is the source of truth for how the form works.

This is not a dictionary of roots. For word senses, use the [Lexicon](lexicon.md).

SMALLCAPS tags and series names as the lessons print them.

### Span TYPE / EDGE letters

From [spans](spans.md#shape): **TYPE** **a** cite / **e** aside / **o** mention / **u** opaque; **EDGE** **a** multi / **e** clause-scoped / **o** atomic / **u** empty (exact empty `…axul` / resume `…axur`).

From [numbers](numbers.md#marker-vowel-referential-identity): **scalar** (`+` / `-`), **ordinal** / rank from the start (`#`), **end-relative ordinal** (`#-`), **digit-string** / label (`_`).

## A–Z

### Ability / incapability

Hosted *can* / *can’t* (`xa` / `xe` / `xo` / `xu`) and hostless **ABIL**.

[Ability](ability.md)

### Act word

The written `/j/` word: **`jal` / `jol` / `jel` / `jul`** and soft **-m**.

[Clause](clause.md#speech-act)

**Compare with:** [speech act](#speech-act) is the setting (statement / question / command / prohibition). Polar [stance](#polar-stance) particles are not act words.

### Address set

Listener special plus **-x**: the current addressees (no speaker).

[Plurality](plurality.md#person-role-x)

### Adjective extra (`/w/`)

Detail on the following adjective, not the whole clause.

[Clause](clause.md)

**Compare with:** a [restrictor](#restrictor) says when the host applies. Default `/w/` on needs is [values](#values).

### Adverb

Ordinary manner `/h/`.

[Clause](clause.md#adverbs-h)

**Compare with:** [mood tags](#mood-tags) are closed psychological `/h/` only.

### Ambient magnitude

Casual claim that an omitted exponent inherits a discourse order of magnitude; **`Ne0`** asserts OoM 0.

[Numbers](numbers.md#ambient-magnitude)

### Antecedent

The word a **-r** form points back to.

[Pronouns](pronouns.md)

### Arity (list / single-item / standalone)

How many items sit before a join: **list** (2+), **single-item** (1), **standalone** (0).

[Joins](joins.md#single-item-phrase)

### As-for

Complex `/h/` + `/b/` (**`ahaza`**) *as for X*.

[Clause](clause.md#as-for)

**Compare with:** values [met](#met-unmet-motive-prescription-values) / unmet on `/ɡ/` is how a need stands toward a noun, not *as for*.

### Aside

Span TYPE **e** (`h(…)`).

[Spans](spans.md#asides)

### Associative

**-x** = named **anchor plus associates**.

[Plurality](plurality.md#associative)

### Atomic (span EDGE)

Span open that does not nest-push (EDGE **o**).

[Spans](spans.md#edge)

### Bare OoM

Digitless exponent naming a magnitude band (`g+e0`, `g+e3`).

[Numbers](numbers.md#bare-oom-bands)

### Binder

Inside a scope island: scope-taking `/h/` and/or a join.

[Spans](spans.md#scope-islands)

### Body (utterance)

Clause content after the left-edge `/j/` cluster.

[Clause](clause.md#left-edge-order-and-sentence-boundaries)

### Bound / endorse / invite

Prescription-force endings on value **`xe`**: **-l** bound (*must* / *has to*), **-m** endorse (*should*), **-r** invite (*could* / *might*).

[Values](values.md#value-force)

### Changeability

Endings on unmet **`xu`**, **DECISION**, and ability *can’t*.

[Values](values.md#value-changeability), [Intention](intention.md#decision)

### Citation / prefix-less citation

Root + ending with no role letter, outside a sentence.

[Reference suffix](reference-suffix.md#citation-forms)

### Classification

Kind / role as predicative `/ɡ/` (no *to-be* verb).

[Predication](predication.md#classification)

**Compare with:** [identity](#identity) uses **SAME**. [Equative](#equative) is *as ADJ as*, not kind-ascription.

### Clause pole / NP pole

Condition vs outcome as NPs vs full sentences after **`barl`**. **Clause pole** is the causation reading. Concession **`ezeba`** uses the same NP vs clause split (*despite Ululon* vs *although Ululon walks*). Intended outcome **`olala`** uses it too (*for a money-bag* vs *so that Ululon sits*).

[Causation](causation.md)

### Clusivity

Who counts as *we* / *you* when names are unavailable.

[Plurality](plurality.md#clusivity)

### Collective

**-x** on `/v/` (one shared act) vs on `/ɡ/` (property of the group as a unit).

[Plurality](plurality.md#verbs-v), [plurality](plurality.md#adjectives-g)

### Command / request / prohibition

Speech act **`jel` / `jem` / `jul` / `jum`**.

[Clause](clause.md#speech-act)

### Comparative / superlative / equative

Rank join + SHARED **scale** (`/ɡ/` quality or `/h/` manner); single-item = superlative; **`ae`** = equative.

[Comparatives](comparatives.md)

### Complex adjective / complex adverb

`/ɡ/` or `/h/` plus immediately following `/b/`.

[Clause](clause.md#extra-nouns)

### Confirming a negative

Polar patterns that confirm a denied body.

[Questions](questions.md#confirming-a-negative)

### Contact / contact channel

Met-value **`xa`** endings (physical / mental / spiritual).

[Values](values.md#value-contact)

### Continue (`/x/`)

Same-speech-act forward motion.

[Dependents](dependents.md#continue-x)

**Compare with:** a [sentence linker](#sentence-linker) is the *therefore / however* subclass of continue.

### Conventional (number **-n**)

Number ending **-n**.

[Numbers](numbers.md#number-endings)

**Compare with:** content **-n** is [named](#concrete-abstract-named-resume). Phrase join **-n** is a [named list](#named-list). Clause join **-n** is a [sequence](#sequence).

### Cross-role recast

Resume with a different PoS letter than the antecedent.

[Pronouns](pronouns.md)

### Dependent clause

A full sentence that fills a [stand-in](#stand-in) slot (`darl` / `barl` / `dorl` …). Last in the host slot; the dependent follows immediately.

[Dependents](dependents.md#dependent-clauses)

**Compare with:** English *the dog that runs* (which dog) is [which person or thing](dependents.md#which-noun), not a stand-in. Intended outcome *so that* is [**`holalam`**](dependents.md#so-that) plus **`barl`** or a noun `/b/`.

### Digitless

Number word with marker and ending but no digit groups.

[Numbers](numbers.md#digitless)

### Digitless exponent

Advanced free-number specials (`+e`, `-e-`, `+0e`, …). **Imaginary** is free `-e-`.

[Numbers](numbers.md#digitless-exponents), [imaginary](numbers.md#imaginary)

**Compare with:** [quasi](#quasi) is derivation `ROOTx-e-`. **NOTIONAL** is the as-if [mood](#mood-tags), not a number.

### Empty-allowed

Plain **o** + **-m**: *or none*.

[Joins](joins.md#empty-allowed-om)

Final **-l / -m / -n / -r** (plus optional **-x**). **Reference suffix** names the content-word table.

[Reference suffix](reference-suffix.md)

### Epistemic *because*

Reason for the *could be* (**MAY**), not world **BECAUSE**.

[Causation](causation.md#epistemic-because)

### Equative

**`ae`** SHARED scale = *as ADJ as*.

[Comparatives](comparatives.md#equatives)

### Evidentiality

Closed `/h/` how-you-know roots.

[Knowing](knowing.md#evidentiality)

### Residue / former climate

Closed `/h/` episode standing: leftover on the tally, or usual weather you are not claiming now. Not past tense.

[Knowing](knowing.md#residue)

### Extra noun (`/b/`)

Hosted: noun bolted onto a complex `/ɡ/` or `/h/`. Unhosted: recipient or addressee of the verb.

[Clause](clause.md#extra-nouns)

### Locative relation

Place how (*in*, *at*, *on*, *from*, *toward*, *through*, *out of*; frame **-m** *amid* / *near* / *over* / *away from* / *in the direction of* / *out from among* / *by way of*) as extra-noun [hooks](hooks.md#extra-noun) plus landmark `/b/`. *Between* is hosted `/h/` or `/ɡ/` plus a `/b/` join. A *from A to B* path is two hook extras (source, then goal).

[Relations](relations.md#locative-relations)

### Means

Extra-noun [hook](hooks.md#extra-noun) **`ael`** plus implement `/b/` (*using / with* a tool). Not join-relation *with*, not role **`exROOT`** (that names the **place** of an event).

[Relations](relations.md#means)

### Simile (*like*)

Hosted `/h/` or `/ɡ/` **`urorom`** plus model `/b/` (*like* a duck / *like* Azawan’s). Not **`SAME`**, not equative *as … as*, not NOTIONAL *as if*, not join-relation *on a par with*.

[Relations](relations.md#similative)

### Exchange (*for*)

Hosted `/h/` or `/ɡ/` **`uhanem`** plus consideration `/b/` (*in exchange for* a hammer). Not recipient `/b/`, not values motive **`xo`**, not intended-outcome **`olala`**.

[Relations](relations.md#exchange)

### Proxy (*on behalf of*)

Hosted `/h/` or `/ɡ/` **`udagam`** plus principal `/b/` (*on behalf of* Ululon). Not hook *instead*, not recipient `/b/`.

[Relations](relations.md#proxy)

### Of relation

Hosted `/h/` or `/ɡ/` plus `/b/` for English *of* that is not ownership or a place: *part of*, *contents of*, *made of*, origin *from*.

[Relations](relations.md#of-relations)

### Factivity

Whether **IF** vs **BECAUSE** treats the dependent as asserted.

[Causation](causation.md#factivity)

### Fill-ask / fill-all

Under question, join **-r** is a blank; several **-r** = fill all.

[Questions](questions.md#fill-ask-r)

### Firm / soft

Speech-act ending **-l** vs **-m**.

[Clause](clause.md#speech-act)

### Forecast source

[Intention](intention.md#predict-evidentiality)

### Full-root resume / short resume

[Restrictors](restrictors.md)

### Resume

[Pronouns](pronouns.md), [spans](spans.md), [numbers](numbers.md#number-endings)

### Hook

Prefix-less *including / rather / instead / except*, discourse glue, and extra-noun **in** / **on** / **at** / **toward** / **from** / **out of** / **through** / **for** / **using** / **against** (frame **-m** *amid* / *over* / *near* / *in the direction of* / *away from* / *out from among* / *by way of* / *with in mind* / *by* / *contrary to*; placement decides the job). Optional `/w/` immediately before the hook grades that hook (including restrictors); `/b/` sits immediately after the hook.

[Hooks](hooks.md)

### Stand-in

[Dependents](dependents.md#stand-in)

**Compare with:** unspecified join **`-r`** (`dar`) is *something* with no following clause. [Clause poles](#clause-pole--np-pole) (`hurugum`, `hadorom`) name the relation; the stand-in fills `/b/`.
