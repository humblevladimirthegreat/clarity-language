# Proper names and titled phrases {#proper-names-and-titled-phrases}

::: tip Reminder:
Intermediate sections assume you have read the beginner sections of every page.
:::

### Proper name (`-n`) {#proper-name--n}

Beginner used **-n** for a person’s or place’s name. You can also mark a **title, brand, or other conventional name** on any role letter: a named race as the verb, a named style as the adjective, a named standard as the adverb. The first letter still says the word’s role in the clause; **-n** says you mean the thing that bears that name, not the kind the root describes.

A brand, a product line, a work, or a yearly event counts as one named thing, even though it has many units, copies, or runnings. To mean one of those, use **-ln**.

> `zahelan vezuyon.`
>
> z-Ahelan | v-Ezuyon
>
> "Ahelan sings Ezuyon." (that titled song)

The rest of the role map (same **-n**):

| Agebon | Use | English |
|--------|-----|---------|
| `/z/` `/d/` `/b/` + **-n** | this named entity | person, place, titled work, brand or product line (*Uzozen*, *Paris*, *the Odyssey*; *book by* **[Rowling]**) |
| `/v/` + **-n** | this named event, rite, or titled action | *perform* **[Hamlet]**, *run* **[the Boston Marathon]**, *observe* **[Ramadan]** |
| `/ɡ/` + **-n** | this named style, brand, family, or category | **[Art Deco]** furniture, **[iOS]** app, *Alen* **[Alowen]** |
| `/w/` + **-n** | named scale, grade, or criterion on the following adjective | *spicy* **[Scoville]**, *large* **[King-size]** |
| `/h/` + **-n** | named standard, channel, or official frame | *according to* **[GAAP]**, *in* **[Q3]** as the named quarter  |
| `/y/` vocative + **-n** | address this named person, place, or title; on `/y/`, **-n** always calls | `yolazun`; a kind as a title (`yagayun`); titled group (*Team Alpha*) |

### One of a name (`-ln`) {#name-instance--ln}

English *an iPhone*, *a copy of the Odyssey*, and *someone named Uzozen* each mean one thing the name applies to, not the named thing itself. End the word in **-ln** instead of **-n**, on `/z/`, `/d/`, or `/b/`. Like **-l**, it brings a new thing into the talk, and the **n** says which name it falls under. So you can mention one bed of a bed brand without a separate word for *bed*. (cue: **l** first mention, then **n** name)

> `zolazun duzozeln vawebol.`
>
> z-Olazun | d-Uzozen.instance | v-see
>
> "Olazun sees an Uzozen." (one bed of that brand)

What counts as one depends on what the name names:

| Name (**-n**) | One of it (**-ln**) |
|---------------|---------------------|
| a brand or product line | one unit (*an Uzozen*) |
| a work | one copy or one performance |
| a yearly event | one running of it |
| a person | someone with that name (*another Uzozen*) |

<!-- cheat-sheet: word-shape-clause -->
| Agebon | Use | English |
|--------|-----|---------|
| `duzozen` | the named thing itself | *Uzozen* (the brand) |
| `duzozeln` | one thing the name applies to | *an Uzozen* |
| `duzozelnx` | some things the name applies to ([plurality](plurality.md)) | *some Uzozens* |
| `zaleln galowen` | the same on a full name | *someone named Alen Alowen* |

An **-ln** word is a new mention, so a lone `zuzozeln.` is *there is an Uzozen*, and a later **-r** resume (`duzozer`) is that same bed, not the brand. A foreign name in a span uses the fence mark `^@` for the same job ([spans](spans.md#when-required)).

**Compare with:** `guzozen` after a noun puts it in the brand (`zobahol guzozen` *the bed is an Uzozen*). **-l** on the root is the root’s own sense: `duzozel` is *a swan*.

### Countries and traditions {#countries-traditions}

A country root and a tradition root use all four endings, with one job each:

| Ending | Country (`azabana`) | Tradition (`ugugo`) |
|--------|-------------------|---------------------|
| **-n** | the country as a named place: *Japan* | the tradition as a named whole: *Christianity* |
| **-m** | belonging to its people: *Japanese* | belonging to its people: *Christian* |
| **-l** | its flag: *a Japanese flag* | its symbol: *a crucifix* |
| **-ln** | one thing that bears the name (*a ship named Japan*) | one thing that bears the name |

**-n** names the whole and **-m** says someone or something belongs to it, so a nationality is not a special case. A person, a quality, or a thing from that people (*Japanese food*) takes **-m**; **-n** on `/ɡ/` is a named label instead: a style, a brand, or a family name (*Art Deco*, *iOS*, *Alen* **[Alowen]**).

> `zuzozen gazabanam.`
>
> z-Uzozen | g-japanese
>
> "Uzozen is Japanese."

<!-- cheat-sheet: word-shape-clause -->
| Agebon | Use | English |
|--------|-----|---------|
| `azabanan` | the named country | *Japan* |
| `dazabanal` | its flag | *a Japanese flag* |
| `gazabanam` | belonging to its people | *Japanese* |

Country names are spelled from the English sound (`azabanan` from *Japan*). The [lexicon](lexicon.md#respell) shows that spelling for a name you type. A person whose English name you want to keep as written uses a [span](spans.md#loans) instead.

### Titled phrases (hook, join, span)
<a id="titled-phrases"></a>

A store, title, or handle can be several words. Put **-n** on the **hook**, **join**, or **span** that packages them. That ending names the whole phrase. Each inner word keeps its own ending: a kind stays **-l**, an abstract stays **-m**, a resume stays **-r**, and a person or place that is itself a name still takes **-n**.

> `dududal on dugudal.`
>
> NAME[d-tea | instead | d-coffee]
>
> "Coffee-Instead-of-Tea" (a cafe name)

| Package | Where **-n** sits | Inner words |
|---------|-------------------|-------------|
| hook | the hook (`on`, extra-noun **-n**, …) | sides keep **-l** / **-m** / **-r**, or **-n** if that side is a name |
| join | the join (`zon`, …) | members keep their usual endings |
| [span](spans.md#when-required) | the fence (`@` / spoken **-n**) | interior tokens keep their usual endings |

A one-word name, a hyphenated name with mid-word **`x`**, and each part of a full name still end the **content word** in **-n**.

### Multipart names {#multipart-names}

English writes a given name and a family name as two words (*Alen Alowen*). Agebon does too. The given name fills the slot with **-n**, and the family name follows it as a `/ɡ/` word with **-n**: like a brand, a family is a named group the person falls under. Given name first is the usual order.

> `zalen galowen vowurel.`
>
> [z-Alen | g-Alowen] | v-walk
>
> "Alen Alowen walks."

The family name describes the given name, so the person is still one noun in one slot. A resume repeats the given name’s stem, so `zaler` points back to Alen Alowen, and you can drop the family name once the person is known.

<!-- cheat-sheet: word-shape-clause -->
| Agebon | Use | English |
|--------|-----|---------|
| `alen galowen` | citation of a full name | *Alen Alowen* |
| `zalen galowen` | full name in a noun slot | *Alen Alowen* |
| `zaleln galowen` | [one of a name](#name-instance--ln) | *someone named Alen Alowen* |
| `zaler` | [resume](pronouns.md) | *Alen* (the same person) |

Put the family name first, as an adjective before the noun, only when your culture names people family first. The same family name can describe the family itself (`zavayal galowen` *the Alowen family*), and what the family uses takes the ordinary *whose* hook: `dahehal em bavayal galowen` is *the Alowen family’s house*.

A full name works as a [greeting](word-endings.md#greeting) too: `alen galowen.` is Alen Alowen saying hello. A [call](speech-moves.md#vocative) takes the family name the same way (`yalen galowen.` *Alen Alowen!*).

A family name is an adjective, but the person who receives is a plain `/b/` word, so it may stand right after the family name: `zalen galowen bolazun vezuyel.` is *Alen Alowen tells Olazun*, the same as `zalen galowen vezuyel bolazun.` Only a [`bl-` word](clause.md#extra-nouns) would complete it.

A **hyphenated name** (*Mary-Kate*, *Coffee-Tea*) is one word: roots join left to right with mid-word **`x`**, and **-n** names the whole.

> `zalexalowen vowurel.`
>
> z-Ale-x-Alowen | v-walk
>
> "Alexalowen walks."

| Agebon | Use | English |
|--------|-----|---------|
| `zalexalowen` | hyphenated given name | *Alexalowen* |
| `zalexalowen galowen` | hyphenated given name and a family name | *Alexalowen Alowen* |
| `zugudaxududan`, `zugudaxududaxowulan` | shop label from lexicon roots | *Coffee-Tea*; *Coffee-Tea-Water* |

A business or product name uses the same pieces. A compact label is one **`x`** word. A product under a maker’s name takes the maker as its `/ɡ/` name, as a person takes a family name (*a Mustang by Ford*). A name with grammar inside it, such as a verb or *instead of*, is a [titled phrase](#titled-phrases) or a [span](spans.md#when-required), where any role letter can appear.

A nativized loan (a foreign word adapted into an Agebon root, plus an ordinary ending) takes the same four endings as any content word. A **lexical compound** also fills one slot: it is one stem, written without mid-word **`x`** (`zobahohal` *bedroom*).

**Compare with:** `zalen galowen.` alone is a sentence: *Alen is an Alowen* ([classification](predication.md#classification)). The citation `alen galowen` has no role letter, so it only names. Two people in one role take a [join](joins.md#right-close) after them (`zalen zalowen zal`).

### Continue (`/x/`): overview
<a id="continue-x"></a>

Beginner used the ending to say how to take a content word’s meaning. On an `/x/` continue word, the ending instead picks what the word does:

| Agebon | Use | English |
|--------|-----|---------|
| one of six linkers + **-m** (firm **-l** on three) | glue one finished sentence to the next | *but*, *therefore*, … |
| other `/x/` root + **-l** / **-m** / **-n** | introduce a topic | *now, about X*; *let’s now talk about X* |
| `/x/` root + **-r** | return to a topic | *back to X* |
| clause join + **-n** | **sequence** | *and then* **`xan`**, … ([joins](joins.md)) |

[Discourse hooks](hooks.md#discourse-hooks), which have no first letter, use hook endings. Hook **-n** titles a [proper-name phrase](#titled-phrases).

### Number-word exception {#number-word-exception}

Beginner used **-l** / **-m** / **-n** to say how to take a citation’s meaning. On [number words](numbers.md), those same letters (and **-r**) have **number-specific** meanings. After a role letter, the number marker **r** may start a cluster that only number words use ([phonology.md](phonotactics.md#phonotactics)).
