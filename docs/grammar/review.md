# Level reviews

Each level ends with one review. It mixes every page of that level, one item per page, so you meet each decision again after the pages that followed it. Take the review once you have finished every page at that level. Each answer ends with a **Rule:** link to the section it tests: when you miss an item, reread that section.

Every word in a review was already met in an earlier practice, so there are no new words.

**4.** *Uzozen, whom I remember as sleepy, is sleeping.* `zuzozen wevom gozumol vezuvol.` or `zuzozen gozumol vezuvol thevom.`

::: details Show answer
`zuzozen wevom gozumol vezuvol.`

[z-Uzozen | [w-MEMORY | g-sleepy]] | v-sleep

On `/w/` right before the adjective, MEMORY covers only *sleepy*; **`thevom`** on `/th/` covers the whole sentence: *I remember sleepy Uzozen sleeping*.

**Rule:** [Mood on one adjective](knowing.md#mood-on-adjective)
:::
