# Inspect

Paste Agazan and click or highlight a word for a floating inspect card with part of speech, reference ending, lexicon or overlay gloss, and morph chips. Failed words stay in the stream with an error card. Highlight a join, span fence, or island brace (`{` / `}`) to inspect the construction.

**IPA:** below the input transcribes the spoken forms (phonology letter table, with syllable dots). Writing shorthand and span brackets expand to their spoken forms first; foreign `<>` interiors and compact loan words are skipped (not Agazan phonology).

**Copy Translation Prompt** copies a prompt that asks an LLM to translate the input into English, one numbered line per input line. Use a model at least as capable as Claude Opus 5.5.
