# Reasons, knowledge and plans

Recipes for English *because* / *if* / *would have*, habits, *start* / *stop* doing, *as of that date*, and when or why a feeling happens. Every form here is taught on a grammar page; each recipe links what it needs.

## Reasons and conditions {#reasons}

### English → Agebon {#english-cues}

**Needs:** [Dependent clauses](dependents.md#dependent-clauses) · [Contrary to a stance](sakes.md#contrary-to-stance) · [Continue](dependents.md#continue-x) · [Sentence linkers](dependents.md#sentence-linkers) · [Stacked discourse hooks](discourse-hooks.md#stacked-discourse) · [Because](causation.md#only-because) · [Point back](discourse-hooks.md#hook-resume) · [Clause sequence](join-across-roles.md#clause-sequence)

Time and discourse dependents use the same **`blarl`** hang as *if* / *because*. Discourse glue after a finished sentence is `/x/` continue, not a pole root.

| English | Agebon |
|---------|---------|
| *although* / *while* / *whilst* / *until* / *till* / *before* / *after* | same pole + **`blarl`** shape on adverb `/h/`, **-m** ([dependent clauses](dependents.md#dependent-clauses)): **`hezom`** / **`herem`** / **`harum`** / … |
| *so that* / *in order to* | same shape: **`hovam`** ([so that](dependents.md#so-that)); NP intended get = **`hovam`** + `/b/` **noun** |
| *despite* (NP) | same **`hezom`** (or **`gezom`**) + `/b/` **noun**, not a second pole |
| *against the rules* / *against their will* / *contrary to the plan* / *against my decision* / *contrary to what I was told* | hook **`uem`** + the stance it goes against: `uem hwavul` / `uem hwadum` / `uem thagem` / `uem thogol` / `uem thebam` ([contrary to a stance](sakes.md#contrary-to-stance)) |
| *though I promised* / *breaking my promise* | **`hezom blarl`** + the promise as its own sentence: `zuwon vezuvol hezom blarl zuwon vowurel hwazal.` (*I sleep, although I promised to walk*) ([contrary to a stance](sakes.md#contrary-to-stance)) |
| *after they took back their yes* / *more than they agreed to* | a yes taken back is a no: **`uem hwadum`**; past the agreed terms is the consent bar **`hwadam`** ([every bar](comparatives.md#stance-bars)) |
| *judging by* / *going by* / *given that* (grounds) | inferring or pattern channel + **`blarl`**: **`theyem blarl`** / **`thubem blarl`** ([evidence clause](knowing.md#evidence-clause)) |
| *therefore* / *thus* / *hence* / *consequently* / *as a result* / *accordingly* (discourse) | **`xahem`** ([continue](dependents.md#continue-x)) |
| *it follows that* / *necessarily, then* (a deduction from the last sentence) | **`xahel`** ([sentence linkers](dependents.md#sentence-linkers)) |
| *that doesn't follow* / *non sequitur* | **`thanam thohom thul blarl`** ([arguments](#arguments)) |
| *thus* (*in this way*) | the same adverb again: `/h/` with **-r** ([how English approximates -r](pronouns.md#how-english-approximates-r)) |
| *the fact that* / *the idea that* / *it is a fact that* | a predicate with a `/z/` stand-in: `gumugom zarl zuzozen vowurel.`; or two sentences, then `zarth` ([stand-in vowels](dependents.md#stand-in)): `zuzozen vowurel. zarth gumugom.` A clause never modifies a noun |
| *due to* / *owing to* / *because of* (NP) | **`thahum`** + `/b/` **noun** (`thahum blerulal`) |
| *not because* (clause) | **`thahum thul blarl`** ([stance join before `blarl`](join-across-roles.md#stance-join-before-barl)) |
| *however* / *meanwhile* (discourse) | **`xezom`** / **`xegorem`** |
| *regardless of* (NP) | same **`hezom`** + `/b/` **noun** as *despite* |
| *anyway* / *anyhow* (back to the main line) | the resume hook **`or …`** ([point back](discourse-hooks.md#hook-resume)) |
| *otherwise* / *or else* (failing that) | **`xon`** between the clauses ([clause sequence](join-across-roles.md#clause-sequence)) |
| *nevertheless* / *nonetheless* (discourse) | **`xezom`** after the finished claim; inside one sentence, **`hezom blarl`** |
| *whereas* (two claims set against each other) | **`xezom`** before the second claim, or **`hezom blarl`** inside one sentence |
| *moreover* / *furthermore* (discourse) | **`ael …`** opens the sentence that goes further; **`al …`** adds a separate point ([stacked discourse hooks](discourse-hooks.md#stacked-discourse)) |

### Obviously, apparently, perhaps, guess, assume {#stance-adverbs}

**Needs:** [Evidence strength](knowing.md#evidence-strength) · [Deduction](knowing.md#deduction) · [MAY](knowing.md#may) · [Hold endings (NOTIONAL)](notional-standing.md#hold-endings-notional) · [Hopefully and other attitudes](feelings-permission.md#speaker-attitude) · [Unmet](sakes.md#sake-changeability) · [As for](say-people-places.md#as-for) · [Asides](spans.md#asides) · [CAUSE](causation.md#cause) · [Every bar](comparatives.md#stance-bars)

English adverbs like *obviously*, *apparently* and *presumably* say **how you know** a claim. Agebon has no word for each one. It puts a channel on the clause as a `/th/` word, and the ending grades the evidence: **-l** solid, **-m** ordinary, **-r** thin. *Guess* and *assume* are not channels: a guess is a *could be* (MAY), and an assumption is toying with a premise (NOTIONAL). *Unfortunately* says how **you** feel about the claim, so it is an attitude word.

| English | Agebon | Reading |
|---------|--------|---------|
| *obviously* / *obvious* (it is in plain view) | `thugol` | LIVE, a clear full view |
| *obviously* (the clues are strong) | `theyel` | CLUES, strong clues |
| *apparently* / *apparent* / *it seems* (from clues) | `theyem` | CLUES, ordinary |
| *apparently* (so they say) | `thebam` | REPORTED |
| *apparently* (a glimpse) | `thugor` | LIVE, a glimpse |
| *presumably* (by the usual pattern) | `thubem` | PATTERN |
| *naturally* / *of course* (as you would expect) | `thubel` | PATTERN, a well-established one |
| *presumably* (a weak clue) | `theyer` | CLUES, thin |
| *guess* / *I guess* / *perhaps* / *maybe* / *possibly* / *not sure* / *unsure* | `thomam` | MAY, could be |
| *guess* (a passing thought) | `thomar` | MAY, who knows |
| *guess* (a gut hunch) | `thabor` | INTUITION, faint |
| *assume* / *suppose* | `theyur` | NOTIONAL, toy with it for now |
| *personally* / *in my view* | `hahugem bluwon` | topic: as for me |
| *by the way* / *aside* (in passing) | `th( … )` | aside fence, any place a stance word may sit |
| *necessarily* / *it follows* / *by deduction* | `thanam` | DEDUCED |
| *basically* / *fundamentally* | `hadelom` | manner adverb on *fundamental* |
| *overall* / *on the whole* | `hahugem blual` | as for everything |
| *automatically* / *by itself* | `zanal vowurel thewem blanar.` | CAUSE, with the doer resumed as its own cause |
| *increasingly* / *more and more* | `helam zel` + the quality | more than it used to be |
| *unfortunately* | `thudathum` | unspecified sake, unmet, can be softened |
| *unfortunately* (and it is final) | `thudathul` | unspecified sake, unmet, irreversible |

> `zuzozen theyel vowurel.`
>
> z-Uzozen | th-CLUES.strong | v-walk
>
> "Obviously, Uzozen is walking." (strong clues)

> `zolazun thomam velurul.`
>
> z-Olazun | th-MAY | v-departure
>
> "I guess Olazun is leaving."

> `zuzozen theyur vowurel.`
>
> z-Uzozen | th-NOTIONAL-suppose | v-walk
>
> "Assume Uzozen is walking."

> `zuzozen thudathum velurul.`
>
> z-Uzozen | th-sake-unmet-modifiable | v-departure
>
> "Unfortunately, Uzozen is leaving."

**Compare with:** *hopefully* and *worryingly* are the other speaker attitudes ([hopefully](feelings-permission.md#speaker-attitude)). *Assuming that Q, P* keeps the condition open: P with **`thohom blarl`** ([if](causation.md#if)).

### Reason, purpose, guilty {#reason-purpose-guilty}

**Needs:** [Because](causation.md#only-because) · [Fault](causation.md#fault) · [Motive](sakes.md#sake-preference) · [Prescription](sakes.md#sake-force) · [Attachment sites](sakes.md#attachment-sites) · [So that](dependents.md#so-that) · [Why?](fill-ask-roles.md#why) · [Emotion compose](feelings-permission.md#emotion-compose) · [Feeling with no object](feelings-permission.md#feeling-no-object)

English *reason* covers three jobs, and *purpose*, *justify* and *guilty* each split the same way. Name which one you mean: what **made it happen** (the because pole), what the speaker is **doing it for** (a motive, on a sake), or the **faculty** of thinking (the abstract sense of `ebobo`).

| English | Agebon | Reading |
|---------|--------|---------|
| *the reason it happened* | `thahum` + `/b/` | the because pole |
| *my reason* / *justify (give your reasons)* | `…thom` on a sake (`thawothom`) | motive: doing it for that sake |
| *justified* (the act is warranted) | `…them` on a sake (`thawothem`) | prescription: the act ought to serve that sake |
| *the faculty of reason* | `zebobom` | *intellect* |
| *purpose* (the outcome aimed at) | `hovam` + `/b/` | *so that* |
| *purpose* (what my noun is for) | `g…tho…` after the noun (`gawothom`) | the noun's purpose is this sake |
| *What is the purpose?* | `hovam blar` | *What for?* |
| *guilty* / *to blame* | `thahul` + `/b/` | the because pole, the reason broke a norm |
| *guilty* (the feeling) | a feeling word + **`thahul blarl`** + your own act | the feeling, caused by your act, which broke a norm |
| *hurt* / *upset* (no fault named) | a feeling word + **`thahum blarl`** + what happened | the feeling and its cause, with no one at fault |
| *ashamed* / *embarrassed* | `gubamem` | the embarrassment root as a property |

> `zuzozen velurul thahum blerulal.`
>
> z-Uzozen | v-departure | [th-because | bl-rain]
>
> "The reason Uzozen left is the rain."

> `zuzozen vezuyel thawothom thebamuzozen.`
>
> z-Uzozen | v-tell | th-relatedness-motive-any-term | th-REPORTED-Uzozen
>
> "I hear Uzozen's reason for talking is feeling connected." (for someone else's reason, say [how you know it](knowing.md#holder))

> `zuzozen vowurel hovam blarl zolazun vuhohol.`
>
> z-Uzozen | v-walk | [h-so-that | bl-that-clause] | z-Olazun | v-sit
>
> "Uzozen walks so that Olazun sits."

> `zuzozen velurul thahul blarl zolazun vezuyel.`
>
> z-Uzozen | v-departure | [th-because.fault | bl-that-clause] | z-Olazun | v-tell
>
> "Uzozen left because Olazun spoke, and Olazun was wrong to."

> `thawothumam thahul blarl zuwon vezuyel.`
>
> th-relatedness-unmet-modifiable-INTERNAL-FLOWING | [th-because.fault | bl-that-clause] | z-speaker | v-tell
>
> "I feel guilty for speaking." (a cost to a tie, held inside, and my speaking broke a norm)

What makes the feeling guilt is the fault pole on **your own** act. The feeling word alone says only that a tie is under strain, the same word as *hurt*. With the because pole and someone else's act, the same feeling is *hurt*:

> `thawothumar thahum blarl zolazun vezuyel.`
>
> th-relatedness-unmet-modifiable-INTERNAL-SURGING | [th-because | bl-that-clause] | z-Olazun | v-tell
>
> "I'm hurt that Olazun spoke."

Put the **act** in a `bl-` word after a fault pole, not the person ([fault](causation.md#fault)). *Guilty* is then *the wrong rests on that act*, and it leaves room for *Olazun did a wrong thing* without *Olazun is bad*.

**Compare with:** owning a harm to someone else (*I'm sorry*) is [thanks and sorry](feelings-permission.md#thanks-sorry), not a guilt feeling.

### Kill, feed, remove, prevent, persuade, introduce, show, create, excite {#cause-verbs}

**Needs:** [Make someone do it](causation.md#make) · [Decision](intention.md#decision) · [So that](dependents.md#so-that) · [Extra nouns](hooks.md#extra-noun)

English has a separate verb for *make someone do X* in many common cases: *kill* is *make die*, *feed* is *make eat*. Agebon has one way to say all of them. Keep the ordinary verb for what happens, let the one it happens to be the subject, and put the one who makes it happen in a `bl-` word right after **`thewem`** ([make](causation.md#make)). Change only the verb root.

| English | Agebon | Reading |
|---------|--------|---------|
| *kill* | `zolazun vezobul thewem bluzozen.` | Olazun dies, Uzozen makes it happen |
| *feed* | `zolazun vagazul thewem bluzozen.` | Olazun eats, Uzozen makes it happen |
| *make X angry* / *paint it red* (a result) | `zuzozen vunemul thewem blolazun.` | the adjective's verb root, Uzozen becomes angry, Olazun makes it happen |
| *arrived tired* / *left angry* (a state during) | `zolazun velurul herem blarl zalamur godamul.` or `zolazun godamul. zalamur velurul.` | a `/ɡ/` word right after the verb has no reading, so the state is its own clause |
| *feed* (a child, nurture) | `zolazun vevuyal duzozen.` | the nurturing root, no `thewem` |
| *remove* | `zanal velurul ual bedohol thewem bluzozen.` | the book leaves the table, Uzozen makes it happen |
| *discard* | `zanal velulul thewem bluzozen.` | the book is disposed of |
| *ensure* / *make sure* (that it happens) | `zolazun velurul thewem bluzozen.` | Olazun leaves, Uzozen makes it happen |
| *prevent* (make it not happen) | `zolazun velurul vul thewem bluzozen.` | Olazun does not leave, Uzozen makes that so |
| *prevent* (act so that it will not) | `zuzozen vowurel hovam blurl zolazun velurul.` | Uzozen walks so that Olazun does not leave |
| *persuade* | `zolazun theyemolazun thogom vowurel thewem bluzozen.` | as I gather, Olazun has decided to walk, and Uzozen made that happen |
| *introduce* | `zolazun veluyel duzozen thewem blahelan.` | Olazun learns Uzozen, Ahelan makes it happen: *make learned* |
| *show* / *display* / *reveal* | `zolazun dudozol vawebol thewem bluzozen.` | Olazun sees the dog, Uzozen makes it happen |
| *create* (bring into being) | `zudozol thewem bluzozen.` | the dog exists, Uzozen makes it happen |
| *create* (make by work) | `zuzozen dudozol vemodal.` | the production root |
| *excite* / *thrill* | `zolazun vugemal thewem bluzozen.` | Olazun is delighted, Uzozen makes it happen |
| *encourage* / *inspire* / *motivate* | `zolazun theyemolazun thager vowurel thewem bluzozen.` | as I gather, Olazun intends to walk, and Uzozen made that happen |
| *convince* (of a claim) | `zolazun vugowel duzozen thewem blahelan.` | Olazun trusts Uzozen, Ahelan makes it happen |

> `zolazun vezobul thewem bluzozen.`
>
> z-Olazun | v-die | [th-CAUSE | bl-Uzozen]
>
> "Uzozen kills Olazun."

> `zolazun theyemolazun thogom vowurel thewem bluzozen.`
>
> z-Olazun | th-CLUES-Olazun | th-DECISION-modifiable | v-walk | [th-CAUSE | bl-Uzozen]
>
> "I gather Uzozen persuaded Olazun to walk." (Olazun has decided, and can still change that)

> `zuzozen vowurel hovam blurl zolazun velurul.`
>
> z-Uzozen | v-walk | [h-so-that | bl-lest-clause] | z-Olazun | v-departure
>
> "Uzozen walks so that Olazun does not leave."

**Compare with:** *get someone to* by asking is tell plus a *to* [stand-in](dependents.md#stand-in), not **`thewem`**. **`thewem`** says the causer made it happen. Persuading puts the decision on the one persuaded, so a later change of mind stays possible. Their decision is in their mind, so a [holder](knowing.md#holder) says how you know it.

### Know, mean, explain, realize, forget, become {#mind-verbs}

**Needs:** [Dependent clauses](dependents.md#dependent-clauses) · [Embedded whether](questions.md#embedded-whether) · [Because](causation.md#only-because) · [Already, still, not yet](notional-standing.md#phasal) · [Can](intention.md#can) · [Existence](predication.md#existence) · [As for](say-people-places.md#as-for) · [Start and stop](#phase-verbs) · [Comparatives](comparatives.md#comparatives-e)

English verbs of knowing and saying (*explain*, *realize*, *forget*, *mean*) mostly sit on a few plain moves: tell, know, remember, and whether the change has come. Agebon keeps those roots and adds the phasal word for the change, so *realize* is *already know* and *forget* is *no longer remember*. *Mean* in the sense of *signify* is the compound `ezuyeloma` (*meaning*, speech that carries a thought).

| English | Agebon | Reading |
|---------|--------|---------|
| *mean* (signify) | `zezuyel dudozol vezuyelomal.` | the word carries the meaning *dog* |
| *mean* (intend) | `zuwon thagem vowurel.` | I plan to walk ([intention](intention.md#plan-predict)) |
| *define* | `zuzozen dezuyelomal hahugem bludozol vezuyel.` | tells the meaning, about the dog |
| *explain* | `zuzozen vezuyel bolazun darl zolazun vowurel thahum blarl zudozol varuvel.` | tells Olazun that the walk has the run as its reason |
| *describe* | `zuzozen hahugem bludozol vezuyel bolazun.` | tells Olazun about the dog |
| *know* (that) | `zuzozen vanam darl zudozol varuvel.` | knows that the dog runs; to say how *you* know it, use a [channel](knowing.md#evidentiality) |
| *know whether* / *know which* | `zuzozen vanam dorl zudozol varuvel.` | knows whether the dog runs; a blank inside asks *which* (`dor`) |
| *find out* | `zuzozen vumewol dorl zudozol varuvel.` | finds whether the dog runs |
| *know someone* | `zuzozen havom dolazun vawebol har.` | has met Olazun at some point ([ever](notional-standing.md#ever-never)) |
| *know how to* | `zuzozen vezuyoxal.` | can sing ([can](intention.md#can)) |
| *realize* / *notice* | `zuzozen havom vanam darl zudozol varuvel.` | already knows that the dog runs |
| *forget* | `zuzozen dolazun vevum huvum.` | no longer remembers Olazun |
| *become* | `zuzozen vebugem duzemol.` | starts being sleepy |
| *exist* | `zudozol.` | a lone noun: *there is a dog* |
| *happen* / *occur* | the event's own verb: `verulal.` | no helper word |
| *depend on* | `zuzozen vowurel thebom thahum blerulal.` | only because of rain |
| *allege* / *claim* | `thebam` on the clause | REPORTED: so they say |
| *compare* / *exceed* | `zuzozen zolazun zel gelazom.` | rank on a shared scale ([comparatives](comparatives.md#comparatives-e)) |

> `zuzozen havom vanam darl zudozol varuvel.`
>
> z-Uzozen | h-already | v-knowledge | d-that-clause | z-dog | v-run
>
> "Uzozen realizes that the dog is running."

> `zuzozen dolazun vevum huvum.`
>
> z-Uzozen | d-Olazun | v-memory | h-no-longer
>
> "Uzozen has forgotten Olazun."

**Compare with:** *explain* with no reason is just tell (**`vezuyel`**). *Make something real* is [create](#cause-verbs).

### Condition, factor, requirement, motivation, satisfaction, truth {#reason-nouns}

**Needs:** [If](causation.md#if) · [Only because](causation.md#only-because) · [Fault](causation.md#fault) · [Requirement](feelings-permission.md#requirement) · [Motive](sakes.md#sake-preference) · [Met](sakes.md#time-horizon-endings-on-met) · [Thanks and sorry](feelings-permission.md#thanks-sorry) · [Intention](intention.md#plan-predict) · [Speech manner](speech-moves.md#speech-manner) · [Evidentiality](knowing.md#evidentiality) · [Enough and too](sakes.md#sake-bars)

English turns reasons and feelings into nouns (*condition*, *motivation*, *satisfaction*, *truth*). Agebon has no noun for most of them. It keeps the stance word on the clause, so the noun becomes a short claim about how you stand: a condition is the pole word, a motive is a sake, a requirement is a demand, a truth is how you vouch for it.

| English | Agebon | Reading |
|---------|--------|---------|
| *condition* (*on the condition that*) | `thohom blarl` / `thebom blarl` | if / only if |
| *factor* (one cause among several) | `thahur blarl` | a share of the fault or cause |
| *circumstance* / *context* | a dependent after `blarl` (`herem blarl`, `thahum blarl`) | the situation as a clause |
| *requirement* / *demand* | `hwavel` / `hwavem` / `hwaver` | rule, person, or expectation |
| *necessary* / *unnecessary* | `hwavel` on the act; *more than needed* is the sake bar `thudatham zel` | required by a rule; past what the need asks |
| *motivation* / *motive* | `zuwon vowurel thawothom.` | my reason; someone else's motive takes a [holder](knowing.md#holder) |
| *satisfaction* / *pleasure* | `thodotham.` | pleasure, met |
| *desire* / *wish* | `zuzozen thalem vowurel.` | I want Uzozen to walk; someone else's wish takes a [holder](knowing.md#holder) |
| *regret* (for the harm) | `thawothum blawan.` | unmet relatedness, yours |
| *mistake* / *error* | `gogugol gul` or `thahul blarl` | not correct, or at fault |
| *assumption* | `theyur` | NOTIONAL, toy with it |
| *premise* (of an argument) | `ebobomahul` | a word about the argument ([arguments](#arguments)) |
| *truth* / *to tell the truth* | `thavewem` | revelation |
| *experience* (first-hand) | `thevum` | MEMORY, remembered as seen |

> `zuwon vowurel thawothom.`
>
> z-speaker | v-walk | th-relatedness-motive-any-term
>
> "I walk to feel connected." (that is my motive)

> `thodotham.`
>
> th-pleasure-met-any-term
>
> "That was a pleasure."

**Compare with:** a sake word names the sake that is met, so pick the one you mean: relatedness, competence, pleasure ([sakes](sakes.md#sake-inventory)). A noun that says what someone did is a [free relative](say-people-places.md#free-relative-what).

### Biased, wishful thinking, overconfident {#biased}

**Needs:** [Motive](sakes.md#sake-preference) · [Want](intention.md#want) · [MAY](knowing.md#may) · [Speech manner](speech-moves.md#speech-manner) · [Every bar](comparatives.md#stance-bars)

English *biased* says a view may be bent by what the holder wants from it. Agebon says that outright: put a [motive](sakes.md#sake-preference) on the thinking, so the view is held *for a stake*. Name the sake when you know which one, or use the unspecified sake **`uda`**. *Wishful thinking* and *I'd like to believe* are a want on the thinking itself. *Overconfident* ranks your trust against what the clues warrant: a CLUES [bar](comparatives.md#stance-bars) on *trust*.

| English | Agebon | Reading |
|---------|--------|---------|
| *I may be biased* | `zuwon thomam vevemol thudathom.` | I may think this for a stake of my own |
| *biased* (someone else) | `zuzozen vevemol thudathom blwazer.` | as you see it, Uzozen's view serves a stake of their own |
| *bias* (the noun, *Uzozen's bias*) | `zuzozen vevemol thudathom blwazer.` | the view held for a stake; [point back](dependents.md#which-noun) to it to name it |
| *I'd like to believe* / *wishful thinking* | `zuwon thalem vevemol darl zolazun vowurel.` | I want to think that Olazun walks |
| *overconfident* | `zuwon theyem zel gugowem.` | surer than the clues warrant |
| *underconfident* | `zuzozen theyem zuel gugowem.` | less sure than the clues warrant |
| *to be honest*, before owning a bias | `thavewem` | [speech manner](speech-moves.md#speech-manner) |

> `thavewem zuwon thomam vevemol thudathom.`
>
> th-revelation | z-speaker | th-MAY | v-think | th-sake-motive-any-term
>
> "To be honest, I may be biased."

> `zuwon theyem zel gugowem.`
>
> [z-speaker | th-CLUES | z-rank/more | g-trust]
>
> "I'm overconfident."

**Compare with:** *I think* as a guess is [MAY](knowing.md#may) on the claim. The motive says why the view is held, not how sure you are.

### Factivity (`if` vs `because`)
<a id="factivity"></a>

**Needs:** [If](causation.md#if) · [Because](causation.md#only-because) · [MAY](knowing.md#may) · [*as-of*](relations.md#as-of) · [RESIDUE](notional-standing.md#residue) · [forecasts](knowing.md#forecast)

English *because* and *if* can hide whether you **assert the dependent as a world fact**. Agebon puts that choice on the pole: **`thahum`** asserts the condition as the reason the outcome rests on; **`thohom`** does not (the outcome is under that opportunity). *Only if* vs *only because* is the same factivity split on the necessary pole.

> `zuzozen vowurel thahum blerulal.`
>
> z-Uzozen | v-walk | [th-because | bl-rain]
>
> "Uzozen walks because it rains." (the rain is stated as fact)

> `zuzozen vowurel thohom blerulal.`
>
> z-Uzozen | v-walk | [th-if | bl-rain]
>
> "Uzozen walks if it rains." (whether it rains is left open)

English *If he'd left, the door would still be locked* is not this pole. Write bookmark [*as-of*](relations.md#as-of) (`hunem`) plus [RESIDUE](notional-standing.md#residue) / a [forecast](knowing.md#forecast) (a channel such as CLUES plus `blral`) as needed, with **no** `thohom`. `thohom` stays speaker-now opportunity (*if it rains*). *If it rains, the Friday tab still stands* may stack both: `thohom` plus a **date** in *as-of* `/b/`.

> `zohol gelewul haram theyem blral hunem blarl zolazun velurul.`
>
> [z-door | g-locked] | h-RESIDUE | [th-CLUES | bl-later] | [h-as-of.bookmark | bl-that-clause] | z-Olazun | v-departure
>
> "If Olazun had left, the door would still be locked."

> `zaral haram henam bl_#22,7 thohom blerulal.`
>
> z-money | h-RESIDUE | [h-as-of.ledger | bl-_22,7] | [th-if | bl-rain]
>
> "If it rains, the 22 July tab still stands."

**Compare with:** [NOTIONAL](notional-standing.md#notional) is play (*as if*), not a bookmark now.

### Remote and unreal conditions {#remote-unreal}

**Needs:** [If](causation.md#if) · [Dependent clauses](dependents.md#dependent-clauses) · [stance numbers](numbers.md#number-as-stance-by-marker) · [NOTIONAL](notional-standing.md#notional)

English *If Olazun swam, Uzozen would walk* (past-tense *if*) says the condition is a long shot. Keep the open pole **`thohom blarl`** and put *unlikely* **`thrul`** inside the dependent clause.

> `zuzozen vowurel thohom blarl zolazun thrul vazuvel.`
>
> z-Uzozen | v-walk | [th-if | bl-that-clause] | z-Olazun | th-unlikely | v-swim
>
> "If Olazun swam, Uzozen would walk." (Olazun swimming is unlikely)

When the condition is known to be false (*If Olazun had left…*), keep the bookmark recipe from [factivity](#factivity) and add *suppose* **`theyur`** inside the dependent. That marks the departure as imagined, not something that happened.

> `zohol gelewul haram theyem blral hunem blarl zolazun theyur velurul.`
>
> [z-door | g-locked] | h-RESIDUE | [th-CLUES | bl-later] | [h-as-of.bookmark | bl-that-clause] | z-Olazun | th-NOTIONAL-suppose | v-departure
>
> "If Olazun had left, the door would still be locked." (Olazun did not leave)

#### Epistemic *because* {#epistemic-because}

English often uses *because* for **speaker grounds** (*it rained, because the street is wet*): Q is how you know P, not what made P happen. Put the inferring or pattern channel on the main sentence and hang the grounds on it with **`blarl`** ([evidence clause](knowing.md#evidence-clause)). The channel's ending grades the grounds.

> `verulal theyel blarl zugalal gegulol.`
>
> v-rain | [th-CLUES.strong | bl-that-clause] | [z-cloud | g-gray]
>
> "It is raining, judging by the gray clouds." (strong clues)

Use **`thahum blarl`** only when Q is also asserted as a world-foundation, what made P happen. For a soft *could be* with no grounds stated, put [MAY](knowing.md#may) (`thomam`, …) on the main sentence.

> `zolazun thomam velurul dahelan.`
>
> z-Olazun | th-MAY | v-departure | d-Ahelan
>
> "Olazun may be leaving Ahelan."

**For *could be*, use:** [MAY](knowing.md#may) (`oma`). **`thahum`** is world-reason under the claim; **`theyem`** / **`thubem`** + **`blarl`** is the grounds you go by.

**Related form:** *P, since / given that Q* (Q already shared) uses **`thahum blarl`** when Q is the reason P holds in the world, and **`theyem blarl`** when Q is only your grounds.

### Arguments: premises, validity, contradiction {#arguments}

**Needs:** [Deduction](knowing.md#deduction) · [Evidence clause](knowing.md#evidence-clause) · [If](causation.md#if) · [Because, iff, and only because](causation.md#only-because) · [Clause joins](joins.md#clause-joins) · [Sentence linkers](dependents.md#sentence-linkers) · [Hold endings (NOTIONAL)](notional-standing.md#hold-endings-notional)

An argument has three parts, and each has its own slot. The **link** between premises and conclusion is a pole (*if*, *if and only if*). **How you know** the link is the channel: DEDUCED (`thanam`) when the conclusion must hold. **Whether you grant the premises** depends on what sits before **`blarl`**: the channel alone asserts them, and a pole between the channel and **`blarl`** does not.

| English | Agebon | You assert |
|---------|--------|------------|
| *P, so Q* / *since P, Q* (a proof) / *a sound argument* | Q **`thanam blarl`** P | P and Q |
| *P implies Q* / *Q follows from P* / *P entails Q* / *a valid argument* | Q **`thanam thohom blarl`** P | only the link |
| *P is equivalent to Q* / *P just means Q* | Q **`thanam thehem blarl`** P | only the link, both ways |
| *P contradicts Q* / *P rules out Q* / *P and Q are inconsistent* | Q **`vul thanam thohom blarl`** P | only that they cannot both hold |
| *Q doesn't follow from P* / *that's a non sequitur* / *an invalid argument* | Q **`thanam thohom thul blarl`** P | only that the link fails |
| several premises (*P and R, so Q*) | one [clause join](joins.md#clause-joins) after **`blarl`**: P **`xam`** R | as above |
| *it follows that* (premises in the sentence before) | **`xahel`** Q | Q, on the frame the premises carried |
| *for the sake of argument* / *suppose P* | P with **`theyur`**, then **`xahel`** for each step | nothing: the steps stay supposed |
| *I checked every step* / *it seems to follow* | **`thanal`** / **`thanar`** | the same, graded on your check of the steps |

> `zuzozen vowurel vul thanam thohom blarl zuzozen vezuvol.`
>
> z-Uzozen | [v-walk | v-not] | th-DEDUCED | [th-if | bl-that-clause] | z-Uzozen | v-sleep
>
> "If Uzozen is asleep, it follows that Uzozen isn't walking." (I'm only saying the two can't both hold)

**Compare with:** *it obviously follows* from strong clues (*obviously, it rained*) is CLUES (`theyel`), not a deduction: the clues make it likely, not certain. *Because* in the sense of what made it happen is **`thahum`** ([factivity](#factivity)).

To talk **about** an argument rather than make one, use the dictionary words. Each is *reason* (`ebobo`, as in `zebobom` *the faculty of reason*) joined to a second root ([words you look up](compounds.md#lexical-compounds)).

| English | Agebon | Built from |
|---------|--------|------------|
| *an argument* / *logic* | `ebobomolawel` / `ebobomolawem` | *reason* + *ladder*: steps from what you grant to what follows |
| *a premise* | `ebobomahul` | *reason* + *wall*: what the argument stands on |
| *the conclusion* (of an argument) | `ebobomevahul` | *reason* + *finish line*: where the argument arrives |
| *valid* / *validity* | `ebobomulewel` / `ebobomulewem` | *reason* + *link*: the conclusion must hold if the premises do |
| *sound* / *soundness* | `ebobomabezol` / `ebobomabezom` | *reason* + *hardiness*: valid, and the premises are true |
| *a counterexample* | `ebobomunewul` | *reason* + *unlink*: a case where the premises hold and the conclusion fails |

> `zebobomolawel gebobomabezol gul.`
>
> z-argument | [g-well-founded | g-not]
>
> "The argument isn't sound."

A word about the argument does not make it. *The argument is valid* names the link without stating it; to give the link itself, use **`thanam thohom blarl`** from the table above. *A premise* says nothing on whether you grant it; *an assumption* you only toy with is **`theyur`** ([reason nouns](#reason-nouns)). *Conclusion* in the sense of *the end* of a talk or story is `ogaham`, not `ebobomevahul`.

### Stacks (evidentiality, CAUSE, habit)
<a id="stacks"></a>

**Needs:** [If](causation.md#if) · [evidentiality](knowing.md#evidentiality) · [restrictors](restrictors.md) · [CAUSE](causation.md#cause)

A one-off episode and a standing pattern use the same poles. Add extra words for the extra jobs: evidential `/th/` for *how you know* ([evidentiality](knowing.md#evidentiality)), **`hual` / `huam`** for habit ([restrictors](restrictors.md)), **`thewem`** for mechanism ([CAUSE](causation.md#cause)).

> `zerulal gohom blugalal hual.`
>
> [z-rain | [g-if | bl-cloud]] | h-always
>
> "It always rains if there are clouds."

**Compare with:** to say how you know a general claim, put a channel on it ([channels on a generalization](knowing.md#universality)). **CAUSE** is **`thewem`**.

### Hoping something will happen {#hope-forecast}

**Needs:** [Hopefully](feelings-permission.md#speaker-attitude) · [forecasts](knowing.md#forecast) · [evidentiality](knowing.md#evidentiality) · [soon](knowing.md#dated-channel)

English *I hope X will happen* is two claims: you want it, and you expect it. **`thoguyem`** gives the wanting. The *will* is a [forecast](knowing.md#forecast), so it needs a channel plus **`blral`** (or **`blrawum`** for *soon*). If nothing backs it but your gut, the honest channel is INTUITION: faint **`thabor`** for a slim hope, **`thabom`** for an ordinary one.

> `thoguyem thabor blrawum huvum verulal.`
>
> th-hope | [th-INTUITION.weak | bl-+-e-.about] | h-no-longer | v-rain
>
> "I hope the rain stops soon, though it's just a hunch."

**Compare with:** **`thoguyem`** with no channel and no offset is hope about now: `zuzozen thoguyem vowurel.` is *Hopefully Uzozen is walking.*

## Judging and helping {#judging}

### Important, useful, helpful, benefit, satisfy, upset {#sake-words}

**Needs:** [Sake inventory](sakes.md#sake-inventory) · [Met](sakes.md#time-horizon-endings-on-met) · [Emotion compose](feelings-permission.md#emotion-compose) · [Thanks and sorry](feelings-permission.md#thanks-sorry) · [Bars](comparatives.md#bars)

English *useful*, *helpful*, *important* and *benefit* judge a thing by what it does for someone. Agebon names the someone's **sake** (autonomy, competence, understanding, purpose, relatedness, beneficence, pleasure, physical). A met word says the thing serves that sake, and its ending says how long the payoff lasts. On a noun that is yours, the sake word sits on `/ɡ/`. On another noun, put it on `/w/` before **`goyem`**. Put a person in `/b/` for whose sake it is.

| English | Agebon | Reading |
|---------|--------|---------|
| *useful* / *helpful* / *practical* / *relevant* (for getting things done) | `guwatham` | competence, met |
| *important* / *critical* / *crucial* (it matters for the long run) | `wurethal goyem` | purpose, met, lasting |
| *meaningful* / *worthwhile* | `wuretham goyem` | purpose, met |
| *pointless* / *futile* | `wurethum goyem` | purpose, unmet |
| *glad to help* / *rewarding to give* | `thewatham.` | the act met your beneficence |
| *grateful* / *thankful* / *appreciate* (your own thanks) | `thawotham.`, or the met word for the sake that was served | your sake, met: the thanks ([thanks and sorry](feelings-permission.md#thanks-sorry)) |
| *benefit* / *benefits Olazun* | `thawotham blolazun` | the act met Olazun's sake |
| *advantage* (a lead over someone) | `zel` with the scale | rank against the other |
| *satisfy* (you) | `thawotham blawan` | the act met your sake |
| *satisfy* (a requirement) | `hwavel zoel` + scale | tie against the rule: it meets the requirement |
| *suitable* / *appropriate* (for a need) | `guwatham` or `thudatham zoel` | met, or enough for the need |
| *more important than* | `zel` between the nouns, then `gurethal` | rank on the lasting met sake |
| *upset* | `wawothumar goyem` | relatedness, unmet, held inside, surging |
| *upset for someone* | `wawothumem goyem` + `/b/` | unmet relatedness on their behalf |

> `zanal guwatham.`
>
> z-book | g-competence-met-any-term
>
> "My book is useful." (it helps me get things done)

> `zonal wurethal goyem.`
>
> z-memo | [w-purpose-met-lasting | g-stimulus]
>
> "The memo is important." (it matters for the long run)

> `zuzozen vowurel thawotham blolazun.`
>
> z-Uzozen | v-walk | [th-relatedness-met-any-term | bl-Olazun]
>
> "Uzozen's walking benefits Olazun."

> `zonal zezuyel zel gurethal.`
>
> [z-memo | z-speech | z-rank/more | g-purpose-met-lasting]
>
> "The memo is more important than the talk." (it matters more for the long run)

> `zuzozen zolazun zel gezuyol.`
>
> [z-Uzozen | z-Olazun | z-rank/more | g-sing]
>
> "Uzozen has the advantage over Olazun at singing."

> `zonal wawothumar goyem.`
>
> z-memo | [w-relatedness-unmet-modifiable-INTERNAL-SURGING | g-stimulus]
>
> "Upset about the memo."

**Compare with:** *too* and *enough* rank against a [sake bar](comparatives.md#bars). Bare *good* and *nice* have no root; they go the same way, to a met sake.

### Wrong, ugly {#wrong-ugly}

**Needs:** [Fault](causation.md#fault) · [Every bar](comparatives.md#stance-bars) · [Negation](joins.md#negation-u) · [Unmet](sakes.md#sake-changeability)

English *wrong* and *ugly* each hide a choice. Name which. *Wrong* is **incorrect** (not matching), **morally wrong** (someone broke a norm), or **bad for someone** (a sake unmet). *Ugly* is **not beautiful**, **less beautiful than a bar**, or **unpleasant to me**.

| English | Agebon | Reading |
|---------|--------|---------|
| *wrong* (incorrect) | `gogugol gul` | not correct, closed with **`gul`** |
| *wrong* (morally) | `thahul blarl` + the act | fault on the act ([fault](causation.md#fault)) |
| *wrong* (bad for someone) | `thawothum blolazun` | the act detracted from Olazun's sake |
| *badly* (manner) | the doer, then `thubem zuel hogugol` | less correctly than usual ([manner words](say-amounts.md#manner-words)) |
| *ugly* (not beautiful) | `gahelal gul` | not beautiful |
| *ugly* (below a bar) | `thoguyem zuel gahelal` | less beautiful than I hoped |
| *ugly* (unpleasant to me) | `godothum` | my noun detracts from pleasure |

> `zezuyel gogugol gul.`
>
> z-speech | [g-correct | g-not]
>
> "What was said is wrong." (it isn't correct)

> `zahelan thoguyem zuel gahelal.`
>
> [z-Ahelan | th-hope | z-rank/less | g-hibiscus]
>
> "Ahelan is less beautiful than I hoped."

**Compare with:** *bad*, *terrible* and the other bare evaluatives have no root; they route to an unmet sake, a rank against a bar, or a specific content root.

### Deserve, earn, entitled {#deserve}

**Needs:** [Prescription](sakes.md#sake-force) · [Requirement](feelings-permission.md#requirement) · [Permission](feelings-permission.md#permission) · [Exchange](relations.md#exchange) · [Adverbs `/h/`](clause.md#adverbs-h)

English *deserve* says something is owed without saying why. Name the ground. It is owed because giving it would be **fair**, because a **rule** gives a right to it, or because it was **earned** in exchange for effort.

| English | Agebon | Reading |
|---------|--------|---------|
| *deserves* (it would be fair) | `zolazun demebel vewal buzozen halurem thudathem.` | Olazun ought to give Uzozen the medal, fairly |
| *deserves* / *is entitled to* (a thing, by right) | `zolazun demebel vewal buzozen hwavel.` | the rules require Olazun to give it |
| *is entitled to* (an act) | `zuzozen vowurel hwaval.` | the rules allow Uzozen to walk |
| *earned* / *merited* (by effort) | `zuzozen varuvel heham blemebel.` | ran in exchange for the medal ([earn](say-people-places.md#give-get)) |

> `zolazun demebel vewal buzozen halurem thudathem.`
>
> z-Olazun | d-medal | v-present | b-Uzozen | h-fairness | th-sake-ought-offered
>
> "Uzozen deserves the medal." (Olazun ought, in fairness, to give it to Uzozen)

> `zuzozen varuvel heham blemebel.`
>
> z-Uzozen | v-run | [h-in-exchange-for | bl-medal]
>
> "Uzozen earned the medal by running."

**Compare with:** *deserving* with no ground has no word, like the bare evaluatives above. *Fair* on its own (*a fair judge*) is `galurem` ([leftover senses](say-people-places.md#leftover-senses)).

### Clear, honest, false, general, proud {#trait-words}

**Needs:** [Negation](joins.md#negation-u) · [Universals, domains and generics](joins.md#universals-domains-generics) · [Fault](causation.md#fault) · [Emotion compose](feelings-permission.md#emotion-compose) · [Number as stance](digitless-exponents.md#special-number-as-stance)

Many English adjectives are the plain opposite of something that has a root (*unclear*, *honest*, *false*). Agebon says the positive root and closes it with **`gul`** (*not*). Others claim how far something holds (*general*, *universal*, *absolute*). That is the universal fence: closed for no exceptions, open for *as a rule*. A few are a feeling (*proud*), which is an emotion compose, so the sake and the stimulus are named.

| English | Agebon | Reading |
|---------|--------|---------|
| *unclear* / *obscure* | `gagebom gul` | not clear |
| *honest* / *truthful* / *sincere* | `galamum gul` | not deceiving |
| *false* / *untrue* | `gogugol gul` | not correct |
| *responsible* (to blame) | `thahul blarl` + the act | fault on the act ([fault](causation.md#fault)) |
| *responsible* (in charge) | `gobayem` | of authority |
| *general* / *generally true* | `zuam` with the kind | every member, as a rule |
| *universal* / *absolute* / *without exception* | `zual` with the kind | every member, no exceptions |
| *comprehensive* / *covers everything* | `zual` with the scope | every member, nothing left out |
| *sure* / *confident* (I am) | stance number `thrawal` (`th+e`) | certain, no exceptions |
| *proud* (of something) | `wuwathamam goyem` after the thing | competence met, held inside, flowing |

> `zanal gagebom gul.`
>
> z-book | [g-clarity | g-not]
>
> "The book is unclear."

> `zuam gavulul gohamul.`
>
> [z-everything.open | g-fire] | g-hot
>
> "Fire is hot, as a rule."

> `zonal wuwathamam goyem.`
>
> z-memo | [w-competence-met-any-term-INTERNAL-FLOWING | g-stimulus]
>
> "Proud of the memo."

**Compare with:** *proud* rides on whichever sake the pride serves: competence for a skill, relatedness for a tie ([sakes](sakes.md#sake-inventory)). *Confident* about someone else's claim needs a [holder](knowing.md#holder). `th+e` is only the speaker's own certainty.

## Starting and stopping {#phase-verbs}

**Needs:** [objects `/d/`](clause.md#beginner), [word endings](word-endings.md).

English *start* / *stop* / *finish* doing something are ordinary verbs. Put the activity in `/d/` as an ordinary noun (`dowurel` *a walk*).

| English | Agebon | Same root as |
|---------|--------|--------------|
| *start* | `vebugem` | ▶️ `ebugel` *play button* |
| *stop* | `vozohul` | 🛑 `ozohul` *stop sign* |
| *finish* | `vevahul` | 🏁 `evahul` *finish line* |

> `zuzozen vebugem dowurel.`
>
> z-Uzozen | v-commencement | d-walk
>
> "Uzozen starts walking."

> `zuzozen vevahul dowurel.`
>
> z-Uzozen | v-finish-line | d-walk
>
> "Uzozen finishes walking."

*Stop* means the activity ends, finished or not. *Finish* means it reached its end.

**Compare with:** *still* / *no longer* / *not yet* are [phasal words](notional-standing.md#phasal), not these verbs.

## Against a dated now {#dated-now}

### Residue against a snapshot
<a id="as-of-standing"></a>

**Needs:** [RESIDUE and FORMER](notional-standing.md#residue) · [evidentiality](knowing.md#evidentiality) · [*as-of*](relations.md#as-of) · [NOTIONAL](notional-standing.md#notional)

[RESIDUE](notional-standing.md#residue) and [FORMER](notional-standing.md#former-climate) without a hosted pair score against **today’s** books. To score them against a dated now, add [*as-of*](relations.md#as-of). LIVE plus *as-of* puts the camera in that snapshot. MEMORY plus *as-of* is memory of a scene whose internal now is the snapshot. Write **`thevum`** again on the next memory clause; resume the books with **`henar`**. [MAY](knowing.md#may) still evaluates from speech-now.

> `zolazun haram henam bl_#22,7 velurul.`
>
> z-Olazun | h-RESIDUE | [h-as-of.ledger | bl-_22,7] | v-departure
>
> "As of 22 July, Olazun had left and was still gone."

> `zuzozen thugom henam bl_#22,7 vowurel.`
>
> z-Uzozen | th-LIVE | [h-as-of.ledger | bl-_22,7] | v-walk
>
> "It's 22 July, and I can see Uzozen walking."

> `zolazun thevum henam bl_#22,7 haram velurul. xuzozen thevum henar vowurel.`
>
> z-Olazun | th-MEMORY | [h-as-of.ledger | bl-_22,7] | h-RESIDUE | v-departure . x-Uzozen | th-MEMORY | h-as-of.ledger | v-walk
>
> "I remember that as of 22 July, Olazun had left and was still gone. I also remember Uzozen walking at that point."

> `zuzozen hual vezuyel helam henam bl_#22,7.`
>
> z-Uzozen | h-always | v-tell | h-FORMER | [h-as-of.ledger | bl-_22,7]
>
> "As of 22 July, Uzozen's habit of always talking was already in the past."

[NOTIONAL](notional-standing.md#notional) may stack with *as-of* (*as if, from Friday’s books*). Serious English *if he had* stays bookmark `hunem`, not play.

> `zolazun theyum henam bl_#22,7 velurul.`
>
> z-Olazun | th-NOTIONAL | [h-as-of.ledger | bl-_22,7] | v-departure
>
> "Imagine that, as of 22 July, Olazun is leaving."

### Plan and forecast against a snapshot
<a id="as-of-intention"></a>

**Needs:** [PLAN](intention.md#plan-predict) · [forecasts](knowing.md#forecast) · [DECISION](intention.md#decision) · [*as-of*](relations.md#as-of)

[PLAN](intention.md#plan-predict), [DECISION](intention.md#decision), and a [forecast](knowing.md#forecast) (channel + `blral`) without a hosted pair score against **speech-now**. PLAN and DECISION are stances, so the stance pair **`thenam`** ([stance as-of](relations.md#stance-as-of)) dates them: the plan as it stood **at** that now, aimed later than it (*was going to*), and the pick as it stood then. With an event pair ([*as-of*](relations.md#as-of)), the forecast offset counts **after** that now (*would rain*). Repeat the channel and `blral` on the next clause; resume whose-now with `henar` / `huner`.

> `zuwon thager vowurel thenam bl_#22,7.`
>
> z-speaker | th-plan-sketch | v-walk | [th-as-of.ledger | bl-_22,7]
>
> "As of 22 July, I was going to walk."

> `thubem blral hunem bl_#22,7 verulal. xuzozen thubem blral huner vowurel.`
>
> [th-PATTERN | bl-later] | [h-as-of.bookmark | bl-_22,7] | v-rain . x-Uzozen | [th-PATTERN | bl-later] | h-as-of.bookmark | v-walk
>
> "Taking 22 July as now, it would rain, going by the pattern. From that same now, Uzozen would walk too, going by the pattern."

> `zuwon thogom vowurel thenam bl_#22,7.`
>
> z-speaker | th-DECISION-modifiable | v-walk | [th-as-of.ledger | bl-_22,7]
>
> "As of 22 July, I had decided to walk, and could still change that then."

## Feelings: when and why {#feelings}

### When the stimulus happens {#emotion-stimulus-time}

**Needs:** [Emotion compose](feelings-permission.md#emotion-compose) · [forecasts](knowing.md#forecast) · [evidentiality](knowing.md#evidentiality) · [evidence strength](knowing.md#evidence-strength) · [RESIDUE](notional-standing.md#residue) · [NOTIONAL](notional-standing.md#notional)


A feeling word is how you feel **now**. The stimulus can sit anywhere in time. To place it, write a channel and an offset right after **`goyem`**, as for any [forecast](knowing.md#forecast) or [dated claim](knowing.md#dated-channel): the offset dates the stimulus, and the channel says how you know it.

> `zezuyel wuwathuraor goyem thebal blral.`
>
> [z-speech | [w-competence-unmet-passing-CIRCUM-SURGING | g-stimulus]] | [th-REPORTED.strong | bl-later]
>
> "Anxious about the dialogue that's coming, as a reliable source says."

> `zezuyel wuwathuraor goyem thabor blral.`
>
> [z-speech | [w-competence-unmet-passing-CIRCUM-SURGING | g-stimulus]] | [th-INTUITION.weak | bl-later]
>
> "Anxious about a dialogue I only have a hunch is coming."

> `zezuyel wawothumol goyem thevum blrul.`
>
> [z-speech | [w-relatedness-unmet-modifiable-AIMED-STILL | g-stimulus]] | [th-MEMORY | bl-earlier]
>
> "Stung by the dialogue, which is over; I was there."

Other shapes use forms you already have:

| Stimulus | Write | English |
|----------|-------|---------|
| coming | channel + `blral` | *dreading*, *hoping* |
| over | channel + `blrul` | *regretting*, *relieved*, *grieving* |
| over, still counting | [RESIDUE](notional-standing.md#residue) `haram` | *still stung, though it's done* |
| recurring | [always](restrictors.md) `hual` | *dreading every dialogue* |
| did not happen | [NOTIONAL](notional-standing.md#notional) | *relieved about what didn't happen* |

A [feeling with no object](feelings-permission.md#feeling-no-object) can take a channel and offset too. Then the stimulus is real but unnamed: you know when it is, not what it is.

> `thuwathuruor thabor blral.`
>
> th-competence-unmet-passing-UNPLACED-SURGING | [th-INTUITION.weak | bl-later]
>
> "Anxious about something I sense is coming."

How the stimulus is known matters. A dialogue a reliable source announced (`thebal`) and a hunch (`thabor`) can feel the same; the grammar asks which one it is.

### Feeling then {#emotion-feeling-time}

**Needs:** [Emotion compose](feelings-permission.md#emotion-compose) · [stance as-of](relations.md#stance-as-of) · [evidentiality](knowing.md#evidentiality)


To say you **felt** it at another time, date the feeling itself with [stance as-of](relations.md#stance-as-of): **`thenam`** plus the time or event in `/b/`, after the stimulus. Add a remembering channel for *I remember feeling it*.

> `zezuyel wawothumol goyem thenam blezuyel.`
>
> [z-speech | [w-relatedness-unmet-modifiable-AIMED-STILL | g-stimulus]] | [th-as-of.ledger | bl-speech]
>
> "The dialogue stung me at the time." (nothing is said about now)

> `zezuyel wawothumol goyem thevum thenam blezuyel.`
>
> [z-speech | [w-relatedness-unmet-modifiable-AIMED-STILL | g-stimulus]] | th-MEMORY | [th-as-of.ledger | bl-speech]
>
> "I remember the dialogue stinging at the time."

With no pair, the feeling is now. Keeping *it hurt then* apart from *it hurts now* lets you say that a feeling has passed.

### Cause is not target {#emotion-blame}

**Needs:** [Emotion compose](feelings-permission.md#emotion-compose) · [Because](causation.md#only-because) · [Fault](causation.md#fault) · [MAY](knowing.md#may)


A direction locus says where the charge **goes**. It does not say who **caused** it. Name the cause with the [because pole](causation.md#because) after the feeling, and name its [fault](causation.md#fault) only when you mean it. The target and the cause may differ.

> `zezuyel wawothumom goyem bluzozen thahum blerulal.`
>
> [z-speech | [[w-relatedness-unmet-modifiable-AIMED-FLOWING | g-stimulus] | bl-Uzozen]] | [th-because | bl-rain]
>
> "Irritated at Uzozen about the dialogue, but the rain caused it."

> `zonal wawothumol goyem blolazun thahum blarl zolazun vezuyel.`
>
> [z-memo | [[w-relatedness-unmet-modifiable-AIMED-STILL | g-stimulus] | bl-Olazun]] | [th-because | bl-that-clause] | z-Olazun | v-tell
>
> "Resentful at Olazun about the memo, because Olazun spoke." (a cause, and no one is blamed)

> `zonal wawothumol goyem blolazun thomam thahul blarl zolazun vezuyel.`
>
> [z-memo | [[w-relatedness-unmet-modifiable-AIMED-STILL | g-stimulus] | bl-Olazun]] | th-MAY | [th-because.fault | bl-that-clause] | z-Olazun | v-tell
>
> "Resentful at Olazun about the memo; maybe Olazun was wrong to speak."

Put an **act** after the pole (`barl zolazun vezuyel`), not the person. A feeling can be aimed at Olazun; blame goes on what Olazun did.

### Curious, confused, bored, awed, surprised {#understanding-feelings}

**Needs:** [Sake inventory](sakes.md#sake-inventory) · [Emotion compose](feelings-permission.md#emotion-compose) · [Feeling with no object](feelings-permission.md#feeling-no-object) · [Mirative](notional-standing.md#mirative)

Most of these feelings are about the **understanding** sake: whether something makes sense. Surprise is different. It says the news ran against what you expected, so it is the [mirative](notional-standing.md#mirative), and a sake word says how the news lands.

| English | Agebon | Reading |
|---------|--------|---------|
| *curious about* | `wowothomom goyem` | understanding as the motive, aimed at it, flowing |
| *interested in* | `wowothamam goyem` | understanding met, held inside, flowing |
| *fascinated by* | `wowothamor goyem` | understanding met, aimed at it, surging |
| *it clicked* / *aha* | `thowotharar.` | understanding met right away, held inside, surging |
| *confused by* | `wowothumaom goyem` | understanding unmet, can be softened, over the situation, flowing |
| *bored by* | `wowothurul goyem` | understanding unmet for now, moving off, still |
| *bored* (no object) | `thowothural.` | understanding unmet for now, held inside, still |
| *in awe of* | `wowothalaol goyem` | understanding met for good, over the situation, still |
| *it turns out* / *surprisingly* | `themom` | mirative on the clause |
| *amazed* / *astonished* | `themol` | mirative: a firm expectation overturned |
| *pleasantly surprised by* | a met feeling + `themom` | how it lands, plus the mirative |

> `zogalal wowothalaol goyem.`
>
> z-galaxy | [w-understanding-met-lasting-CIRCUM-STILL | g-stimulus]
>
> "In awe of the galaxy."

> `zewal wodothamar goyem themom.`
>
> [z-present | [w-pleasure-met-any-term-INTERNAL-SURGING | g-stimulus]] | th-MIRATIVE
>
> "Pleasantly surprised by the present."

Something new for its own sake (new sights, variety) is the pleasure sake, not understanding. *Bored* can be either: nothing new to enjoy is unmet pleasure; nothing new to learn is unmet understanding.
