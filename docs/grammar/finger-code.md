# Finger Code

::: warning Experimental
The finger code is new. Its shapes and instrument layouts have not yet been tried by signers, receivers, or players, so they may change.
:::

The finger code is a way to produce Agebon with your fingers instead of your voice. Each letter is a shape: a set of raised fingers. One hand shows vowels and the other shows consonants, so a whole syllable takes one beat, with both hands at once. The same shapes can be signed in the air, pressed into another person's hands, or played on a piano or a guitar, so one chart serves all of them. The code adds no words and no grammar: anything you can say, you can sign or play.

## Counting on your fingers {#counting}

Each spoken digit starts with its own consonant ([counts](./numbers.md#counts)): `b` for 1, `d` for 2, and so on to `m` for 0. In the finger code, each of these ten letters is shown as its digit, counted on your fingers the way you already count:

- 1 to 4 is a run: fingers raised in order, starting at the index finger (index; index + middle; index + middle + ring; all four).
- The thumb counts five: the thumb alone is 5, the thumb plus a run of 1 is 6, and so on up to the open hand for 9 (cue: the five bead on an abacus).
- 0 is the index and pinky (horns): the two outer fingers with an empty middle.

| Letter | Count | Shape |
|--------|-------|-------|
| `b` | 1 | index |
| `d` | 2 | index + middle (V) |
| `g` | 3 | index + middle + ring |
| `v` | 4 | four fingers, thumb tucked (flat hand) |
| `z` | 5 | thumb alone |
| `h` | 6 | thumb + index (L) |
| `l` | 7 | thumb + index + middle |
| `r` | 8 | thumb + index + middle + ring |
| `n` | 9 | open hand |
| `m` | 0 | index + pinky (horns) |

The four consonants left over come next in [alphabet order](./phonology.md#letter-names): `w`, `y`, `th`, `x`. They are the runs 1 to 4 again, with the fingers hooked: keep the base knuckle straight and curl the two outer joints, so the hook sticks out from the fist instead of folding into it. Straight fingers mean a digit letter; hooked fingers mean one of these four. The thumb is never hooked.

| Letter | Shape |
|--------|-------|
| `w` | index, hooked |
| `y` | index + middle, hooked |
| `th` | index + middle + ring, hooked |
| `x` | all four, hooked (claw) |

The vowels go on the other hand. They are the runs 1 to 4, in alphabet order:

| Vowel | Shape |
|-------|-------|
| `u` | index |
| `a` | index + middle (V) |
| `o` | index + middle + ring |
| `e` | four fingers |

[Opposite vowels](./phonology.md#opposite-vowels) (`u` and `a`, `o` and `e`) differ by one finger. A fist is never a letter: it means *this hand is silent on this beat*.

The chart in [Try it](#try-it) draws every shape in a sentence.

## Two hands {#two-hands}

Your dominant hand shows consonants and your other hand shows vowels. The consonant hand does more work (fourteen shapes, some of them hooked), so it gets your stronger hand. Neither hand moves around; each letter is only a change of fingers.

Several shapes are the same on both hands: index alone is `u` on the vowel hand and `b` on the consonant hand. So that a viewer can tell the hands apart, hold both palms toward the viewer, with the consonant hand's fingers pointing up and the vowel hand's fingers pointing sideways, toward the other hand. A left-handed signer's layout is the mirror image of a right-handed one; either way, the sideways fingers mark the vowel hand.

[Try it](#try-it) shows both hands in this layout.

## One beat per syllable {#beats}

Agebon syllables have a fixed shape, so the code times them the same way every time. Each syllable takes one beat, and every beat is the same length, as in [speech](./phonology.md#rhythm-and-stress):

| In speech | In the finger code |
|-----------|--------------------|
| A consonant and then a vowel | Both hands on the same beat |
| A vowel with no consonant before it | The vowel hand alone |
| Two consonants before a vowel | A grace shape: a quick shape for the first consonant, just before the beat |
| A consonant after a word's last vowel (**-n**, **-l**, **-m**, **-r**, a plural **-x**) | The consonant hand alone, one beat per letter. The last one is held through its beat |
| The first syllable of a word | A stronger beat |
| The gap between words | A one-beat rest |
| The end of a sentence | A longer rest, both hands silent |

Because each hand has its own letters, a beat always reads one way: one hand alone is either a vowel with no consonant before it or a consonant at the end of a word, and the direction of the fingers says which.

For example, `thohom` (*if*) is three beats:

| Beat | Consonant hand | Vowel hand |
|------|----------------|------------|
| 1 (stronger) | `th`: index + middle + ring, hooked | `o`: index + middle + ring |
| 2 | `h`: thumb + index | `o`: index + middle + ring |
| 3, held | `m`: horns | fist |

Play any sentence in [Try it](#try-it) to see its beats.

## Signed {#signed}

Hold the shapes up at chest height, palms toward the viewer. Each beat, both hands form their shapes and pulse forward together.

| Beat | Signed |
|------|--------|
| Syllable | Both hands pulse forward together |
| Stronger first beat | A bigger pulse |
| Held letter | The shape stays still through the beat, with no pulse |
| Grace shape | A quick flash of the shape before the beat |
| Silent hand | Fist |
| Rest | Both fists drop |

Like fingerspelling, the finger code spells sounds, one letter at a time. It has no signs for whole words, and where your hands are in the space around you carries no meaning.

Pick **Signed** in [Try it](#try-it) to watch a sentence signed.

## Touch {#touch}

The shapes can be felt as well as seen. Every touch mode uses the same chart:

| Mode | How |
|------|-----|
| Tapping | Both hands tap their shapes on a table or on your thighs. It is silent, useful for practice and quiet use, and visible to anyone watching |
| Palm press | The signer presses the shapes into the receiver's upturned palms, each hand into the palm facing it |
| Hand over hand | The receiver rests a hand over each of the signer's hands and feels the shapes in the air |

When pressing, straight fingers land on their fingertips, spread at their natural spacing, and hooked fingers land on their middle knuckles. Each finger leaves one point of pressure, so the receiver reads a shape from things touch picks up well: how many points there are, how far the group reaches from the index edge, whether the thumb's point is there, the gap in the middle for `m`, and a soft fingertip against a hard knuckle for straight against hooked.

| Beat | Touch |
|------|-------|
| Syllable | A tap or press, both hands together |
| Stronger first beat | A firmer press |
| Held letter | The fingers stay down |
| Rest | Both hands lift briefly. This also marks the gap between words |

In a palm press there is no finger direction, so the receiver tells the hands apart by which palm is touched. Agree on the signer's dominant hand before you start.

Pick **Touch** in [Try it](#try-it) to see a sentence pressed into a receiver's palms.

## Piano {#piano}

On a piano, every note is a black key. The black keys make one five-note scale, so any notes you play together sound pleasant. The left hand plays vowels and the right hand plays consonants for every player, left-handed or not, so the consonants sit on top.

Pressing a whole run would sound as a blur of neighboring notes that is hard to hear apart. So on the keys you strike where the count ends: only the last finger of a run goes down, plus the thumb when the thumb is part of the count. The horns shape for `m` presses both of its fingers. Fingers are numbered 1 (thumb) to 5 (pinky).

| Hand | Thumb (1) | 2 | 3 | 4 | Pinky (5) |
|------|-----------|---|---|---|-----------|
| Right (consonants) | F♯5 `z` | G♯5 `b` | A♯5 `d` | C♯6 `g` | D♯6 `v` |
| Left (vowels) | C♯4 hook mark | A♯3 `u` | G♯3 `a` | F♯3 `o` | D♯3 `e` |

The other digit letters combine the thumb with a run's last finger: `l` is thumb + 3, `r` thumb + 4, `n` thumb + 5, and `m` is 2 + 5.

A key cannot be hooked, so the left thumb is the hook mark: a hooked letter is its straight letter plus the left thumb. `w` is `b` + hook, `y` is `d` + hook, `th` is `g` + hook, and `x` is `v` + hook. Neighboring fingers would strike neighboring keys, which sound harsh together, so `h` (thumb + index) is the one letter you learn separately: on piano it is `z` + hook.

Play detached and without pedal, so each key comes up at the end of its beat. A held letter keeps its keys down for one beat. Leave a one-beat rest after each word and two more at the end of a sentence.

## Guitar {#guitar}

The guitar is tuned to open G (D G D G B D, low to high). It keeps the code's two hands and its beats, but each hand gets its own strings and its own shapes, because a guitar string sounds only one note at a time.

The picking hand plays consonants on the four open treble strings, which the fretting hand never touches: the thumb on the D below middle C, and the index, middle, and ring fingers on the G, B, and D above it. As on piano, a run sounds only its last finger's string, and the thumb adds its own string when the thumb is part of the count:

| Letter | Strings |
|--------|---------|
| `b` | G |
| `d` | B |
| `g` | high D |
| `v` | G + B + high D (all three fingers) |
| `z` | low D |
| `h` | low D + G |
| `l` | low D + B |
| `r` | low D + high D |
| `n` | all four |
| `m` | G + high D (the two outer fingers) |

A string cannot be hooked either, so the hooked letters take the next string up. `w` is `b` plus the next string (G + B), and `y` is `d` plus the next string (B + high D). `th` is the thumb plus `w`, and `x` is the thumb plus `y`.

| Letter | Strings |
|--------|---------|
| `w` | G + B |
| `y` | B + high D |
| `th` | low D + G + B |
| `x` | low D + B + high D |

The fretting hand plays vowels on the two lowest strings (the 6th, tuned to D, and the 5th, tuned to G), without picking: it hammers a finger down on a fret hard enough to sound the note. The vowels climb the scale in count order:

| Vowel | Note | Fret |
|-------|------|------|
| `u` | E | 6th string, fret 2 |
| `a` | G | 6th string, fret 5 |
| `o` | B | 5th string, fret 4 |
| `e` | D | 5th string, fret 7 |

The two D strings in the consonant hand are the same note an octave apart, so `z` (low D) and `g` (high D) differ only by how high they sound.
