# Language name (editors)

English **Egabon** is the published 👓 *glasses* root **`egabo`** (metaphorical *clarity*) plus proper **-n**, the same name shape as the house cast's names (`uzoze` + **-n**). Learner wording and the English gloss live only in [introduction.md](../grammar/introduction.md) — do not restate that gloss here or in [AGENTS.md](../../AGENTS.md).

**Why this root.** 👓 is placed like every other row, with no pin: its tail says it is worn on the body (`b`) and has no special job (`o`), and its onset comes from root-tails placement ([root spellings](lexicon.md#root-spellings-come-from-convert-word)). The name tracks that root. When a retie moves 👓, the name moves with it through `npm run rename-language` ([retie § language name](retie.md#language-name)).
