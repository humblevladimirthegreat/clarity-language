# Proposals (editors)

How to keep **`docs/proposals/`**. Grammar pages must **not** link here or mention that folder.

**Do not link to proposal pages.** Files move between the folder root, `partially-implemented/`, and `rejected/`; a markdown link to a proposal will break. If another editor note must name one, use a backtick filename (`learner-tts.md`) — never a markdown link whose target is a file under `docs/proposals/`. The same rule applies in grammar, meta, examples, `AGENTS.md`, `TODO.md`, and **other proposals**.

Proposals may link **out** to `docs/grammar/`, `docs/meta/`, `data/`, and code. They are not design authority; absorb into grammar or meta, then drop or reject the proposal.
