# Comparatives, superlatives, and equatives

This page is the source of truth for **scalar comparison**: *more … than*, *the …-est*, *as … as*, and pointers for measured differentials (*two inches taller*). Fence join vowels, endings, and SHARED placement are defined in [coordination.md](coordination.md); this page says when those forms mean comparison rather than ordinary ranking or bundle description.

PoS prefixes: [language-reference.md](language-reference.md). Scale adjectives are ordinary `/ɡ/` (lexicon-marked as **gradable / scalar**). Absolute (non-comparative) use stays unfenced: `z-Samn g-bigl` = *Sam is big*.

## Overview

| Join + SHARED scale `/ɡ/` | Reading |
|---------------------------|---------|
| Ranked **`e` / `ae` / `oe` / `ue`** | **Comparative / superlative** — conjuncts ordered **along** the scale |
| Boolean **`a`** | **Equative** — conjuncts **equal** on the scale |
| **`o` / `ao`** | Not equative — SHARED stays [bundle description](coordination.md#scope-fence-p-coord) (prefer non-scalar `/ɡ/`) |
| Invert **`ua` / `uo`** | SHARED = [kind / domain](coordination.md#universals-domains-generics), not a comparison scale |

**Trigger:** SHARED ordinary `/ɡ/` that the lexicon treats as a **scale** (gradable), on an NP-slot fence (`/z/` `/d/` `/b/`). Degree on that scale (*much*, *slightly*) is `/w/` in SHARED on the scale `/ɡ/`. Complex `/ɡ/`+`/b/` in SHARED is still available when the scale adjective takes an argument (including [measured differentials](#measured-differentials)).

Revision **`el`** (*or rather*) is unrelated. Do **not** encode *than* primarily as a dedicated `/w/` *than* particle — the fence is the spine.

## Comparatives and superlatives (ranked + SHARED scale)
<a id="comparatives"></a>
<a id="superlatives"></a>
<a id="comparative-shared-scale"></a>

**Comparatives reuse ranked conjunction.** Bare `zel A B` ranks *alternatives* (preference / priority / contingency from context). When a ranked fence (`e` / `ae` / `oe` / `ue`) carries a SHARED ordinary `/ɡ/` (plus its `/w/` stack), that `/ɡ/` is the **scale of ranking** — not “property of the bundle.” Conjuncts are ordered **along that scale**.

| Pattern | Reading |
|---------|---------|
| **Multi (2+)** + SHARED scale | **Comparative ladder** — earlier ≻ later on the scale (`e` / `ae` / `oe`); later ≻ earlier under **ue** |
| **Unary (1)** + SHARED scale | **Superlative** — the sole conjunct ranks at the top of the scale for the domain in play (*the …-est* / *most …*); under **ue**, sole bottom (*the least …*) |
| **Nullary (0)** + SHARED scale | **Empty superlative** — there is no top of the scale (*there is no biggest* / *nobody is the …-est*); open **-m** = no biggest comes to mind. Contrast **-r**: `zer g-bigl` → *whatever ranks highest on big* (positive twin, not emptiness) |
| Ranked **without** SHARED `/ɡ/` | Ordinary alternative ranking (*prefer A over B*; *A else B*) — **not** a scalar *bigger than*; nullary without scale stays *don’t care* / *I don’t have a ranking* |

**Ordinary scalar *than*:** prefer bare **`e`** (exclusivity unmarked — both may be high on the scale). Keep **`ae`** / **`oe`** for co-satisfiable vs exclusive *ladders* (wishlist / triage), not as the default *more … than*. **`ue`** (or reverse conjunct order under **e**) = *less … than* / ascending on the scale.

| Example | Gloss |
|---------|-------|
| `zel g-bigl z-Samn z-Lean` | *Sam is bigger than Lea* (closed; Sam ≻ Lea on *big*) |
| `zem g-talll z-Samn z-Lean z-Patn` | *Sam ≻ Lea ≻ Pat on height* (open; others may rank too) |
| `zuel g-bigl z-Samn z-Lean` | *Sam is less big than Lea* / Sam ≺ Lea on *big* (closed reverse) |
| `zel w-muchl g-bigl z-Samn z-Lean` | *Sam is much bigger than Lea* |
| `zel g-bigl z-Samn` | *Sam is the biggest (of all)* — unary superlative; domain = context / discourse universe unless narrowed elsewhere |
| `zel g-bigl` | *there is no biggest* — nullary **empty superlative** (closed) |
| `zem g-bigl` | *no biggest comes to mind* — nullary empty superlative (open) |
| `zuel g-bigl z-Samn` | *Sam is the least big (of all)* — unary reverse / bottom of the scale |
| `zuel g-bigl` | *there is no least* — nullary empty reverse superlative (closed) |
| `zel g-bigl z-Samn z-Lean z-Patn` | *Sam is biggest among these three* (multi; Sam first) |
| `zer g-bigl` | *whatever ranks highest on big* — positive twin of empty `zel g-bigl`, not emptiness |
| `zer g-bigl z-Samn z-Lean` | *whichever of Sam or Lea ranks higher on big* |

Same under `/d/` / `/b/` when the ranked group fills that slot. Under `/ɡ/`, SHARED `/w/` on a ranked AP fence remains shared *degree* over ranked properties (`gel w-veryl g-happyl g-proudl`), not a noun-scale comparative — noun-scale comparatives use an NP-slot ranked fence (`/z/` `/d/` `/b/`) with SHARED `/ɡ/`.

Assert the ranking as clause content with the same predicative pattern as plain adjectives (zero-copula / light verb as elsewhere): `jal zel g-bigl z-Samn z-Lean` → *Sam is bigger than Lea.* When discourse needs the comparee alone as subject of another verb, keep that subject ordinary and place the comparative claim in another slot or sentence — do not force the whole ladder to be the only subject.

**Number ranges** and **numeric thresholds** (unary ranked **`zel z+5l`** = *\<5*, **`zuel z+5l`** = *\>5*): **[numbers.md § Ranges](numbers.md#ranges)** — not expanded here.

## Equatives (boolean **`a`** + SHARED scale)
<a id="equatives"></a>
<a id="equative"></a>
<a id="as-as"></a>

**Equatives reuse boolean *and*.** When an **`a`** fence (`zal` / `zam` / `zan` / …) on an NP slot carries a SHARED **scale** `/ɡ/` (gradable), that `/ɡ/` is **equality on the scale** — not ranking, and not “property of the bundle.”

| Pattern | Reading |
|---------|---------|
| **Multi (2+)** + SHARED scale under **`a`** | **Equative** — the listed conjuncts are **equal** on the scale (*A is as ADJ as B*; three or more = all equal) |
| **Unary / nullary** + SHARED scale under **`a`** | **Not** equative — stay ordinary unary / nullary *and* readings ([coordination](coordination.md#unary-phrase)); equative needs **two or more** comparees |
| **`a`** + SHARED **non-scalar** `/ɡ/` | Whole-phrase **bundle** description (status quo) — `zam g-ofl b-Samn z-dogl z-catl` = *Sam’s (dog and cat)* |
| **`a`** **without** SHARED scale | Ordinary inventory *and* — not an equative |

Open **-m** (`zam`) = soft / approximate equality (*about as … as*). Closed **-l** = stand behind sameness on the scale for the claim. Named **-n** = conventional equal-set label when useful.

**Distributive “both are big” (not necessarily equal):** do **not** use SHARED scale under **`a`**. Put `/ɡ/` on each conjunct (or left-bound `gl-` per head): `zam z-dogl g-bigl z-catl g-bigl`.

| Example | Gloss |
|---------|-------|
| `zal g-bigl z-Samn z-Lean` | *Sam is as big as Lea* (closed) |
| `zam g-talll z-Samn z-Lean` | *Sam is about as tall as Lea* (open / soft) |
| `zal g-bigl z-Samn z-Lean z-Patn` | *Sam, Lea, and Pat are equally big* |
| `jal zal g-bigl z-Samn z-Lean` | predicative: *Sam is as big as Lea.* |
| `zal g-bigl z-dogl z-catl` | *the dog is as big as the cat* |

Same under `/d/` / `/b/` when the equal group fills that slot. Under `/ɡ/`, an **`a`** AP fence with SHARED `/w/` stays shared degree over conjoined properties — not a noun-scale equative (use an NP-slot **`a`** fence with SHARED scale `/ɡ/`).

**Contrast with comparative:** `zel g-bigl z-Samn z-Lean` = Sam ≻ Lea on *big*; `zal g-bigl z-Samn z-Lean` = Sam = Lea on *big*. Do **not** encode equative with ranked **`e`** (that asserts inequality).

## Measured differentials
<a id="measured-differentials"></a>
<a id="measure-gap"></a>

*Two inches taller* is still a **comparative** (ranked + SHARED scale). The gap size is a **measure NP** as the scale adjective’s single `/b/` argument: **unit** as the `/b/` noun, **amount** as `/ɡ/` on that unit.

Full shape and unit grammar: **[numbers.md § Measure phrases](numbers.md#measure-phrases)**.

| Example | Gloss |
|---------|-------|
| `zel g-talll b-inchl g+2l z-Samn z-Lean` | *Sam is two inches taller than Lea* |
| `zel w-muchl g-talll z-Samn z-Lean` | *Sam is much taller than Lea* (vague degree — `/w/`, no measure NP) |

Do **not** stack two `/b/` arguments (amount + unit) on the scale. Vague degree stays `/w/`; counted gaps use the measure-NP pattern.
